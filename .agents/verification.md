# 交付前验收清单

任何内容、结构或构建变更在交付前都要执行适用项。

## 内容正确性

- [ ] 覆盖大纲对应学习范围，没有因拆分或改写遗漏段落。
- [ ] 所有计算题已用第二种方法复算。
- [ ] 教学图结构合法、数字成立、术语口径一致、字符对齐。
- [ ] 反例确实错误，并且错因与正文说明一致。
- [ ] 题干中的实体、属性和名词完整自洽。
- [ ] 每道选择题恰有一个正确答案，干扰项可被明确排除。
- [ ] 正文没有草稿、自问自答、“等等／更正”等推理痕迹。
- [ ] 每个一句话带过的概念对只读仓库的学习者仍然自足。

## 结构与链接

- [ ] 学习进度只在 `00-总览与进度.md` 维护，且没有误改用户状态。
- [ ] 课程顺序、章节顺序、上一章／下一章指向正确。
- [ ] 所有相对链接指向真实文件，旧路径已处理。
- [ ] 没有 Markdown 页内锚点链接。
- [ ] README 的文件结构和实际结构一致。
- [ ] 仓库内容不含资料品牌、水印、联系方式或本机绝对路径。

## Markdown 与渲染

- [ ] UML 构造型已放入反引号。
- [ ] 没有失效的粗体标记或页面上暴露的 `**`。
- [ ] 普通范围使用全角 `～`，没有意外删除线。
- [ ] 长表格没有出现逐字竖排；没有使用全角竖线伪造表格。
- [ ] ASCII 图、表格、折叠答案、代码块在浏览器中显示正常。

## 构建产物

- [ ] 修改课程或工具后已运行 `npm run build`。
- [ ] `docs/` 中的 HTML、CSS、JS 和 `.nojekyll` 已正确生成。
- [ ] 1440、1140、880 三档布局通过检查，深色主题已抽查。
- [ ] 导航高亮、章节目录、移动抽屉和跨页链接可用。
- [ ] 没有手工修改 `docs/`，没有提交 `pdf/*.pdf` 或 `.refs/` 内容。

## 规则维护

如果用户反馈暴露了新的错误类型，把可复用的检查规则加入最匹配的 `.agents/*.md`。不要在多个文件重复维护同一条状态或结构定义。
