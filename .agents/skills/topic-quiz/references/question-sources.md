# 题源地图

出卷前用这份地图确定「该考点有哪些题可出、在哪找、检索词怎么写」。所有位置都是相对仓库根的真源路径；`docs/` 是产物，不要从这里找题。

## 一、通用结构

每课一个目录 `软考学习/NN-课名/`，其中与出题有关的有：

| 文件 | 内容 | 题型 |
|---|---|---|
| `90-课后考题.md` | 选择题 + 1～2 道案例题 | 课后题 / 案例题 |
| `91-精华题*.md` | 前半是精华题，`## 补充题…` 小节起是补充题 | 精华题 / 补充题 |
| `07-案例题专攻.md`（部分课为 `08-`） | 案例题套路讲解，含**带答案的演示例题** | 案例题（作素材，不作题目） |
| `99-答案与解析.md` | 上述全部答案 | —（批改阶段才读） |
| `NN-小节.md` | 讲义正文 | 含零星「案例 A/B」教学示例，不作出题 |

模拟卷单独一课 `99-考前全真模拟卷/`：`01/02-上午卷*.md`（75 选择题）、`03-上午卷补充题.md`、`04/05-下午卷案例*.md`（5 道案例大题）。

## 四、出卷注意

- **课后题和模拟卷的选择题是连续编号的**，抽题时按 `sourceNo` 记进选题记录即可，卷面对外重排成 1、2、3。
- **03/04 的案例题没有独立题号**，以「二、案例题（…）」小节标题定位，选题记录里 `sourceNo` 写小节名（如 `二`），并记行号。
- **11 专业英语是完形填空**，一篇文章 5 空连体，出题要整篇给（不然没有上下文），题量按「篇」算不算按「空」算。
- **99 模拟卷**别拿来当日常练习：它体量大、目的是限时模拟，用户没要求就只从里面抽 1～2 道补充题。
- 91 文件里「补充题」小节之前的是**精华题**、之后的是**补充题**，出卷要分得清这两类（用户点名两类都要）。

## 五、判答案去哪找

| 题目来路 | 答案位置 |
|---|---|
| `NN-*/90-*.md` | `NN-*/99-答案与解析.md` 的「课后考题答案」「案例题答案」 |
| `NN-*/91-*.md` | `99-答案与解析.md` 的「精华题答案」「补充题答案」 |
| 模拟卷上午卷 | `99-考前全真模拟卷/90-上午卷答案与解析.md` |
| 模拟卷下午卷 | `99-考前全真模拟卷/91-下午卷答案与评分点.md` |

`sections` 名称各课略有差异（如 04 的「案例题答案（第一道…）」、09 的「课后选择题答案」），以文件内实际标题为准。
