- `outlineNavHtml()` 生成左栏：`<nav class="outline-nav">` → `<section class="tier tier-N">` → `<p class="tier-title">梯队名<span class="cnt">已学/总数</span></p>` + 课程 `<ul>`；当前页 `is-current`、已学打 `✓`（`ok` span）；第一梯队琥珀色标出。
- 大纲页标题过长（软件设计师（软考中级）考点大纲与学习范围）在窄栏折三行 → 导航里换短名「考点大纲与优先级」。
- 「本页大纲」抽成可移动块 `TOC_BLOCK`（`[data-toc-block]`），只存在一份：宽屏在 `<aside class="rail">`，窄屏由 JS 移进 `.sidebar`。
- **顺带修掉一个旧 bug**：`<footer class="page-nav">` 原本在 `.shell` 之外且宽屏 `margin-inline: 0`，与正文列严重错位 → 移进 `<main>` 内，并去掉其 max-width/inline padding。

**样式**（`tools/style.css`）
- 令牌 `--nav-w: 13rem`、`--rail-w: 14rem`；`.shell` max-width 仍 1240px。
- ≥1200px 三栏 `var(--nav-w) minmax(0,1fr) var(--rail-w)`；1080–1199px 两栏（右栏隐藏，正文 `margin: 0 auto` 居中）；<1080px 左栏变抽屉。
- `.rail` 默认 `display:none`，≥1200px 才 sticky；右栏条目行高收紧（`padding-block .27rem`、字号 .81/.77rem）。
- 踩坑：全局 `a { border-bottom: 1px solid ... }` 会渗进 `.toc-nav a` 与 `.brand`，导致大纲条目之间出现一排淡虚线；两处补 `border-bottom: 0`。

**交互**（`tools/app.js`）
- 新增「大纲归位」模块：`matchMedia('(min-width: 1200px)')` + `change` 监听，把 `[data-toc-block]` 在 `.rail` 与 `.sidebar` 之间 `append`；宽窄之间只搬一次 DOM，不存在两套大纲。
- 本页大纲标题补条目数（`<span class="cnt">36</span>`）。

**文档同步**：`AGENTS.md`（三栏骨架说明 + TIERS 唯一定义）、`design/styleguide.html`（左栏换成梯队目录、补右栏 rail、第 10 节改为本次布局调整说明、尾部 page-nav 移入 main）。

**验证方式**：无头 Chrome 分别按 1440 / 1140 / 880 三种宽度截图核对三栏、两栏、抽屉；深色主题单独注入 `data-theme='dark'` 截图；抽屉展开态靠注入脚本加 `.open`。

**工具踩坑（重要）**：对**同一个文件**并行发多个 Edit 会互相覆盖 —— 本次两条针对 `tools/style.css` 与 `tools/build_html.mjs` 的并行编辑被静默丢弃，导致 `.tier-title` 整段规则缺失、`shellHtml` 的 `rail` 参数没写进去，直到构建报错/截图才发现。以后同一文件的多次编辑必须串行，改完用 `grep` 或括号配平校验兜底。
