# 软考软件设计师自学项目

2026 年下半年软考中级·软件设计师的自学资料库。不依赖视频，以本仓库文件为唯一学习资料。

## 从哪里开始

1. 先看 [软件设计师考点大纲.md](软件设计师考点大纲.md) 了解整体考试结构和考点分布。
2. 进入 [软考学习/00-总览与进度.md](软考学习/00-总览与进度.md)，按进度表逐考点学习。

## 目录结构

```
├── README.md                    ← 本文件

└── 软考学习/
    ├── 00-总览与进度.md          ← TODO 进度表 + 学习方法（学习入口）

```

## 考试速览

- **考试时间**：2026 年 10 月 24—27 日，机考
- **科目**：基础知识（75 道选择题）+ 应用技术（案例大题），两科均 ≥45 分通过
- **学习顺序**：数据结构与算法 → 数据库 → 软件工程 → 面向对象/设计模式 → 操作系统 → 网络 → 程序语言 → 信息安全 → 计算机系统 → 知识产权 → 英语 → 数学与多媒体
