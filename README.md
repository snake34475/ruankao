## 让 AI 按考点出题

仓库内置了「考点出题」技能（[`.agents/skills/topic-quiz/`](.agents/skills/topic-quiz/SKILL.md)），可在 ZCode、Codex、WorkBuddy 里用同一套说法触发。对它说：

```
死锁请出题
SQL 分组 出题
考考我子网划分
```

它会从本仓库题库（课后题、案例题、精华题、补充题）抽出该考点的题组成一份卷子，**只给题目、不给答案，也不告诉你是哪一道原题**。你把答案发回来后，它批改、在对话里罗列错题与涉及的知识点，并把错题写入[错题本看板](interactive/mistake-book/index.html)（`app.js` 里的 `MISTAKES` / `WEAK`）。

## 网页阅读版

Markdown 源文件是唯一真源；课程既可使用单个 Markdown，也可使用“课程目录 + 子章节 Markdown”。构建时，`tools/prepare_vitepress.mjs` 从真源生成不提交的 `site-src/`，VitePress 再将网页写入 `docs/`。需要更新网页阅读版时运行 `npm run build`；开发预览用 `npm run dev`，验收构建产物用 `npm run preview`。未重新构建时，`docs/` 可能落后于 Markdown 真源。

阅读版使用 VitePress 文档主题：左侧按梯队列课程和章节，正文右侧显示本页大纲；窄屏使用目录抽屉。支持深浅色、站内搜索、代码复制、数学公式及本地学习状态标记；分章课程把答案放在独立页面，避免做题时误瞄。站点不依赖 CDN。离线双击 [docs/index.html](docs/index.html) 可读静态正文；搜索、学习状态等交互请通过 `npm run preview` 打开。

## 在线部署（GitHub Pages）

**本仓库已配置完成**，在线阅读：<https://snake34475.github.io/ruankao/>

`docs/` 是构建好的静态站点，Pages 直接发布该目录即可，不需要在 Pages 端运行构建。下面记录的是本仓库首次配置时的步骤；当前仓库无需重复建仓或配置：

1. 在 GitHub 新建一个仓库（建议 public），把本地仓库推上去；
2. 打开仓库 **Settings → Pages**；
3. *Source* 选 **Deploy from a branch**，*Branch* 选 **`main`**、目录选 **`/docs`**，保存；
4. 等 1～2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

几条要注意的：

- **要发布最新讲义时需构建并提交网页产物**：`npm run build` → 提交 `docs/` → 推送。GitHub 只发布推送到仓库的 `docs/` 内容，它不跑构建；只提交 Markdown 不会更新线上网页。
- **`docs/.nojekyll` 不要删**：它随 VitePress 静态资源生成并提交，用来跳过 GitHub Pages 的 Jekyll 处理。
- **本仓库配了两个远端**：`origin` 指向 Gitee、`github` 指向 GitHub。Gitee Pages 服务已下线，**在线可读的只有 GitHub Pages**，所以推送时两个远端都要推：

```bash
git push origin main    # Gitee → git@gitee.com:wang-tengyao/ruankao-software-designer.git
git push github main    # GitHub → git@github.com:snake34475/ruankao.git（Pages 从这个仓库的 /docs 发布）
```

> 平台政策会变，以官方通知为准。
