▸ 设计说明（交付编码阶段的规格）

1. 颜色映射（沿用讲义令牌，保证整体一致）

  • 前序 ① → --gold（金），语义：进入/起始，最醒目
  • 中序 ② → --accent（青），语义：主过程，与讲义主色统一
  • 后序 ③ → --red（红），语义：收尾/离开

2. 组件清单

  • 树区：边（.edge）+ 节点圆（.node-c，当前节点 .cur 描金边）+ 轮廓双路径（底图浅 + 进度青，stroke-dashoffset 描边动画）+ walker（金点 + 脉冲光晕）。
  • 节点状态灯网格：6 张卡，每张 3 盏灯（前/中/后），点亮态 .on + 脉冲动画；当前节点卡 .cur 描金边。
  • 步骤表：复用讲义表格样式；当前行 .is-active（左侧金条 + 淡金底）；前/中/后单元格命中态 .on-pre/.on-in/.on-post 着色。
  • 控制条：播放/暂停/重置/速度/步数徽标。

3. 动效规格（编码阶段由 app.js 驱动）

  • 轮廓描边：stroke-dasharray=pathLength，按步推进 stroke-dashoffset，实现"沿轮廓一笔画出"。
  • walker：用 path.getPointAtLength() 跟随进度定位，落到当前触碰点。
  • 状态灯/表格：随步号切换 .on 与 .is-active，命中单元格着色。
  • 步号 → (节点,状态) 映射见讲义 16 行表（本预览快照为第 7 步：E·前序）。

4. 联动（双向）

  • 自动播放：步 1→16 推进，同步 轮廓描边 + walker + 节点灯 + 表格高亮。
  • 表 → 动画：点击表格行 k，动画跳到步 k。
  • 动画 → 表：悬停/点节点，反查并高亮它的三行（如点 B → 高亮 2/6/10）。

5. 响应式 / 主题

  • 窄屏（≤880px）树区与表区上下堆叠；灯网格 ≤640px 变 3 列。
  • 深/浅双主题沿用讲义令牌，顶部按钮切换 data-theme。
  • 遵循 prefers-reduced-motion：关闭脉冲与描边动画。
