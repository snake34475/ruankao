5 · 表格（讲义最主要的信息载体）

常规对比表

对比项顺序存储（数组）链式存储（链表）
按位置访问第 i 个O(1) 直接算地址O(n) 要从头数过去
插入/删除一个元素O(n)（后面全要挪）O(1)（改指针即可）
空间需预估容量，可能浪费按需分配，但每节点多一个指针开销

宽表（窄屏可横向滚动）

排序法平均最坏空间稳定性课堂记忆点
快速排序O(n log₂n)O(n²)O(log₂n)不稳定枢轴归位后左右各自递归
堆排序O(n log₂n)O(n log₂n)O(1)不稳定建堆 + 反复取堆顶
归并排序O(n log₂n)O(n log₂n)O(n)稳定两两合并，需额外空间

处理：整表包在一张圆角卡片里，表头灰底、偶数行浅底、悬停整行高亮；窄屏时整块横向滚动，边框不会散架。注意：单元格内的 O(1)、log₂n 现在用等宽字体，数字能列对齐。

6 · 代码块与行内代码

算法填空常见代码

int partition(int[] a, int lo, int hi) {
    int pivot = a[lo];
    while (lo < hi) {
        while (lo < hi && a[hi] >= pivot) hi--;
        a[lo] = a[hi];
        while (lo < hi && a[lo] <= pivot) lo++;
        a[hi] = a[lo];
    }
    a[lo] = pivot;
    return lo;
}

复制按钮：鼠标移入代码块右上角出现「复制」，触屏设备常显（36px 触达区）。点击后变成「已复制」，1.6 秒回落。算法填空训练时要反复对照代码，这个按钮是刚需。
