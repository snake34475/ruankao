课后考题答案 ​

1. C n0 = n2 + 1 = 5 + 1 = 6。★ 必背结论。易错点：忘了 "+1"，或把度数为 1 的节点扯进来（不需要）。

2. A（后序 DEBCA） 前序第一个 A 是根；中序 DBE 在 A 左、C 在 A 右。左子树：前序 BDE + 中序 DBE → 根 B，中序中 D 在左 E 在右。后序 = 左(先D后E) → 右(C) → 根(A) = DEBCA。

3. C 循环队列用"牺牲一个单元法"时，front==rear 只表示空，满用 (rear+1)%m==front 判断。如果不牺牲单元，才需要额外标志位区分。C 的说法错在"既可以表示空也可以表示满"（在本题默认判满方式下）。

4. B 元素个数公式 (rear−front+m)%m，取模保证 front>rear（绕圈）时也算对。

5. A 合并：2+3=5 → {4,5,5} → 4+5=9 → {5,9} → 14。WPL = 2×3+3×3+4×2+5×1 = 6+9+8+5 = 28。 易错点：每次必须取当前最小的两个，合并后新权值要放回集合继续比。

6. B 哈夫曼树无度为 1 的节点，n0=n，n2=n0−1=n−1，总数 n+n−1=2n−1。

7. B 快排本身有序（正序或逆序）时枢轴划分极度不平衡，退化为 O(n²)。归并、堆排最坏仍 O(nlog₂n)。

8. A 一趟快排后，枢轴 49 必然到达最终位置：比 49 小的恰好有 3 个（38、13、27），所以 49 应落在第 4 位，且左边全是 <49、右边全是 >49。逐项检查：A ✓；B 中 76（>49）跑到 49 左边，✗；C 中 65（>49）在 49 左边，✗；D 中 49 还在第 2 位（未归位），✗。判别要点：枢轴归位 + 两侧大小关系，不必精确模拟每步交换（不同教材的一趟交换次序略有差异，但这条性质是唯一的）。

9. B 稳定的四个：直接插入、冒泡、归并、基数（口诀「插冒归基」）。

10. A 1000 顶点仅 10 条边 = 稀疏图，用邻接表省空间（O(n+e)）。三元组顺序表是稀疏矩阵的存储，不是图的。

11. C Dijkstra 每轮取当前距离最小者确定下来，是贪心。易混：Floyd（多源）是动态规划。

12. A 拓扑排序标准做法：取入度 0 顶点输出并删其出边。B 说反了（那是逆拓扑的一种做法：取出度 0 并删入边，得到的序列是逆拓扑序，作为"得到拓扑序列"的表述在考题中通常判错）。D 深度优先遍历的逆序其实可以得到一种拓扑序——但本题 D 表述为"不可行"，错误，故选 A。★ 这题故意做成双干扰，记住核心方法即可。

13. C 最多比较 ⌈log₂(n+1)⌉ = ⌈log₂1001⌉ = 10 次。

14. B ⌈log₂65⌉ = 7。易错点：别用 log₂64=6 就填 6，公式里要 n+1。（部分教材按判定树深度的定义对 n=2^k−1 型给出 k 次，64 个元素判定树深度为 7。）

15. C 必须缩短所有关键路径共同经过的关键活动才能缩短工期；只压缩一条关键路径上的活动无效。A、B、D 均正确。

精华题答案 ​

1. 前序 = ABCDEFGH，推导过程： 后序最后一个是 A → 根 A；中序 BDCE | AFHG → 左子树 {BDCE}，右子树 {FHG}。 左子树后序 DECB → 根 B；中序 BDCE 中 B 居首 → B 无左孩子，右子树 {DCE}；{D,C,E} 的后序（取原后序中对应段 D、E、C）→ 根 C；中序 D|C|E → D 是 C 的左孩子、E 是右孩子。 右子树后序 HGF → 根 F；中序 FHG 中 F 居首 → F 无左孩子，右子树 {HG}；后序 HG → 根 G，中序 H|G → H 是 G 的左孩子。 前序：A B C D E F G H（画出树形可验证：中序 B D C E A F H G ✓、后序 D E C B H G F A ✓）。

2. WPL = 33，各字符编码长度：a(5)=2 位、b(2)=3 位、c(3)=2 位、d(1)=3 位、e(4)=2 位 构造：1+2=3 → {3(新), 3(c), 4, 5} → 3+3=6 → {4, 5, 6} → 4+5=9 → {6, 9} → 15。 树形：15 根下左 6、右 9；6 的孩子是"节点(1+2)"和叶子 c(3)；9 的孩子是叶子 4 和 5；节点(1+2) 的孩子是 1 和 2。深度：a、c、e 在第 2 层，b、d 在第 3 层。 WPL = 5×2 + 2×3 + 3×2 + 1×3 + 4×2 = 10+6+6+3+8 = 33。 验算（哈夫曼树性质）：WPL = 所有非叶节点权值之和 = 3+6+9+15 = 33 ✓。易错点：合并后要永远挑当前最小的两个；本题 {3,3,4,5} 里挑的是两个 3，不是 3 和 4。

3. 插入过程（H(key)=key%7，线性探测）：

  • 15：15%7=1 → 放位置 1，比较 1 次
  • 22：22%7=1 → 冲突，探到 2 → 位置 2，比较 2 次
  • 8：8%7=1 → 冲突，2 冲突，探到 3 → 位置 3，比较 3 次
  • 29：29%7=1 → 冲突 ×3，探到 4 → 位置 4，比较 4 次
  • 36：36%7=1 → 冲突 ×4，探到 5 → 位置 5，比较 5 次 ASL(成功) = (1+2+3+4+5)/5 = 3。 这题展示的正是"同义词堆积"现象：全部 hash 到 1，线性探测让 ASL 恶化——考题常拿它对比链地址法。

4. 总工期 8，关键路径两条：V1→V2→V4→V5 和 V1→V3→V4→V5

  • ve（顺推取 max）：V1=0，V2=3，V3=2，V4=max(3+4, 2+5)=7（两条路径长度恰好相等），V5=7+1=8。
  • vl（逆推取 min）：V5=8，V4=8−1=7，V3=7−5=2，V2=7−4=3，V1=min(3−3, 2−2)=0。
  • 活动（e=起点的 ve，l=终点的 vl − 工期）：a1: e=0, l=3−3=0 → 余量 0；a2: e=0, l=2−2=0 → 余量 0；a3: e=3, l=7−4=3 → 余量 0；a4: e=2, l=7−5=2 → 余量 0；a5: e=7, l=8−1=7 → 余量 0。
  • 本例所有活动都是关键活动——因为两条路径长度同为 7，全都是关键路径，每个活动都在某条关键路径上。它演示了"缩短工期必须压缩所有关键路径的公共活动"：两条路径的公共活动只有 a5，只压 a1 或 a2 工期纹丝不动。
  • 做题教训：算 ve 时对每个入点都要取 max（这里 max(7,7) 很容易漏算成单边），每步动手验算。

5. 快速排序 第一趟后 25 在位置 4（最终位置），左侧 {20,15,21} 全 <25，右侧全 >25，且 84 也恰在末尾（本轮的边界比较把它交换到最右），符合快排一趟特征。

6. O(n log n) 外层 i*=2 执行 log₂n 次，内层 n 次，相乘得 O(nlog₂n)。易错点：外层不是 +1 而是 ×2，别答 O(n²)。

7. 共 2 种：ABCDE 和 ACBDE 分析约束：A 是唯一入度为 0 的顶点 → 必须最先；E 入度来自 D → 必须最后；B→D 和 C→D 都指向 D → D 必须排在 B、C 两者之后，而 B、C 之间无约束、可互换。于是 D 只能落在第 3 位（A 之后、B/C 之后），序列只有 A、{B,C 两种顺序}、D、E 一种骨架 → 2 种。若答 4 种，是漏了 C→D 这条边对 D 的约束（只看到 B→D 就以为 D 可紧跟 B）。

补充题答案（第三节 图 专项） ​

1【最小生成树】

  • (1) MST 权值和 = 10，选中的边：B-C 1、C-D 2、D-E 3、A-C 4。 Kruskal 过程（边按权从小到大排队）：B-C 1 ✔（不连通）→ C-D 2 ✔ → D-E 3 ✔ → A-C 4 ✔（A 还是孤点）→ B-D 5 ✘（B、D 已连通）→ A-B 6 ✘（A、B 已连通）→ C-E 7 ✘。 验算：4 条边 = 5 个顶点 − 1 ✓；覆盖全部 5 个顶点 ✓；无回路 ✓。 Prim 复核（从 A 出发）：A→C(4) → 经 C→B(1) → 经 C→D(2) → 经 D→E(3)，合计 4+1+2+3 = 10 ✓ 两个算法一致。
  • (2) A-B 权值 6 一定不选：A 和 B 已经通过 A-C-B 连通（4+1=5 < 6），再选 A-B 就形成了回路 A-B-C-A，而生成树不允许有回路。更本质的原因：MST 只要 n−1 条边，任何"两端已连通"的边都是多余的；而且就算比大小，走 A-C-B 只花 5、比 A-B 直接的 6 更省。（易错点：做题时只想着"6 比 1、2、3、4 大"是不够的，要养成"按权排序后逐条查环"的习惯。）

V3 是本题的关键一步：它有两条出边，各自给出一道"V3 最晚哪天必须发生"的上界——走 a4 到 V4，要求 V3 不晚于 9−2 = 7；走 a5 到 V5，要求 V3 不晚于 10−5 = 5。两条约束都要满足，所以取小的 5。若取 7 就错了：V3 真在第 7 天发生的话，a5 要到第 12 天才完工，而 V5 最晚只能第 10 天，整条链直接超期。 自检：vl(V1) = 0 ✓（源点逆推必须回到 0）

易错点：

  • a2 的 l 用的是终点 V3 的 vl（5−3=2），不要误用起点 V1 的 vl。
  • V3 的两条出边必须取 min（7 与 5 取 5）；这一步取错，后面所有活动的余量全歪。
  • 余量是按定义 l − e 算出的"这条活动自己的空隙"，不等于"可以无限晚开工"：若起点事件本身的余量更小，晚开工会被起点事件卡住（如 a4 的余量是 4，但它的起点 V3 只有 vl−ve = 5−3 = 2 天的余量）。考试按定义逐个填数即可，不必叠加。

5【关键路径 · 压缩工期】

  • (1) 总工期 = 11，关键路径唯一：V1 → V2 → V4 → V5；a2 的时间余量 = 2。 顺推求 ve（取 max）：ve(V1)=0，ve(V2)=6，ve(V3)=3，ve(V4)=max(6+3=9, 3+4=7)=9，ve(V5)=9+2=11。 逆推求 vl（取 min）：vl(V5)=11，vl(V4)=11−2=9，vl(V3)=9−4=5，vl(V2)=9−3=6，vl(V1)=min(6−6=0, 5−3=2)=0 ✓ 两条候选路线：V1→V2→V4→V5 = 6+3+2 = 11；V1→V3→V4→V5 = 3+4+2 = 9。最长的是前者，所以关键路径唯一。 a2 的 e = ve(V1) = 0，l = vl(V3) − 3 = 5−3 = 2，余量 = 2。 （顺带验算：a4 的余量 = (9−4) − 3 = 2，与 a2 相同——因为它俩都在同一条"次长"路线 V1→V3→V4 上，这条路线比关键路径短 11−9 = 2 天，正好差 2。）

  • (2) 总工期变成 9；关键路径变成 2 条。 a1 压到 4 天后重算 ve：ve(V2)=4，ve(V4)=max(4+3=7, 3+4=7)=7，ve(V5)=7+2=9。 此时 V1→V2→V4→V5 = 4+3+2 = 9，V1→V3→V4→V5 = 3+4+2 = 9，两条并列最长，所以关键路径有 2 条。

  • (3) 不能，总工期仍是 9。 把 a1 继续压到 3 天：ve(V2)=3，ve(V4)=max(3+3=6, 3+4=7)=7，ve(V5)=9。V4 的 ve 已由 a4 那条边（3+4=7）接管，不再由 a1 决定。 原因：总工期是"所有源点到汇点路线里最长的那条"。两条路线一样长时（都 9 天），只压其中一条，另一条立刻成为新的最长路线，工期纹丝不动。要降到 8 天，必须同时压缩两条路线上的活动（例如 a1 和 a4 各减 1 天：此时两条路线都是 3+3+2 = 8）。

应试提醒：题干出现"缩短工期／压缩活动工期"时，先数清关键路径有几条——只有一条，压它上面任一关键活动都有效；有多条，必须压所有关键路径的公共活动（本题 a5 就是公共的，压它一定有效，而 a1 不是），并且提防"压过头导致关键路径转移"。
