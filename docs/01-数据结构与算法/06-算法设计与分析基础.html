01.6 算法设计与分析基础 ​

6.0 先补两件基础：算法的五个特性、好算法的标准 ​

算法的五个特性（选择题原话考，五个字要背准）：

特性含义反例（哪个不满足）
有穷性执行有穷步之后必须结束"不断重复直到满足条件"若永不满足就不算算法
确定性每条指令含义唯一、无歧义x = 随机数 不算（结果不确定）
可行性每步都能用基本运算有限次实现"求 π 的精确值"不可行
输入有 0 个或多个输入"无输入的算法"是合法的（如打印一行字）
输出至少一个输出没有任何输出的不能叫算法

易错点：输入可以是 0 个，输出至少 1 个——这两个数字经常被互换着考。程序与算法的区别也只在这条：程序可以不满足有穷性（操作系统就是一个"永不结束"的程序），算法必须满足。

好算法的标准：正确性、可读性、健壮性（对非法输入能处理）、高效性（时间与空间）。题干问"评价算法优劣主要看什么"→ 正确性 + 效率。

6.1 五大算法策略（选择题常考"这是哪种策略"） ​

策略核心思想典型例子
分治法拆成互相独立的子问题，分别解再合并二分查找、归并排序、快排、汉诺塔、大整数乘法
动态规划子问题重叠，用表保存子问题的解（自底向上），要求最优子结构矩阵连乘、最长公共子序列、0-1 背包、LIS、Fibonacci
贪心法每步取当前最优，不回溯，不保证全局最优Prim、Kruskal、Dijkstra、哈夫曼、部分背包
回溯法深搜 + 试探 + 走不通就退回来（可剪枝）N 皇后、迷宫、子集和、图着色
分支限界广搜式搜索 + 用"界限"剪枝旅行商问题（TSP）

★ 动态规划 vs 分治：分治的子问题互相独立（算左边不用管右边）；动态规划的子问题重叠（同一个子问题会被反复用到），所以要用表存下答案避免重复计算。这也是 DP 比"朴素递归"快的唯一原因——比如求 Fibonacci，朴素递归是 O(2ⁿ)，加了记忆表就是 O(n)。 ★ 贪心 vs 动态规划：贪心只走一条路、走了不回头；动态规划考察所有子问题再取最优。所以贪心快但可能错，DP 稳但要多花空间。

动态规划的四个要件（题目问"能否用 DP"时拿这四条对）：最优子结构（大问题的最优解由小问题的最优解拼成）、重叠子问题、状态与状态转移方程、无后效性（当前状态一旦确定，不受后面怎么决策影响）。

下面把五个策略各配一个能亲手算的小例子，考试时要能"给代码说策略、给策略说思路"。

分治：汉诺塔（把"分治"算到底） ​

规则：n 个盘子从 A 柱移到 C 柱，一次只能挪一个，且任何时候大盘不能压在小盘上。

分治三步：

  1. 分：把"n 个盘子从 A 到 C"拆成三件事：先把上面 n−1 个从 A 挪到 B（中转柱）；
  2. 治：把最大的第 n 个盘从 A 直接挪到 C（就这一下）；
  3. 合：再把 B 上的 n−1 个挪到 C。

递推式：T(n) = 2·T(n−1) + 1，边界 T(1) = 1。

  • 代入算例：T(1)=1 → T(2)=2×1+1=3 → T(3)=2×3+1=7 → T(4)=15……
  • 通项：每次"翻倍再加一"，答案就是 T(n) = 2ⁿ − 1（n=3 时 7 ✓，n=4 时 15 ✓）。
  • 它说明什么：n=64 时约 1.8×10¹⁹ 次——指数级增长的可怕，这就是"O(2ⁿ) 不可做"的直观来源。选择题问"汉诺塔的时间复杂度"答 O(2ⁿ)。

动态规划：0-1 背包（把表亲手填一遍） ​

问题：背包容量 5，3 件物品（每件只能整个拿或不拿）：A 重 2 值 3、B 重 3 值 4、C 重 4 值 5。求能装的最大价值。

状态：dp[i][j] = 只考虑前 i 件物品、容量为 j 时的最大价值。 状态转移方程（★ 必背）：

dp[i][j] = max( dp[i-1][j] ,                    ← 不放第 i 件
                dp[i-1][j - w[i]] + v[i] )      ← 放第 i 件（前提：j ≥ w[i]）

含义："要么不要它（继承上一行同列），要么要它（腾出 w[i] 的容量，再加上它的价值）"——两者取大。

填表（行 = 只考虑前 i 件，列 = 容量 j 从 0 到 5）：

j=0j=1j=2j=3j=4j=5
i=0（无物品）000000
i=1（只有 A：w2 v3）003333
i=2（加入 B：w3 v4）003447
i=3（加入 C：w4 v5）003457

读答案：dp[3][5] = 7。 反向追出"拿了哪几件"（考点：DP 不只给数值，还能回溯方案）：

  • dp[3][5] = 7 等于 dp[2][5] = 7 → C（第 3 件）没拿；
  • dp[2][5] = 7 = dp[1][5−3] + 4 = 3 + 4 → 拿了 B；
  • dp[1][2] = 3 = dp[0][2−2] + 3 = 0 + 3 → 拿了 A。 → 最优方案 = {A, B}，重量 2+3=5 恰好装满、价值 7 ✓（与表格一致）

易错点：

  • 填表顺序是逐行从左到右（每格只依赖上一行和本行左边的格子），手算时别跳行。
  • j < w[i] 的格子不能"放"，只能继承上一行——初学者最爱在这里瞎算。
  • 时间复杂度 O(n·C)（物品数 × 容量），不是多项式时间里的"n 的多项式"（C 是数值，所以叫伪多项式）。
  • 0-1 背包的滚动数组写法：把二维压成一维 dp[j] 时 j 必须从大到小遍历（否则同一件物品会被重复拿，变成"完全背包"）。这个"从大到小"是案例题的高频空。

贪心：两个反例（说明"贪心为什么不一定最优"） ​

反例 1——找零钱：面额 {1, 3, 4}，要凑出 6。

  • 贪心的做法：每次拿不超过剩余金额的最大面额 → 拿 4 → 剩 2 → 拿 1 → 拿 1 → 3 枚。
  • 最优解：3 + 3 = 6 → 2 枚。贪心错了 ✓

反例 2——0-1 背包：容量 10，物品 A(重 8 值 80)、B(重 5 值 49)、C(重 5 值 49)。

  • 贪心按"单位价值"排：A 每单位 10 最高 → 先拿 A → 剩余容量 2，B、C 都放不下 → 总价值 80。（B 9.8、C 9.8）
  • 最优解：拿 B + C，重量 5+5=10，价值 49+49 = 98 > 80。贪心又错了 ✓

为什么"部分背包"贪心就对：如果物品可以切碎（比如装金粉），那容量 10 时拿 A(8) 后还能再装 2 单位的 B → 价值 80 + 49×2/5 = 99.6，反而超过了只拿 B+C 的 98，贪心确实最优。 结论（考点）：背包问题可以分割时用贪心，不可分割（0-1）时必须用动态规划。这一句是贪心与 DP 分界线的标准考法。

为什么 Prim/Kruskal/Dijkstra/哈夫曼贪心对：它们的问题结构有"拟阵"性质或特殊性质，能保证局部最优能拼出全局最优——考试不必证明，记住这四个是"贪心但正确"的就行。

回溯：N 皇后（DFS + 剪枝） ​

问题：n×n 棋盘放 n 个皇后，任意两个不同行、不同列、不同斜线。

回溯的骨架（一段伪代码背下来，案例题填空就是它）：

放第 row 行：
    for 每一列 col:
        若 (row, col) 不冲突:
            摆上皇后            ← 试探
            若 row == n: 输出一个解
            否则 放第 row+1 行   ← 递归深入
            撤掉皇后            ← 回溯（关键！恢复现场）
  • 试探 → 深入 → 撤回三步循环，就是"一条路走到黑，走不通退回来换条路"。
  • 剪枝：一旦当前摆法已经冲突，立刻停（不再往下递归），省掉整棵子树。剪枝越狠越快。
  • 4 皇后只有 2 个解（选择题考过"n=4 时解的数量"）；8 皇后 92 个解。
  • 回溯与图遍历的关系：回溯 = 在"状态空间树"上做 DFS。3.2 节的 DFS 是它在图上的特例，本节是它在"所有可能的选择组合"上的推广——所以两者都用递归 + 恢复现场。
  • 子集和问题：从一堆数里挑出若干使和 = 目标值；做法就是"每个数选择拿/不拿两分支"的 DFS，和 0-1 背包的搜索版同族。

分支限界 vs 回溯（一字之差） ​

回溯法分支限界法
搜索方式深度优先（一条路走到底）广度优先（一层层扩）
剪枝依据约束条件（不合法就停）界限函数（当前活结点若"不可能比已知最优更好"就砍）
目标找出所有可行解 / 任意一个解通常求最优解
典型N 皇后、迷宫、图着色旅行商问题（TSP）、0-1 背包最优化

记法：回溯很深、限界很广；回溯看"合不合法"、限界看"划不划算"。

延伸阅读：汉诺塔、0-1 背包、N 皇后的分步图示与代码见 hello-algo · 分治、动态规划、回溯（在线可看；离线不影响自足）。

6.2 时间复杂度（必考 1–2 题） ​

常见复杂度从小到大：O(1) < O(log n) < O(n) < O(nlog n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)

怎么"数"出来（不用背公式，数循环）：

  • 单层循环 n 次 → O(n)。
  • 两层嵌套、各 n 次 → 乘起来 O(n²)。三层 → O(n³)。
  • 循环变量每次 ×2 或 ÷2 → 只跑 log₂n 次 → O(log n)。例：for (i=1; i<=n; i*=2) 是 log₂n 次。
  • 一外一内：外 ×2 内 n → O(nlog n)（这就是归并/快排的来源）。
  • 递归：看递推式——T(n)=2T(n−1)+1（汉诺塔）→ O(2ⁿ)；T(n)=2T(n/2)+n（归并）→ O(nlog n)；T(n)=T(n/2)+1（二分）→ O(log n)。
  • 暴力枚举子集/全排列 → O(2ⁿ)、O(n!)。

对照表（考前扫一眼）：

代码特征复杂度
三条语句、无循环O(1)
for i=1..nO(n)
for i=1..n 套 for j=1..nO(n²)
while (i<n) i*=2;O(log₂n)
外层 i*=2、内层 j 跑 nO(nlog₂n)
汉诺塔 T(n)=2T(n−1)+1O(2ⁿ)

★ 渐近记号：O 是上界（增长率不超过 f(n) 的量级）、Ω 是下界、Θ 是精确界（上下界同阶）。选择题常考"O(f(n)) 的含义：增长率不超过 f(n) 的量级"。 易错点：O(2n) 就是 O(n)、O(n²+n) 就是 O(n²)——常数系数和低阶项都要扔掉，只留增长最快的项。

6.3 空间复杂度与递归 ​

  • 空间复杂度看的是额外开销：几个临时变量是 O(1)；开一个长度 n 的数组是 O(n)。
  • 递归的空间 = 递归深度 × 每层开销：快排平均递归深度 log₂n → 空间 O(log₂n)；最坏（已有序）深度退化为 n → 空间 O(n)（第 5.1 节的表里那一列就是这么来的）；归并排序要一个 n 长度的辅助数组 → O(n)。
  • 递归的两面：写起来简洁（树遍历、汉诺塔、回溯全靠它），代价是栈空间和函数调用开销。想改成迭代，就用自己维护的栈（3.2 节 DFS 的栈实现就是这个道理）。
  • 递归三要素（案例题挖空必考）：① 边界条件（什么情况下直接返回）；② 递推式（大问题怎么用小问题表达）；③ 返回值/现场恢复。缺边界条件 → 无限递归 → 栈溢出。

6.4 第六节小结与应试清单 ​

考点一句话抓手
算法五特性有穷、确定、可行、输入（0 个也行）、输出（至少 1 个）
五大策略分治（独立子问题）、DP（重叠子问题+最优子结构）、贪心（不回溯不保证最优）、回溯（深搜+剪枝）、分支限界（广搜+界限）
汉诺塔T(n)=2ⁿ−1，O(2ⁿ)
0-1 背包dp[i][j]=max(不放, 放)；滚动数组要倒着遍历 j
贪心边界可分割背包 → 贪心对；0-1 背包 → 必须 DP
复杂度数法嵌套相乘、倍增取 log、递推式看分治结构
复杂度记号O 上界、Ω 下界、Θ 精确界；常数与低阶项全扔

应试动作：

  • 案例题第 4 题（约 15 分）常给一段 DP 或回溯代码挖空。先看"状态定义"那句话（说明里一定有），空基本就在"初始化、转移方程、边界、返回"四处。
  • 手算纪律：DP 题填完表要反向追一次方案（像上面背包那样），能对上才算真懂；填表时按"逐行从左到右"一行行来，别跳。
  • 背什么：五个策略的"典型例子归属"（看到 Prim 就要能反应"贪心"）、汉诺塔 2ⁿ−1、背包转移方程、O/Ω/Θ 的含义。
