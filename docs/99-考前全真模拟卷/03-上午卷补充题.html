99.3 上午卷补充题

这 6 道题覆盖前文 75 题没考到、但属于高频考点的三块内容：数据结构（关键路径与散列表平均查找长度）、软件工程（逻辑覆盖强弱排序）、数学与多媒体（采样定理／颜色空间／JPEG 压缩流程）。同样建议限时作答，答案在文末"补充题解析"。

第一组　数据结构：关键路径与散列表 ASL ★★★

补充 1. 某 AOE 网（用边表示活动、顶点表示事件）中各活动持续时间为：1→2 为 4，1→3 为 3，2→4 为 5，3→4 为 6，3→5 为 2，4→5 为 3，2→5 为 4。则从起点事件 1 到终点事件 5 的关键路径长度（即工程的最短完工时间）为（ ）。

A. 10
B. 11
C. 12
D. 13

补充 2. 散列表长度为 10，散列函数 H(key)=key mod 7，采用线性探测法处理冲突。依次插入关键字 8、15、1、22、13 后，查找关键字 22 所需的比较次数为（ ）。

A. 2
B. 3
C. 4
D. 5

第二组　软件工程：逻辑覆盖强弱排序 ★★★

补充 3. 按覆盖标准的严格程度，从较弱到较强（条件覆盖认为不比判定覆盖强）排列逻辑覆盖，正确的顺序是（ ）。

A. 语句覆盖 → 判定覆盖 → 条件覆盖 → 判定/条件覆盖 → 条件组合覆盖 → 路径覆盖
B. 路径覆盖 → 条件组合覆盖 → 判定/条件覆盖 → 条件覆盖 → 判定覆盖 → 语句覆盖
C. 语句覆盖 → 条件覆盖 → 判定覆盖 → 条件组合覆盖 → 判定/条件覆盖 → 路径覆盖
D. 判定覆盖 → 语句覆盖 → 条件覆盖 → 条件组合覆盖 → 路径覆盖 → 判定/条件覆盖

第三组　数学与多媒体：采样定理、颜色空间、JPEG 步骤 ★★

补充 4. 以 8 kHz 的采样率对一段模拟信号采样。根据采样定理，为保证能从离散样本无失真地恢复原信号，原信号的最高频率不能超过（ ）。

A. 4 kHz
B. 8 kHz
C. 16 kHz
D. 2 kHz

补充 5. 视频传输与压缩中，把亮度与色度分离开（人眼对亮度更敏感），便于对色度成分进行更大程度压缩的颜色空间是（ ）。

A. RGB
B. CMYK
C. YCbCr（YUV）
D. Lab

A. DCT 变换 → 量化 → Z 字形扫描 → 熵编码
B. 量化 → DCT 变换 → 熵编码 → Z 字形扫描
