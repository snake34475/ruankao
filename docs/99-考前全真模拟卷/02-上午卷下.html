十二、专业英语（第 71–75 题） ​

Software architecture describes the major components of a system and the relationships among them. A good architecture makes important design decisions explicit and helps developers reason about quality attributes. For example, dividing a system into modules with high cohesion and low (71) can improve maintainability. When traffic grows, a scalable system can add resources to handle the increased (72). Reliability is also important: redundant components may allow a service to continue operating when one component (73). Security must be considered throughout development rather than added only at the end. Authentication verifies a user's identity, while authorization determines which resources the user is (74) to access. Finally, automated tests provide rapid (75) when a change breaks existing behavior.

B. recursion
C. bandwidth
D. inheritance

72.

B. workload
C. ciphertext
D. compilation

73.
A. fails
B. compiles
C. inherits
D. encrypts

74.

75.
