第一科逐题解析 ​

计算机系统基础 ​

1. A　负数补码求绝对值：10010110 按位取反为 01101001，加 1 得 01101010=106，所以原数为 −106。反向验证：+106=01101010，取反加 1 正好回到 10010110。D 是误按无符号数解释。

2. A　阶码位数决定可表示指数范围，尾数位数决定有效精度。甲阶码长、尾数短，因此范围更大、精度更低。口诀“阶范尾精”。

3. B　IR 保存当前指令；PC 保存下一条指令地址；MAR 保存要访问的主存地址；PSW 保存状态标志。“当前指令”是 IR 的识别词。

4. B　题目明确 100 ns 是未命中的完整时间，使用加权平均：0.95×10+0.05×100=9.5+5=14.5 ns。结果位于 10～100 ns 之间，合理。C 对应“先查 Cache，未命中再追加 100 ns”的另一种题意，本题不适用。

5. C　6000 RPM 一圈需要 60000/6000=10 ms，平均旋转等待为半圈 5 ms；平均存取约为 8+5=13 ms。D 错在加了整圈等待。

6. A　直接映射中每个主存块只能放到固定 Cache 行，最容易冲突但电路简单；全相联最自由、冲突最低、硬件最复杂；组相联折中。

7. C　冗余模块可靠度=1−(1−0.8)^2=1−0.04=0.96；再与 A 串联：0.9×0.96=0.864。反向检查：并联后高于 0.8，与 A 串联后低于 0.9，符合直觉。

8. B　r=3 时 2^3=8<8+3+1=12，不够；r=4 时 16≥8+4+1=13，所以至少 4 位。等号或大于均满足。

9. C　RISC 的典型特征是指令少而规整、寻址方式少、多寄存器、Load/Store 访存、常用硬布线并利于流水线。A、B、D 都更符合 CISC。

10. B　流水线周期为最长段 4 ns，第一条建立时间=2+3+4=9 ns，20 条总时间=9+(20−1)×4=85 ns。非流水时间为 20×9=180 ns，85 ns 小于它，合理。

程序设计语言基础 ​

11. A　词法分析把字符流切分并识别为 token；语法分析再检查 token 序列能否按文法组成表达式和语句。

12. B　括号匹配和表达式结构属于语法结构检查，由语法分析完成。词法分析只识别单词级记号。

13. B　正规式要求字符串由 a、b 构成并以 abb 结尾。baabb 满足；A 以 bba 结尾，C 以 bab 结尾，D 长度虽可但以 bbb 结尾。

14. B　传值时形参得到实参值的副本，修改形参一般不改变调用者变量本身。若值本身是对象引用，可能通过引用修改对象内容，但“把形参重新赋值”仍不等于改变调用者的引用变量；应服从题面语言语义。

15. C　解释执行通常边翻译边执行，不要求先生成完整目标程序；编译通常先把源程序整体转换为目标代码，再运行目标程序。A、D 把两者说反，B 把编译期和运行期错误混为一谈。

操作系统 ​

16. B　I/O 完成只表示等待条件消失，进程进入就绪队列；是否立即运行还取决于调度器，不能直接写运行态。

17. B　进入临界区前执行 P 申请互斥资源，退出后执行 V 释放资源。若顺序倒置，就不能阻止多个进程同时进入。

18. C　死锁四个必要条件是互斥、请求并保持、不可剥夺、循环等待。选项 C“可剥夺”恰好是否定了必要条件。

19. B　最不利时每个进程都占有 4−1=3 个资源，再多 1 个即可让某进程完成：3×(4−1)+1=10。用 9 个时可能三个进程各占 3 个并互等第 4 个；10 个时至少有一个能取得第 4 个，完成并释放。

20. B　4 KiB=2^12 B，低 12 位即后三个十六进制数 ABCH 为页内偏移；页号 5 换为物理块号 9，拼成 9ABCH。页内偏移在转换中不变。

21. C　前三次装入 1、2、3；再次访问 1 命中，但 FIFO 不改变进入先后；访问 4 时淘汰最早进入的 1，最终集合为 {2,3,4}。若是 LRU，命中 1 会更新近期性并淘汰 2。

数据结构与算法 ​

22. C　按栈计算：读到 6、2 后弹出二者做 6/2=3，再压入 3；读到下一个 3 后执行加法，得到 3+3=6。后缀表达式必须按“先弹出的是右操作数”计算。

23. B　元素数=(rear−front+10)%10=(7−2+10)%10=5。

24. C　二叉树边数既可写为 n−1，又可写为 n1+2n2；代入 n=n0+n1+n2 得 n0=n2+1。即叶子比双分支结点多 1。

25. A　前序首项 A 是根；中序把树分为左 DB、右 EC。左子树前序 BD，为 B 的左孩子 D；右子树前序 CE，为 C 的左孩子 E。后序是左 DB、右 EC、根 A，即 DBECA。

26. C　依次合并最小权：2+3=5，5+7=12，8+12=20。哈夫曼 WPL 等于所有非叶结点权值之和：5+12+20=37。按叶深复核：2、3 深 3，7 深 2，8 深 1，2×3+3×3+7×2+8×1=37。

27. A　无向边 {i,j} 同时使 A[i][j] 与 A[j][i] 有边，因此矩阵关于主对角线对称。无自环时对角线为 0，并非总为 1。

28. B　Dijkstra 用“已确定最短距离不会再被更小值推翻”的贪心性质，要求边权非负。含负权边时应考虑 Bellman-Ford 等算法。

29. C　拓扑排序不断删除入度为 0 的顶点；能包含所有顶点当且仅当图没有有向环，即图为 DAG。

30. B　100 个元素最坏比较次数为 ⌈log2(100+1)⌉=7。也可按判定树容量反查：6 次最多区分 2^6−1=63 个元素，不够；7 次最多 127 个，足够。

31. D　归并排序在相等关键字时先取左序列元素即可保持原相对次序，属于稳定排序。快速、堆、希尔通常不稳定。

32. D　当每次枢轴都造成极不平衡划分时，比较量为 (n−1)+(n−2)+…+1=n(n−1)/2，故最坏为 O(n^2)；平均通常为 O(n log n)。

软件工程基础 ​

33. B　原型模型用可运行原型帮助用户看到系统并反馈，适合需求不清。需求明确、变更少才更适合瀑布。

34. B　螺旋模型每一圈包含计划、风险分析、实施和客户评估，最突出的识别词是“风险分析”。

35. D　模块内所有成分为一个明确功能服务且不可或缺，是最强的功能内聚。顺序内聚要求前一步输出成为后一步输入，题干没有这种接力链。

36. D　直接进入另一个模块内部访问其数据或代码是最强、最差的内容耦合。共享全局数据区才是公共耦合。

37. C　V(G)=E−N+2=12−9+2=5。若画出的流程图有 4 个独立判定结点，也可用“判定结点数+1=5”交叉验证。

38. B　边界值分析关注合法边界及紧邻边界外的值，0、1、100、101 正好覆盖两个端点内外。A 缺少边界外值。

39. B　因外部运行环境（操作系统）变化而修改是适应性维护。修复已发生错误是改正性；扩功能是完善性；为防未来隐患是预防性。

40. C　第 4 级定量管理级以度量、统计和定量控制为关键词；第 5 级优化级强调持续过程改进与新技术反馈。

面向对象与设计模式 ​

41. A　封装把数据与操作组合并隐藏内部实现，通过公开接口使用。继承是复用父类特征，多态是同一消息产生不同响应。

42. B　同类中方法名相同、参数列表不同是重载，编译期按参数匹配；子类用相同签名替换父类实现才是重写。

43. B　顺序图以生命线和消息箭头表现对象交互，纵向体现时间先后。类图看静态结构，部署图看物理结点。

44. C　部署图描述软件制品/构件部署在哪些物理或执行环境结点上。构件图主要表现软件构件及依赖，不强调物理落点。

45. A　身份校验是每次提交订单都执行的必经行为，使用 <<include>>；箭头从基用例“提交订单”指向被包含用例“身份校验”。

46. B　“一族可互换算法、运行时选择”是策略模式。观察者处理一对多通知；适配器转换接口；单例保证唯一实例。

47. C　适配器把不兼容接口转换为客户期望接口。装饰器增加职责，代理控制访问，备忘录保存和恢复状态。

数据库系统 ​

48. B　内模式/物理存储变化不影响概念模式和应用，称为物理数据独立性；概念模式变化不影响外模式和应用才是逻辑数据独立性。

49. B　投影 π 选列，选择 σ 选行。口诀“σ 像筛子筛行，π 两条竖线切列”。

50. B　候选键 A 为单属性，不可能存在对键的部分依赖，所以满足 2NF；但 A→B→C 形成非主属性 C 对键 A 的传递依赖，不满足 3NF，最高为 2NF。逐级判断不能因看到冗余就退回 1NF。

51. B　AVG 在分组后计算，聚合结果的筛选必须用 HAVING。WHERE 在分组前筛选原始行，此时平均值尚未形成。

52. D　持久性要求已提交结果经受系统故障仍保留。原子性是全做或全不做，隔离性处理并发影响。

53. A　两段锁要求先处于加锁增长阶段，再处于解锁收缩阶段，可保证冲突可串行化；事务仍可能互持对方需要的锁而死锁。

54. C　故障恢复口诀：已提交事务 REDO，保证持久性；未提交事务 UNDO，保证原子性。

计算机网络 ​

55. B　传统交换机依据 MAC 地址转发帧，工作在数据链路层。路由器依据 IP 地址工作在网络层。

56. B　/27 留 5 位主机位，共 2^5=32 个地址；传统 IPv4 子网扣除网络地址和广播地址，可分配 32−2=30 个。

57. C　/26 每块 64 个地址，末字节网段起点为 0、64、128、192。130 落在 128～191，网络地址为 192.168.1.128。按位与掩码 255.255.255.192 也得 128。

58. C　DNS 默认端口 53；FTP 控制 21，SMTP 25，HTTP 80。DNS 常用 UDP，区域传送或较大响应等场景可用 TCP。

59. B　TCP 面向连接，提供可靠、有序、无重复的字节流，并具有确认、重传、流量与拥塞控制；UDP 无连接、尽力而为。

信息安全 ​

60. A　签名用发送者自己的私钥，验证用发送者公钥。口诀“私签公验”；接收者的密钥用于保密方向，不用于代表甲签名。

61. A　数字信封取长补短：用快速的对称密钥加密大数据，再用接收者公钥加密那把对称密钥，接收者用自己的私钥取出密钥。

62. B　Hash 摘要对修改敏感，主要用于完整性校验；它通常无密钥且不隐藏原文，不能单独提供机密性。

63. B　参数化查询把 SQL 结构与数据参数分离，配合输入校验可阻止恶意输入被解释成 SQL 代码。单纯改端口、加长密码不能修复字符串拼接漏洞。

标准化与知识产权 ​

64. B　GB 是国家标准代号，/T 表示推荐性，因此 GB/T 为推荐性国家标准。具体标准是否适用仍以现行正式文本为准。

65. A　根据《计算机软件保护条例》，合法软件复制品所有人为了防止复制品损坏，可在不经著作权人许可的情况下制作一份备份复制品，但不得再行复制，也不得用于营利或恶意传播。B 错在备份属于法定合理使用、无需书面许可；C 错在备份不以"删除原件"为条件；D 错在法律只许"一份"且不得对外传播。具体争议以现行法律和授权协议为准。

66. C　软件著作权保护程序及有关文档的具体表达，不垄断思想、处理过程、操作方法或数学概念本身。独立创作相同功能也不当然侵权。

数学与多媒体 ​

67. B　不区分职位，用组合：C(8,2)=8×7/(2×1)=28。若两个职位不同才用 A(8,2)=56。

68. B　全称命题“所有都通过”的否定是“至少一个不通过”。不需要所有都失败，只要存在一个反例即可推翻全称命题。

69. B　容量=800×600×24/8=1440000 B。第二种算法：24 bit=3 B/像素，像素数 480000，乘 3 仍为 1440000 B。C 是漏除以 8 的 bit 数。

70. B　容量=8000×8×1×10/8=80000 B。按每次采样 8 bit=1 B 复核：每秒 8000 B，10 秒 80000 B。

专业英语 ​

71. A — coupling　良好模块设计是 high cohesion and low coupling（高内聚、低耦合）。其他词分别是递归、带宽、继承。

72. B — workload　系统扩展资源是为了处理增长的工作负载，固定语义为 increased workload。

73. A — fails　冗余部件的目的，是一个部件失效时服务仍能继续；when one component fails 语法和语义都唯一成立。

74. A — permitted　authorization 决定用户被允许访问哪些资源，搭配为 be permitted to access。

75. A — feedback　自动测试在变更破坏既有行为时提供快速反馈，固定搭配 rapid feedback。

全文意译：软件体系结构描述系统主要构件及其关系。高内聚低耦合有助于维护；可伸缩系统通过增加资源应对负载；冗余提高可靠性；认证确认身份，授权决定访问权限；自动测试为破坏既有行为的变更提供快速反馈。

补充题解析 ​

补充 1. C（12）　求各事件的最早发生时间 ve（按拓扑序前推取最大）：ve(1)=0；ve(2)=0+4=4；ve(3)=0+3=3；ve(4)=max(4+5, 3+6)=max(9,9)=9；ve(5)=max(3+2, 9+3, 4+4)=max(5,12,8)=12。关键路径即 1→3→4→5（3+6+3=12），长度为 12。反向验证：1→2→4→5 为 4+5+3=12，同样是最长路径，两道最长路径一致印证 12 正确。D(13) 是把某些活动各加一误算。

补充 2. C（4）　线性探测依次定位：8 落位 1；15 落位 1 冲突→探测到 2；1 落位 1 冲突→探测 2、3；22 落位 1 冲突→探测 2、3、4（3 次冲突后再空位），共比较 4 次。反向验证成表 [—, 8, 15, 1, 22, —, 13]：查找 22 从位 1 起依次与 8、15、1、22 比较，共 4 次。顺带记住：该表查找成功的平均查找长度 ASL=(1+2+3+4+1)/5=2.2。

补充 3. A　由弱到强依次为：语句覆盖 < 判定覆盖 ≤ 条件覆盖 < 判定/条件覆盖 < 条件组合覆盖 < 路径覆盖。A 正确。B 是"强→弱"逆序；C 把判定与条件的先后写反；D 起始就错（判定覆盖应强于语句覆盖），且末尾漏了路径覆盖被放到倒数第二。口诀：语判条→加条（判定/条件）→组合→路径。

补充 4. A（4 kHz）　采样定理：采样率 fs 至少为信号最高频率 fmax 的 2 倍，即 fs≥2·fmax，反解得 fmax≤fs/2=8/2=4 kHz。B 是把 fs 直接当成 fmax；C/D 违背"采样定理采样率大约最高频率的两倍"。反向验证：对 4 kHz 信号确实至少需 8 kHz 采样才能复原 ✓。

补充 5. C（YCbCr/YUV）　人眼对亮度（Y）敏感、对色度（CbCr）迟钝，把二者分离后可在色度分量上抽稀压缩而不易察觉。RGB 是把三原色混在一起、彼此等权，不利于对人眼迟钝分量单独压缩；CMYK 面向印刷（青品黄黑油墨）；Lab 是设备无关色彩感知空间。

补充 6. A　JPEG 对 8×8 图像块的处理顺序：DCT 变换 → 量化（舍弃人眼不敏感的高频系数）→ Z 字形扫描（把系数按低频到高频重排，加长零游程）→ 熵编码（Huffman/算术编码）。答案 A。B 把量化和 DCT 对调、Z 字形与熵编码颠倒；C 整体逆序；D 把熵编码与量化位置互换——量化和熵编码都发生在扫描之后，不可能先熵编码再量化。
