补充 Passage B：Data Backup and Recovery（第 B1–B5 题）

Backup is the process of copying data to a secondary location so that it can be restored after loss or damage. A common strategy keeps several copies, because a single copy provides little (B1) against media failure. Backups may be full, incremental, or differential; an incremental backup stores only the data that has changed (B2) the previous backup, saving time and space. Because restoring from incremental backups may require many tapes, organizations often combine them with periodic full backups. To be dependable, a backup plan must run (B3) on a schedule, and the restored data must be periodically (B4) to confirm it can actually be used. Finally, copies should be stored off site so that they survive a fire or other (B5).
