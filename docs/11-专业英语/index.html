11 专业英语

分值地位：基础知识第 71–75 题通常固定为一篇 IT 主题英文短文、5 个完形填空，共 5 分（约占上午卷 6.67%）。它不单独对应下午案例大题，但题号固定、选项明确，是很值得争取的稳定分。

学习目标：学完本课后，你能——① 不逐字翻译也能快速判断短文主题；② 用“词性—搭配—逻辑—专业知识”四层筛选选项；③ 掌握软件工程、数据库、网络安全、云计算和 AI 的高频词；④ 避开 actual、execute、library、argument 等“看着眼熟却容易译错”的词；⑤ 在 5–7 分钟内完成一组 5 空专业英语题，并说出每个答案的文本依据。

第一部分 本课导航

1. 本章究竟考什么

专业英语不是单独考语法，也不是要求翻译整篇文章。它把三种能力揉在一起：

  1. 专业知识：知道 requirement、transaction、encryption、scalability 等概念；
  2. 英文搭配：知道 comply with、be responsible for、rather than 怎样搭配；
  3. 上下文推理：能根据因果、转折、同义复现判断空格含义。

常见主题包括：软件工程与测试、面向对象与设计模式、数据结构与数据库、操作系统与网络、信息安全，以及 cloud、AI、machine learning 等新技术。

2. 本章与已有课程的联动

英文题常常只是把你学过的中文结论换一种语言表达。例如：

  • high cohesion and low coupling = 高内聚、低耦合；
  • a transaction is atomic = 事务具有原子性；
  • only Load/Store instructions access memory = 只有 Load/Store 指令访存；
  • a digital signature provides authentication and non-repudiation = 数字签名提供身份认证和不可否认性。

所以专业英语的本质是：用英文识别熟悉的计算机知识，不需要把自己训练成文学翻译。

3. 建议得分目标与时间

当前基础 第一目标 做题时间
英语较弱 先保 3/5 7 分钟内
一般 稳定 4/5 5–6 分钟
较好 冲 5/5 4–5 分钟

做题顺序：先读本章解题法和词汇表，再做 3 篇课后完形，最后限时做精华题。
