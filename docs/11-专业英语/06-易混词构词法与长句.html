11.6 易混词、构词法、长句与考前速记 ★★★ ​

词在 IT 语境中的常见意思不要误译成
actual实际的当前的（current）
argument实参/参数；论点争吵
execute执行程序/指令处决
library程序库图书馆
issue问题；发布；议题只理解为“发行”
current当前的；电流实际的
support支持、兼容只理解为“扶着”
implement实现、实施工具（名词义很少用于题目）
instance实例；一次情况只理解为“例子”
object对象；目标物体
property属性财产
field字段；领域田地
record记录唱片
relation关系（数据库表）人际关系
interrupt中断打扰
address地址；处理/解决问题演讲
port端口港口
host主机主持人
thread线程线
token记号；令牌纪念品

另有四组必须分开：

  • adapt（适应/改造）与 adopt（采用）；
  • affect（通常作动词：影响）与 effect（通常作名词：效果）；
  • ensure（确保）与 insure（投保）；
  • complement（补充、补码）与 compliment（赞美）。

应试动作：不背孤立中文，要把词放回 IT 搭配中背，例如 execute an instruction、software library、address a security issue、database record。

第七节 构词法：不认识也能猜 ★★ ​

词缀含义例词
re-再次、返回retry, retransmit, recover
de-去除、反向decrypt, decode, deallocate
en-/em-使成为enable, encrypt, encapsulate
inter-之间interface, interaction, interoperability
intra-内部intranet
multi-多multitasking, multithreading
dis-否定、分离disconnect, disable
un-否定unauthorized, unavailable
-tion/-ment常构成名词authentication, management
-able/-ible可……的maintainable, compatible
-ity性质、状态reliability, availability

例：即使第一次见 interoperability，也可拆成 inter-（相互之间）+ operate（操作）+ -ability（能力），猜到“不同系统相互协作的能力”，即互操作性。

反例：构词法只能帮助猜范围，不能压过上下文。decomposition 中 de- 不是简单“不”，整体是“分解”；最终仍要代回句子验证。

应试动作：长词先拆前缀、词根、后缀，再结合主题判断。看到 -tion/-ment/-ity 先按名词处理，看到 -able 先按形容词处理。

第八节 长句拆解：只抓主干，不被修饰成分拖走 ★★ ​

专业短文常把条件、定语从句塞进一句话里。拆句只做三件事：找主语 S、谓语 V、宾语/表语 O/C。

例句：

A cache, which stores recently accessed data, reduces the time that the processor spends waiting for main memory.

先去掉两个修饰成分：

  • which stores recently accessed data 修饰 cache；
  • that the processor spends waiting for main memory 修饰 time。

主干只剩：A cache reduces the time.（Cache 减少时间。）

再把修饰补回：Cache 保存最近访问的数据，从而减少处理器等待主存的时间。

拆句的难点来自三类结构，下面把"最小语法"补一张四卡 + 三个示范，让你不必死记专业语法书。

8.1 四张最小语法卡 ​

卡①　五大基本句型：任何句子必有主语 S + 谓语 V，它是哪种句型看谓语后面还跟什么：

句型结构示例（先看 V 后有什么）
S+V主+谓The process runs. 进程运行。
S+V+O主+谓+宾The server sends a packet. 服务器发送分组。
S+V+C主+谓+表语The system is reliable. 系统是可靠的。
S+V+O+O主+谓+双宾语The cache gives the CPU data. 缓存把数据给 CPU。
S+V+O+C主+谓+宾+宾补We call this object an instance. 我们把这个对象称为实例。

判别口诀："先找 V（谓语），它后面有没有宾语 O，宾语后面是否还跟一个词/句说明 O（宾补 C）"。真题里出现频率最高的是 S+V+O 与 S+V+C（系动词 be 后接表语）。

卡②　被动语态 = be + 过去分词：主语是动作的承受者。抓法：is/are/was/were/has been/be + 过去分词（-ed 或不规则）。例：Data is transferred over the network.（数据被通过网络传输）。 反例：The file is downloading（下载中，现在进行，-ing）≠ The file is downloaded（已被下载，被动）。看到 be + ___ 的空格，选项里 -ed 与 -ing 二选一时，若主语承受动作就选 -ed。

卡③　分词作后置定语：名词后面直接跟短语修饰它，分词两兄弟分工明确：

  • 现在分词 -ing：表主动、正在进行（相当于 something that does…）→ the process running in background（正在后台运行的那个进程）；
  • 过去分词 -ed：表被动、已完成（相当于 something that is done）→ the data sent（被发送的那些数据）。

判别：看名词与动作的关系——名词主动去做用 -ing，名词被动承受用 -ed。反例：the data sending（数据在"主动发送别人"）是病句，数据是被发送的，应写 the data sent。

卡④　代词指代：it / they / which / that 往前找一个名词作指代对象。找法：向前找到最近的、单复数与代词一致的那个名词。 例：The client sends the request to the server, and it processes it. 两个 it 指不同对象——前一个 it 指 server（它处理请求），后一个 it 指 request。反例：硬把 it 指回句首 client，会误读成"客户端处理它自己发出的请求"。

8.2 三个难句拆解示范 ​

示范 1　被动句：The bandwidth of a link is shared by all active users. 拆：先找 be + 过去分词 = is shared，所以是被动句；主语是 The bandwidth，by 引出动作执行者 all active users。主干"带宽被所有活跃用户共享"，翻译别写成"带宽共享所有用户"。被动句的关键是分清承受者（主语）与执行者（by 后面的名词）。

示范 2　插入语（逗号夹层）：The server, after receiving the request, replies with the stored data. 拆：划掉逗号之间的插入 after receiving the request，主干 The server replies with the stored data.（服务器用存储的数据回复）；再把插入补回：服务器在收到请求之后回复。插入语不一定是定语，也可能是时间/伴随状语，先划掉再读主干最稳。

示范 3　代词指代（含对比）：Each thread shares the process's memory, whereas different processes do not; instead each process has its own address space. 拆：whereas 表对比，前半句主干 Each thread shares the memory（每个线程共享进程的内存），后半句 each process has its own address space（每个进程有它自己的地址空间）。its 指 each process，不要指回 thread。对比结构里，its/they 常指对比另一侧的名词，回看单复数与就近名词。

常见从句信号：

  • which/that/who：通常引出修饰前面名词的定语从句；
  • when/if/unless：条件或时间；
  • because/since：原因；
  • so that/in order to：目的；
  • while/whereas：对比。

反例：不要遇到 that 就翻成“那个”。在 the data that the client sends 中，that 只连接定语从句，整体是“客户端发送的数据”。

应试动作：长句先圈谓语动词，再找谁做这个动作。括号、逗号之间的插入说明可以暂时划掉，先读主干，再逐层加回。
