11.5 信息安全、云计算与 AI 词汇 ★★★

5.1 信息安全

English 中文 识别句
confidentiality 机密性 prevent unauthorized disclosure
integrity 完整性 prevent/detect unauthorized modification
availability 可用性 accessible when needed
authentication 身份认证 verify identity
authorization 授权 determine permitted actions
non-repudiation 不可否认性 prevent denial of an action
encryption / decryption 加密 / 解密 plaintext ↔ ciphertext
symmetric / asymmetric 对称 / 非对称 shared key / public-private key pair
hash / digest 哈希 / 摘要 fixed-length, one-way
digital signature 数字签名 private key signs, public key verifies
vulnerability / exploit 漏洞 / 利用漏洞的手段
threat / attack 威胁 / 攻击
intrusion detection 入侵检测 monitor suspicious activity

反例：authentication 回答“你是谁”，authorization 回答“你能做什么”。已经登录成功只说明通过认证，不代表有权访问所有资源。

5.2 云计算

English 中文
on demand 按需
resource pooling 资源池化
elasticity 弹性伸缩，随负载快速增减资源
scalability 可伸缩性，处理增长负载的能力
virtualization 虚拟化
virtual machine / container 虚拟机 / 容器
infrastructure/platform/software as a service IaaS / PaaS / SaaS
public/private/hybrid cloud 公有云 / 私有云 / 混合云
fault tolerance 容错
load balancing 负载均衡

三种服务模型用“谁管理得更多”来记：

  • IaaS：提供基础设施，用户还要管操作系统和应用；
  • PaaS：提供运行平台，用户重点管应用和数据；
  • SaaS：直接使用应用，提供商管理最多。

5.3 AI 与机器学习

English 中文 易混点
artificial intelligence 人工智能 大范围
machine learning 机器学习 从数据中学习模式
training / inference 训练 / 推理 learn parameters / make predictions
training set / validation set / test set 训练集 / 验证集 / 测试集 学习 / 调参 / 最终评估
feature / label 特征 / 标签 input property / target
supervised learning 监督学习 labeled data
unsupervised learning 无监督学习 discover structure without labels
classification / regression 分类 / 回归 离散类别 / 连续数值
overfitting / underfitting 过拟合 / 欠拟合 记住噪声 / 模型过于简单
generalization 泛化 对未见数据的表现
accuracy / precision / recall 准确率 / 精确率 / 召回率 三个指标不可混用

必背句：A model that performs well on training data but poorly on unseen data is overfitting（训练集好、陌生数据差，就是过拟合）。

应试动作：安全题先分“身份 authentication / 权限 authorization / 保密 confidentiality / 防篡改 integrity”；云题抓 on-demand, elasticity, service；AI 题抓 training, prediction, unseen data, overfitting。
