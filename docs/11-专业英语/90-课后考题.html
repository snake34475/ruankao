综合阅读题（不属于下午固定案例，用于训练长文理解）

Read the incident report and answer the questions in Chinese.

After a new version of an online ordering service was deployed, its response time increased sharply during peak hours. Monitoring data showed that CPU utilization remained moderate, but database latency rose as the number of requests increased. Engineers found that a frequently executed query scanned the entire Orders table because a useful index had been removed during migration. They restored the index and added the query to the regression test suite. Performance returned to normal. The team also updated its deployment checklist so that future schema changes would be reviewed before release.
