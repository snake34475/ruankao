04.9 精华题

  1. 【模式分类】将下列模式归类：Singleton、Factory Method、Prototype、Adapter、Bridge、Composite、Observer、Strategy、Command、Memento。

  2. 【模式识别】给下列场景选模式：① 棋类游戏中大量棋子只按"颜色+位置"区分，位置外提共享以省内存；② 网页图片未滚动到视口时不真正加载，滚动到才加载；③ 报销单提交后依次经过组长、经理、财务审批，任一环节可截住处理；④ 编辑器 Ctrl+Z 撤销上一步操作。

  3. 【UML 关系】区分下列类图关系：① 雁群与雁；② 鸟与翅膀；③ 汽车类的方法里临时 new 了一个引擎对象；④ 电动车型类实现了"可充电"接口。

  4. 【重载重写】某类有方法 f(int) 和 f(String)，另有子类重新定义了 f(int)。指出哪些是重载、哪些是重写，并用"哪个版本被执行"说明多态。

  5. 【状态图 vs 活动图】两图都画"圆角矩形+箭头"，如何快速区分一张图是状态图还是活动图？

  6. 【include/extend】某系统"发布文章"用例必然执行"保存草稿"，"定时发布"仅当用户勾选时发生。指出关系与箭头方向。

  7. 【OOD 原则】某系统原来在业务类中直接 new MySQLDao() 访问数据库，后来改为面向 IDao 接口编程、由配置文件决定注入哪个实现类。这一改造主要体现了哪一条面向对象设计原则？该原则的经典表述是什么？

  8. 【模式角色】某 Java 程序中有如下骨架：

abstract class Subject {
    private List<Observer> obs = new ArrayList<>();
    void attach(Observer o) { obs.add(o); }
    void detach(Observer o) { obs.remove(o); }
    void notifyObservers() { for (Observer o : obs) o.update(); }
}
class Clock extends Subject { /* 时间变化时调用 notifyObservers() */ }
interface Observer { void update(); }
class DigitalClock implements Observer { public void update() { /* 刷新显示 */ } }

指出这是哪种设计模式，并说明 Subject、Clock、Observer、DigitalClock 各对应模式中的哪个角色。

  1. 【多态分类】判断下列情形各属于哪种多态：① int a = 1; double b = a + 0.5;；② 同一个 add 方法名有 add(int,int) 与 add(String,String) 两个版本；③ 用 List<T> 编写的容器既能装整数也能装字符串；④ 父类引用 Shape s = new Circle(); 调用 s.draw() 执行圆的绘制。

  2. 【构件图/部署图】指出下列说法各对应哪种 UML 图：① 图中出现了立体长方体和 <<Database>> 构造型；② 图中一个构件用整圆标出对外提供的服务、用半圆标出需要的服务。
