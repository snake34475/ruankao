09.4 磁盘容量与存取时间 ★★★

6.1 容量计算

磁盘容量的通用形式：

容量 = 记录面数 × 每面磁道数 × 每磁道扇区数 × 每扇区字节数

注意“盘片数”不一定等于“记录面数”：一个盘片通常有两个面，但题目可能说明某些面不用。以题面为准。

例：磁盘有 4 个记录面，每面 2000 磁道，每磁道 100 扇区，每扇区 512 B：

容量 = 4×2000×100×512 = 409,600,000 B。

若按二进制 MiB 换算：409,600,000 / 2^20 = 390.625 MiB。

盘片数与记录面数算例：某磁盘有 3 张盘片，每张上下两面，但最上面和最下面两个外侧面不用来记录，因此记录面数不是 3×2=6，而是 6−2=4。若每面 1000 道、每道 50 扇区、每扇区 512 B，则容量：

4×1000×50×512 = 102,400,000 B。

题目若直接给“磁头数”，传统磁盘中通常可把有效磁头数视为记录面数；若同时给盘片数和记录面数，以明确给出的记录面数为准。

6.2 平均存取时间

磁盘存取时间 = 寻道时间 + 旋转等待时间 + 数据传输时间

  • 寻道：磁头移动到目标磁道；
  • 旋转等待：等目标扇区转到磁头下；
  • 传输：真正读写数据。

若转速为 RPM（转/分）：

  • 一圈时间 = 60 / RPM 秒 = 60,000 / RPM 毫秒；
  • 平均旋转等待 = 半圈时间 = 30,000 / RPM 毫秒；
  • 读 x 个连续扇区（每道 S 个扇区）的传输时间 = 一圈时间 × x/S。

例：7200 RPM，平均寻道 8 ms，每道 120 扇区，读取连续 3 扇区：

  1. 一圈 = 60,000/7200 = 8.333 ms；
  2. 平均旋转等待 = 8.333/2 = 4.167 ms；
  3. 传输 = 8.333×3/120 = 0.208 ms；
  4. 平均存取 = 8+4.167+0.208 = 12.375 ms。

反向验算：3 个扇区是 1/40 圈，所以传输时间应是一圈 8.333 ms 的 1/40，即约 0.208 ms。

连续与非连续存放：差别在于定位成本付几次

若多个扇区连续存放，通常只在开头付一次寻道和平均旋转等待，随后连续传输；若每个块随机散落在不同磁道位置，题目常按“每块都要重新定位”计算。

例：6000 RPM，平均寻道 5 ms，每道 100 个扇区，读取 4 个扇区。

  • 一圈时间：60000/6000=10 ms；
  • 平均旋转等待：10/2=5 ms；
  • 每扇区传输：10/100=0.1 ms。

若 4 个扇区连续：

T连续 = 5+5+4×0.1 = 10.4 ms。

若 4 个扇区分别随机位于不同位置，并假定每次都重新寻道、重新等待：

T非连续 = 4×(5+5+0.1) = 40.4 ms。

反向检查：非连续方案重复支付了 4 次定位成本，时间应明显大于连续方案。题目若说明“同一磁道但不连续”，则是否重复寻道要按题意调整，不能机械乘块数。

反例：把“7200 转/分”直接代成 1/7200 秒是错的，单位还在“分钟”；必须先乘 60 秒/分。平均旋转等待不是一整圈，而是半圈。

应试动作：容量题画四格乘法；时间题写“寻道+半圈+传输”。看到 RPM 先算一圈毫秒数，最后统一单位。
