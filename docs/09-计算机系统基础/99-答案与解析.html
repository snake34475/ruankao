09.10 答案与解析 ​

课后选择题答案 ​

1. A

11101100 是负数补码。求绝对值：整体按位取反得 00010011，再加 1 得 00010100=20，所以原数为 −20。反向验证：+20=00010100，取反加 1 得 11101100。B 少加/多减了 1；C 把无符号数 236 当答案；D 误把后 7 位直接当绝对值。

2. A

阶码位数决定范围，尾数位数决定精度。甲阶码长所以范围更大，尾数短所以精度更低。口诀“阶范尾精”。D 正好说反。

3. B

PC 保存下一条指令地址；IR 保存当前指令；MAR 保存主存地址；PSW 保存状态标志。题干“下一条”是 PC 的直接识别词。

4. C

时间局部性就是刚访问的内容短期内可能再次访问。A、B 把 SRAM/DRAM 说反：SRAM 不刷新，常作 Cache；DRAM 要刷新，常作主存。磁带是顺序存取。

5. B

单元数=5FFFH−2000H+1=4000H=2^14，按字节编址即 2^14 B=16 KiB。交叉检查：2000～2FFF、3000～3FFF、4000～4FFF、5000～5FFF 共 4 段，每段 1000H=4 KiB，总计 16 KiB。

6. B

题目明确 50 ns 是“未命中的完整访问时间”，用加权平均：0.9×5+0.1×50=4.5+5=9.5 ns。结果位于 5～50 ns 之间。不能再额外加一次 Cache 时间。

7. B

全相联映射允许主存块进入任意 Cache 行，冲突率最低；代价是比较范围最大、硬件最复杂。直接映射与之相反，组相联折中。D 不是 Cache 的标准映射方式。

8. C

6000 RPM 的一圈时间=60000/6000=10 ms，平均旋转等待为 5 ms。忽略传输时间，平均存取=7+5=12 ms。D 把整圈 10 ms 加了进去。

9. C

DMA 让外设与主存成批交换数据，由 DMA 控制器接管主要传输工作。查询/轮询让 CPU 忙等；中断虽不忙等，但数据搬运仍较多依赖 CPU。

10. B

中断向量给出中断服务程序入口地址或形成该地址的信息。它不是断点；断点是被中断程序恢复时继续执行的位置。

11. A

间接寻址先取 (120)=600 作为有效地址，再取 (600)=45 作为操作数。B 是立即寻址结果，C 是直接寻址结果。

12. D

“大量、复杂、变长、微程序”是 CISC 画像。RISC 通常指令规整、寻址少、多寄存器、Load/Store、硬布线并利于流水线。

13. C

最长段为 4 ns。理论时间=(2+3+4)+(10−1)×4=9+36=45 ns。非流水时间为 10×9=90 ns，45 ns 小于 90 ns，合理。B 是误用 n×4，漏掉建立时间。

14. C

并联系统可靠度=1−(1−0.8)^2=1−0.04=0.96。A 是误用串联；D 直接相加导致概率超过 1。

15. B

公式 2^r≥m+r+1，m=4。r=2 时 4＜7，不够；r=3 时 8≥8，刚好，所以至少 3 位。

综合计算题答案 ​

16. Cache 与磁盘综合题

（1）题目说先查 Cache，未命中再追加 92 ns，使用串行追加模型：

Tavg=8+(1−0.96)×92=8+3.68=11.68 ns。

第二种写法验证：命中路径 8 ns，未命中完整路径 8+92=100 ns，加权平均=0.96×8+0.04×100=7.68+4=11.68 ns，一致。

（2）容量：

6×4000×200×512=2,457,600,000 B。

换算为 MiB：2,457,600,000/1,048,576=2343.75 MiB。

反向分组：每道 200×512=102,400 B；共 6×4000=24,000 道；102,400×24,000=2,457,600,000 B，一致。

（3）10000 RPM：

  • 一圈=60000/10000=6 ms；
  • 平均旋转等待=6/2=3 ms；
  • 5 个连续扇区传输时间=6×5/200=0.15 ms；
  • 平均存取时间=4+3+0.15=7.15 ms。

交叉检查：5/200=1/40 圈，6 ms/40=0.15 ms。

17. 可靠性与校验综合题

（1）先算 B、C 并联：

RBC=1−(1−0.9)(1−0.9)=1−0.01=0.99。

再与 A 串联：R=0.95×0.99=0.9405。

合理性检查：并联模块 0.99 高于单件 0.9；串联 A 后 0.9405 低于 0.95。

（2）可用性：

A=MTTF/(MTTF+MTTR)=1990/(1990+10)=1990/2000=0.995=99.5%。

（3）1101 有 4 位，故 r=3。在信息 1010 后补 3 个 0：1010000。用 1101 做模二除法，余数为 001，所以：

  • CRC 校验位：001；
  • 发送码字：1010001。

反向验证：1010001 模二除以 1101，余数为 000。

扩充专项题答案 ​

1. B

移码由补码只翻转最高符号位得到：1101 → 0101。也可用偏置法验证：4 位偏置为 8，−3+8=5，5 的 4 位编码为 0101。A 是 +2 的普通二进制，C 是 +2 的移码，D 没有翻符号位。

2. B

尾数相加得 1.1000×2^3。右规时尾数右移 1 位、阶码加 1，得到 0.1100×2^4。数值复核：1.5×8=12，0.75×16=12。D 的尾数和阶码同时放大，数值翻倍。

3. B

单元数必须“末−首+1”：

DABFFH−B3000H+1=27C00H。

27C00H=162816 B，再除以 1024 得 159 KiB。D 把字节数错写成 KiB；A 通常来自漏算边界或十六进制借位错误。

4. C

直接映射先用行号锁定唯一 Cache 行，再比较标记，块内偏移选择块中具体字节，因此结构是“标记｜行号｜块内偏移”。A 是全相联的典型结构，B 是组相联。

5. D

6000 RPM 一圈 60000/6000=10 ms，平均旋转等待 5 ms，每扇区传输 10/100=0.1 ms。每个随机扇区耗时 5+5+0.1=10.1 ms，4 个共 4×10.1=40.4 ms。B 是把 4 个扇区误当连续存放，只付一次定位成本。

6. B

相对寻址 EA=(PC)+A=1000+(−20)=980。A 只取了位移，C 忽略位移，D 把负位移误当正 20。

7. C

RISC 与 CISC 都可以采用流水线。RISC 的指令常定长、格式规整、寻址方式少，各阶段时间更容易均衡，所以通常更适合高效流水化。“更适合”不能偷换成“只有它能”。

8. C

总设备小时为 500×2000=1,000,000 台·h。失效率：

λ=5/1,000,000=5×10^−6/h。

B 漏掉了一个数量级；A 没有用总设备小时作分母。

9. D

恒定修复率下 M(t)=1−e^(−t/MTTR)。代入：

M(4)=1−e^(−4/2)=1−e^(−2)≈1−0.1353=0.8647。

A 是“4 小时后仍未修好”的概率，不是已修好的概率。

10. A

检测 e 位需 dmin≥e+1，所以 e≤4；纠正 t 位需 dmin≥2t+1，所以 5≥2t+1，得 t≤2。因此最多保证检测 4 位、纠正 2 位。B 检测 5 位需码距至少 6；C 纠正 3 位需码距至少 7。

11. B

除数 1011 有 4 位，最高次数 r=3，所以信息后补 3 个 0。按模二除法：

1101 XOR 1011 → 1100 XOR 1011 → 1110 XOR 1011 → 1010 XOR 1011，

最终 3 位余数为 001。发送码字为 1101001，反除余数为 000。

12. C

收到 0110001 后：

  • 1、3、5、7 位共有 2 个 1，s1=0；
  • 2、3、6、7 位共有 3 个 1，s2=1；
  • 4、5、6、7 位共有 1 个 1，s4=1。

综合征 s4s2s1=110₂=6，指出第 6 位出错。翻回后得到原码字 0110011，三组校验均恢复为偶数。

精华题答案 ​

1. C

8 位补码范围为 −2^7～2^7−1，即 −128～127；最小值编码为 10000000。11111111 是 −1，不是最小值。补码负边比正边多一个数。

2. B

题目是“先查 6 ns，未命中后追加 94 ns”：

Tavg=6+(1−0.98)×94=6+1.88=7.88 ns。

路径加权复核：命中 6 ns，未命中总计 100 ns；0.98×6+0.02×100=5.88+2=7.88 ns。

3. C

字数扩展=32K/8K=4；位宽扩展=16/4=4；总片数=4×4=16。容量反验：16 片×8K×4 bit=512 Kbit；目标 32K×16 bit=512 Kbit。

4. C

12000 RPM 一圈=60000/12000=5 ms；平均等待=2.5 ms；读 2/100 圈=5×2/100=0.1 ms；合计 2.6 ms。B 漏了传输时间，D 使用了整圈等待。

5. B

中间两个 0.9 并联：1−0.1²=0.99。再与前后两个 0.9 串联：0.9×0.99×0.9=0.8019。原系统可靠度为 0.9³=0.729，改造后上升，且仍低于任一必经的 0.9，合理。

6. C

海明码通过多个重叠的奇偶校验组形成“错误位置编号”，可定位并纠正一位错。A 错：两位翻转可能让总体奇偶性不变；B 错：CRC 使用 XOR 的模二除法，无借位；D 错：余数为 0 只表示未检测到错误，不是数学上绝对无错，某些错误模式也可能漏检。

7. B

统一周期 Δt=5 ns，T=(k+n−1)Δt=(4+20−1)×5=115 ns。最大吞吐率=1/5 ns=2×10^8 个/秒。非流水时间=20×4×5=400 ns，115 ns 更小，符合流水线作用。
