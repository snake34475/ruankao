09 计算机系统基础

分值地位：基础知识选择题约 6–8 题，是单科里最稳定的计算题来源之一。★★★ 必会三类是 Cache 平均访问时间、磁盘容量/存取时间、串并联系统可靠性；补码、浮点数、寻址方式、RISC/CISC、校验码常以概念题或一步计算题出现。

学习目标：学完本课后，你能——① 在固定位数下写出原码、反码、补码、移码并判断溢出；② 解释浮点数“阶码定范围、尾数定精度”，完成对阶；③ 认清 CPU 部件、存储层次、总线、中断与 DMA；④ 独立算出 Cache 平均时间、主存容量、磁盘容量和平均存取时间；⑤ 区分 RISC/CISC 与常见寻址方式；⑥ 计算串联、并联、混联系统可靠度；⑦ 完成奇偶、CRC、海明码的典型题。

第一部分 本课导航

本章不单独对应下午案例大题，但它有一个特点：题型固定、公式短、计算可验算。学好后，上午卷的 6–8 分比背诵题更稳。

模块 常见考法 目标
数据表示 求负数补码、表示范围、浮点数对阶 会写、会判断
CPU 与存储 部件功能、局部性、RAM/ROM、主存编址 秒答概念题
Cache 平均访问时间、映射方式 必会计算
磁盘 容量、平均旋转等待、存取时间 必会计算
I/O、总线、中断 查询/中断/DMA；中断向量；三类总线 会按关键词归类
指令系统 寻址方式、RISC/CISC、流水线 会认题、会套公式
可靠性 串联、并联、混联、MTTF/MTTR/MTBF 必会计算
校验码 奇偶、CRC、海明码 理解原理并会一步计算

建议顺序：先读讲义，再不看答案做 15 道选择题和 2 道综合题，最后做精华题。计算题必须动笔，尤其注意单位统一。
