08.3 防火墙、常见攻击与恶意代码 ★★ ​

动机：加密和签名保的是"数据本身"，而防火墙保的是"网络边界"——像小区门禁，控制什么人能进、什么包能过。

6.1 防火墙是什么 ​

位于内部网络与外部网络（Internet）之间的屏障，按规则控制进出网络的数据包与流向，是内外网之间信息流的唯一通道。

6.2 两种常考类型 ​

对比项包过滤防火墙应用代理防火墙（应用网关）
工作层次网络层（有的含传输层）应用层
检查内容数据包的源/目的 IP、端口等头部信息具体应用协议的内容（如 URL、命令）
是否转发原始包直接放行/丢弃，内外直通内外不直通，代理替两头转接
优点快、开销小、透明安全控制粒度细、能审计内容
缺点看不懂应用内容，挡不住应用层攻击速度慢、每种协议要单独代理

（另有"状态检测"防火墙，跟踪连接状态，介于两者之间，选择题见过即可。）

同一句危险请求 GET /admin.php，穿过两种防火墙是两种命运——差别全在"它看包到哪一层"：

6.3 三种经典部署体系结构（补充，属认知拓宽，非真题高频） ​

体系结构特征一句话理解
双宿主主机（Dual-Homed Host）一台主机装两块网卡，分别接内网、外网，主机上关闭 IP 路由转发，成为内外网之间的唯一"闸门"一台"两头堵"的机器，掐断内外直连、全要靠它转
屏蔽主机（Screened Host）一台屏蔽路由器（包过滤）在外层先筛普通流量，另配一台堡垒主机负责接待必须进入内部的关键服务"路由在前粗筛 + 主机在后守关键服务"
屏蔽子网（Screened Subnet / DMZ 非军事区）内外网之间再用一道路由器隔出一段子网，把对外服务（Web、Mail）放在这中间缓冲带"两层路由夹一段缓冲子网，公网服务放中间的格子里"

直觉：这套体系是按"边界防御的层次"从单薄到周密排列的——一台机器当闸门（双宿主）→ 一层路由加一台主机（屏蔽主机）→ 两层路由夹一段缓冲子网（屏蔽子网/DMZ）。选择题若问"把对外服务器放在内外网之间的隔离缓冲区"指哪个，答屏蔽子网（DMZ）。

6.4 防火墙的"能与不能"（送分判断题） ​

能：控制进出数据包与流向；提供流量日志与审计；隐藏内部 IP 与网络结构细节（NAT）。

不能（真题三连）：

  • 不能防范内部人员的攻击（它在边界上，管不着墙内）；
  • 不能防范不经过它的连接（如内部拨号直连外网）；
  • 不能防病毒——它按 IP/端口/规则过滤，不做代码级查毒；"漏洞扫描"也不是它的功能。

6.5 入侵检测系统（IDS） ​

动机：防火墙是"门禁"，但进了门或绕过门的人干坏事谁盯着？入侵检测系统 IDS 监视网络/系统，发现可疑行为报警。

  • 定位：监测 + 告警，是防火墙之后的第二道防线；本身不负责拦截阻断（能主动阻断的是 IPS，入侵防御系统）。
  • 采集方式：从网络抓包分析（基于网络）或读主机审计日志（基于主机）。

应试动作：背"包过滤=网络层看头，应用代理=应用层看内容；防火墙不防内部、不防病毒、不管绕道的；IDS 只报警不拦截"。这三句覆盖本节所有真题考法。

第七节 常见攻击与恶意代码 ★★ ​

动机：前面学的都是"防御方"，本节换到"进攻方"视角——考场上给一段场景描述，让你指出"这是什么攻击"，认得出才能答对。

7.1 攻击类型认领表 ​

攻击场景特征（题干关键词）防御
重放攻击截获合法报文，事后原样重发骗系统（主战场是身份认证）时间戳、一次性口令/一次性令牌、挑战-应答、序列号
DoS/DDoS海量请求淹没服务器，耗尽带宽/连接资源，合法用户进不来（破坏可用性）；DDoS = 僵尸网络里成千上万台"肉鸡"同时发起流量清洗、限流、CDN 分散
SQL 注入在输入框/URL 参数里夹带 SQL 片段，骗数据库执行（如 ' or '1'='1 绕过登录）参数化查询（预编译语句）、过滤特殊字符、最小权限（联动 02-数据库系统.md）
钓鱼攻击仿冒官网/邮件诱骗用户主动交出账号密码核对域名、不点陌生链接
窃听/流量分析只监听不修改（被动攻击，见第一节）加密
伪装/假冒冒充合法用户或主机身份认证、数字签名
IP 欺骗伪造数据包的源 IP 地址，冒充可信主机（如内网地址）骗取对方信任认证、过滤可信源地址、加密
会话劫持中途插入/接管已建立的合法会话，冒充其中一方继续通信（常配合嗅探拿到会话标识）会话加密、会话标识随机化、超时注销
资源使用攻击（资源耗尽）占用服务器资源（连接数、内存、CPU）让合法请求没资源可用；DDoS 是其大规模化形态限流、连接数上限、负载均衡
后门 / 特洛伊陷阱攻击者事先在系统里留下隐蔽入口，随时绕过正常认证进入全面补丁、基线核查、最小权限、网络隔离

重放 vs DDoS 一句话分清：重放是"把旧的合法报文再发一遍"骗认证；DDoS 是"发海量的垃圾报文"拖垮服务。

7.2 恶意代码四兄弟（背区别） ​

名称定义要点区别关键
计算机病毒依附于宿主程序、能自我复制、破坏功能或数据的代码必须有宿主，靠寄生的程序/文件传播
蠕虫独立程序，利用系统漏洞自我复制、主动在网络传播不需要宿主、不需要人操作，自己爬
木马伪装成正常软件，隐藏在受害机器里开"后门"，供攻击者远程控制靠"伪装+远程控制"获利，不自我复制
逻辑炸弹平时潜伏，满足特定条件（日期、事件）时爆发破坏条件触发

记忆口诀："病毒寄生、蠕虫自爬、木马开门、炸弹看日子"。四者共同点：都是恶意代码；考场上抓题干关键词——"寄生在正常程序中"选病毒，"利用漏洞自主传播"选蠕虫，"远程控制/后门"选木马，"某日触发"选逻辑炸弹。

补充一个相关概念（DDoS 的"作案工具"）——僵尸网络：攻击者先用木马/蠕虫等手段批量感染大量主机，这些被控主机被称为"僵尸机/肉鸡"，它们组成的受控集群就叫僵尸网络（Botnet）。发起 DDoS 攻击时，攻击者只是向网络里的肉鸡群下达"同时向目标狂发请求"的命令——所以 DDoS 的流量面广、难以追溯到真凶。识别特征：题干说"攻击者控制了大量被入侵的计算机同时发起攻击"→ 僵尸网络。

防毒常识（顺带背）：不打开来历不明附件、及时打补丁、升级杀毒软件特征库、重要数据备份。
