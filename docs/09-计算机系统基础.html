09 计算机系统基础

分值地位：基础知识选择题约 6–8 题，是单科里最稳定的计算题来源之一。★★★ 必会三类是 Cache 平均访问时间、磁盘容量/存取时间、串并联系统可靠性；补码、浮点数、寻址方式、RISC/CISC、校验码常以概念题或一步计算题出现。

学习目标：学完本课后，你能——① 在固定位数下写出原码、反码、补码、移码并判断溢出；② 解释浮点数“阶码定范围、尾数定精度”，完成对阶；③ 认清 CPU 部件、存储层次、总线、中断与 DMA；④ 独立算出 Cache 平均时间、主存容量、磁盘容量和平均存取时间；⑤ 区分 RISC/CISC 与常见寻址方式；⑥ 计算串联、并联、混联系统可靠度；⑦ 完成奇偶、CRC、海明码的典型题。

第二部分 讲义（通俗讲解）

第一节 数据表示：机器怎样保存正负数 ★★★

1.1 为什么不能把负号直接存进去

计算机只保存 0 和 1，没有纸面上的“−”号，所以约定最高位为符号位：0 表示正，1 表示负。由此产生原码、反码和补码。

设机器字长为 n 位（含 1 位符号位）：

码制 正数 负数 n 位定点整数范围 0 的表示
原码 符号位 0，数值位为绝对值 符号位 1，数值位为绝对值 −(2^(n−1)−1)～+(2^(n−1)−1) +0、−0 两种
反码 与原码相同 符号位不变，数值位逐位取反 同原码 +0、−0 两种
补码 与原码相同 负数反码末位加 1 −2^(n−1)～2^(n−1)−1 只有一种
移码 补码的符号位取反 补码的符号位取反 数值范围同补码 只有一种

以 8 位机器数表示 −18：

  1. +18 的二进制绝对值是 00010010；
  2. −18 原码：10010010；
  3. −18 反码：符号位不动，其余取反 → 11101101；
  4. −18 补码：反码 + 1 → 11101110；
  5. −18 移码：补码符号位取反 → 01101110。

反例前置：不能把原码 10010010 整体取反再加 1 得到补码；整体取反会把符号位也翻掉。正确做法是“原码符号位不变，数值位取反，再加 1”。另一个更快的方法是：从原码最低位向左找到第一个 1，这个 1 及其右边不变，左边数值位取反，符号位仍为 1。

为什么日常运算用补码？因为补码能让减法变成加法，并把 +0、−0 合成一个。例如 4 位补码：0011（3）+ 1110（−2）=1 0001，丢弃最高进位后是 0001（1）。同一套加法器即可做加减。

1.2 范围与溢出

8 位补码范围的公式代入：

  • 最小值 = −2^(8−1) = −128；
  • 最大值 = 2^(8−1)−1 = 127。

口诀：补码范围“负边多一个”。10000000 在 8 位补码中是 −128，不是“负零”。

补码加法的溢出判据：同号相加，结果变号，发生溢出。

  • 01111111（127）+ 00000001（1）=10000000，两个正数加出负号 → 溢出；
  • 正数加负数不会因数值范围发生溢出。

应试动作：背“负数原码 → 数值位取反 → +1 得补码；移码只翻补码符号位；n 位补码范围 −2^(n−1)～2^(n−1)−1”。题目给二进制最高位为 1 时，先确认它问的是原码还是补码，不能见 1 就只写负号。

第二节 浮点数：用有限位数装下极大与极小的数 ★★

2.1 通用形式与分工

浮点数类似科学计数法：

N = M × R^E

  • M：尾数，保存有效数字，位数决定精度；
  • E：阶码，保存小数点移动距离，位数决定表示范围；
  • R：基数，二进制机器通常取 2。

例如二进制 101.101₂：

101.101₂ = 0.101101₂ × 2^3。

一般题目约定尾数用补码、阶码用移码；若题面另有约定，以题面为准。

2.2 规格化

同一个数可写成很多形式：0.1011×2^3、0.01011×2^4 数值相同，但后者浪费了一位有效精度。规格化就是让尾数的最高有效位尽快出现。

对二进制补码尾数，常用判断：

  • 正数规格化尾数形如 0.1xxx…；
  • 负数规格化尾数形如 1.0xxx…；
  • 即尾数符号位与其后第一位不同。

反例：把 0.001101×2^5 当作规格化数是错的，它前面有两个无效 0。左移两位、阶码减 2，得到 0.1101×2^3，数值不变，因为尾数乘了 2²，同时指数除以 2²。

2.3 浮点加减：先对阶，再运算，再规格化

机械步骤的动机：两把尺子的刻度不同不能直接相加，必须先把指数统一。

计算 0.1100×2^5 + 0.1010×2^3：

  1. 对阶：小阶向大阶看齐，阶差 5−3=2；
  2. 小数尾数右移 2 位：0.1010×2^3 = 0.001010×2^5；
  3. 尾数相加：0.110000 + 0.001010 = 0.111010；
  4. 结果：0.111010×2^5，已规格化。

为什么只让小阶向大阶看齐？若把大阶尾数左移，可能迅速越出尾数字段；小阶尾数右移虽然可能损失低位精度，但不会把整数部分挤爆。

浮点异常：阶码超过上限是上溢；太小而无法表示是下溢。尾数右移时被舍弃的低位会造成精度损失。

应试动作：背“阶码定范围，尾数定精度；小阶向大阶看齐；对阶—尾数运算—规格化—舍入”。题目比较两种格式时，只看谁的阶码长、谁的尾数长即可。

第三节 CPU：谁计算，谁指挥 ★★

CPU 主要由运算器、控制器、寄存器组和内部总线组成。

部件 作用 关键词
ALU（算术逻辑单元） 做算术与逻辑运算 真正“算”
AC（累加寄存器） 暂存操作数和运算结果 ALU 工作区
DR/MDR（数据缓冲寄存器） 暂存从主存读出或要写入主存的数据 数据中转站
PSW（程序状态字） 保存零、进位、溢出、中断允许等状态 状态标志
PC（程序计数器） 保存下一条要取的指令地址 下一条在哪
IR（指令寄存器） 保存当前正在执行的指令 当前是什么
MAR/AR（地址寄存器） 保存当前访问的主存地址 去哪里读写
指令译码器 解释操作码 要做什么
时序部件 发出有先后次序的控制信号 什么时候做

指令周期通常经历：取指 → 分析/译码 → 执行。冯·诺依曼机的指令和数据都以二进制存入同一存储器，CPU 不是靠“长相”区分它们，而是靠所处的指令周期阶段：取指阶段读到的是指令，执行阶段按指令要求读到的是数据。

反例：“PC 保存当前指令”是错的。当前指令在 IR，PC 通常已经指向下一条指令。“地址寄存器保存数据”也错，MAR 保存地址，MDR 保存数据。

3.1 常见性能指标

  • 时钟周期 T = 1 / 主频 f；
  • CPI = 总时钟周期数 / 指令条数；
  • CPU 执行时间 = 指令条数 × CPI × 时钟周期；
  • MIPS = 主频 / (CPI × 10^6)，主频单位为 Hz；
  • 带宽 = 数据量 / 传输时间。

例：某处理器主频 2 GHz，平均 CPI=4，执行 5×10^8 条指令：

CPU 时间 = 5×10^8 × 4 / (2×10^9) = 1 s。

反向验算：2 GHz 在 1 秒内给出 2×10^9 个周期；5×10^8 条×4 周期/条也正好是 2×10^9 个周期。

应试动作：看到“下一条地址”选 PC，“当前指令”选 IR，“算术逻辑”选 ALU，“主存地址”选 MAR，“主存数据”选 MDR。性能计算先统一 Hz、秒、Byte/bit。

第四节 存储体系与主存编址 ★★★

4.1 为什么分层

理想存储器要又快、又大、又便宜，但现实中三者不能同时满足，所以按层次组合：

寄存器 → Cache → 主存 → 外存

从左到右：速度变慢、容量变大、每位成本降低。分层能奏效，是因为程序具有局部性：

  • 时间局部性：刚访问过的内容很快又访问，如循环中的指令；
  • 空间局部性：访问某地址后很快访问邻近地址，如顺序扫描数组。

4.2 常见存储器

类型 特点 常见用途
SRAM 不需刷新、快、贵、集成度低 Cache
DRAM 需刷新、较慢、便宜、集成度高 主存
ROM 断电不丢，通常只读 固件
EEPROM 可电擦写，常按字节操作 配置数据
Flash 电擦写，通常按块擦除 SSD、U 盘
相联存储器 按内容检索 Cache/TLB 中的快速匹配

反例：RAM 的“随机”不是说数据随机，而是任一地址的访问时间近似相同。磁盘是直接存取，不是严格随机存取；磁带才是典型顺序存取。

4.3 主存编址与芯片扩展

通用形式：

  • 存储单元数 = 最大地址 − 最小地址 + 1；
  • 总容量 = 存储单元数 × 每单元位数；
  • 所需芯片数 = 总容量 / 单片容量；
  • 若位宽和字数都要扩展：芯片数 = 字数扩展倍数 × 位数扩展倍数。

例：地址 4000H～7FFFH 按字节编址：

单元数 = 7FFFH − 4000H + 1 = 4000H = 2^14 个字节，容量 = 16 KiB。

若用 4K×8 bit 芯片组成 16K×16 bit 存储器：

  • 字数扩展：16K/4K=4；
  • 位宽扩展：16/8=2；
  • 总片数：4×2=8 片。

反向验证：8×4K×8 bit = 256 Kbit；目标 16K×16 bit = 256 Kbit，容量相等。

应试动作：地址范围一定写“末−首+1”；先看“按字节还是按字编址”；芯片题分别算字数倍数和位宽倍数，不能只拿总 bit 相除后就结束——虽然片数可能相同，但连接方式还要分组。

第五节 Cache：用小而快的存储器挡住慢主存 ★★★

5.1 原理与命中率

Cache 保存近期最可能再次使用的主存块。CPU 要数据时先查 Cache：找到叫命中，找不到叫未命中，再访问主存。主存与 Cache 的地址映射由硬件自动完成。

命中率 h = 命中次数 / 总访问次数；未命中率 = 1−h。

5.2 平均访问时间：先判断题目的时间定义

考试常见两种模型，差别在“未命中时是否已花过一次查 Cache 的时间”。

模型 A：题目直接给命中时间 tC、未命中访问时间 tM

Tavg = h×tC + (1−h)×tM

例：h=95%，命中 10 ns，未命中 100 ns：

Tavg = 0.95×10 + 0.05×100 = 9.5+5 = 14.5 ns。

模型 B：先查 Cache，未命中后还要追加访问主存

Tavg = tC + (1−h)×tM

例：查 Cache 10 ns，主存 100 ns，h=95%：

Tavg = 10 + 0.05×100 = 15 ns。

两者为何不同？模型 A 的“100 ns”已被题目定义为未命中的完整时间；模型 B 的“100 ns”只是追加的主存时间。不要脱离题干死背一种公式。

反向范围检查：平均时间必须落在快路径与慢路径之间。模型 A 的 14.5 ns 在 10～100 ns 之间；若算出 4.5 ns，必错。

5.3 三种映射

映射方式 一个主存块可放哪里 冲突率 硬件复杂度
直接映射 唯一固定行 高 低
全相联映射 任意一行 低 高
组相联映射 固定组内任意一行 中 中

口诀：直接最死板，全相联最自由，组相联折中。全相联自由度高，但必须同时比较多个标记，硬件复杂。

应试动作：Cache 题先圈出“命中时间/主存时间/未命中总时间”字样再选模型；答案必须做范围检查。映射题背“冲突率：直接＞组相联＞全相联；复杂度反过来”。

第六节 磁盘：容量与时间是两套公式 ★★★

6.1 容量计算

磁盘容量的通用形式：

容量 = 记录面数 × 每面磁道数 × 每磁道扇区数 × 每扇区字节数

注意“盘片数”不一定等于“记录面数”：一个盘片通常有两个面，但题目可能说明某些面不用。以题面为准。

例：磁盘有 4 个记录面，每面 2000 磁道，每磁道 100 扇区，每扇区 512 B：

容量 = 4×2000×100×512 = 409,600,000 B。

若按二进制 MiB 换算：409,600,000 / 2^20 = 390.625 MiB。

6.2 平均存取时间

磁盘存取时间 = 寻道时间 + 旋转等待时间 + 数据传输时间

  • 寻道：磁头移动到目标磁道；
  • 旋转等待：等目标扇区转到磁头下；
  • 传输：真正读写数据。

若转速为 RPM（转/分）：

  • 一圈时间 = 60 / RPM 秒 = 60,000 / RPM 毫秒；
  • 平均旋转等待 = 半圈时间 = 30,000 / RPM 毫秒；
  • 读 x 个连续扇区（每道 S 个扇区）的传输时间 = 一圈时间 × x/S。

例：7200 RPM，平均寻道 8 ms，每道 120 扇区，读取连续 3 扇区：

  1. 一圈 = 60,000/7200 = 8.333 ms；
  2. 平均旋转等待 = 8.333/2 = 4.167 ms；
  3. 传输 = 8.333×3/120 = 0.208 ms；
  4. 平均存取 = 8+4.167+0.208 = 12.375 ms。

反向验算：3 个扇区是 1/40 圈，所以传输时间应是一圈 8.333 ms 的 1/40，即约 0.208 ms。

反例：把“7200 转/分”直接代成 1/7200 秒是错的，单位还在“分钟”；必须先乘 60 秒/分。平均旋转等待不是一整圈，而是半圈。

应试动作：容量题画四格乘法；时间题写“寻道+半圈+传输”。看到 RPM 先算一圈毫秒数，最后统一单位。

第七节 I/O 控制、中断与总线 ★★

7.1 CPU 怎样与外设交换数据

方式 谁盯设备 CPU 负担 适用特点
程序查询 CPU 反复查询 最大，忙等 简单、低速
中断 设备就绪后通知 CPU 不必忙等，但每次传送仍需 CPU 处理 低中速、事件驱动
DMA DMA 控制器在主存与外设间成批传送 很小，CPU 只做初始化与结束处理 高速、批量
通道/I/O 处理机 专用部件执行 I/O 程序 更小 大型系统、多设备

DMA 的关键不是“完全不经过主存”，恰好相反，它让外设与主存直接成批交换数据，只是在传送期间暂时取得总线控制权，减少 CPU 逐字搬运。

7.2 中断过程

简化顺序：

  1. 设备发出中断请求；
  2. CPU 通常在当前指令执行完后响应；
  3. 保存断点和现场；
  4. 根据中断向量找到中断服务程序入口；
  5. 执行中断服务程序；
  6. 恢复现场，返回原程序。

中断向量 = 中断服务程序的入口地址（或形成入口地址的信息）。断点是原程序被打断后应继续执行的位置，二者不是一回事。

7.3 总线分类

按传送内容：

  • 数据总线：传数据，通常双向；
  • 地址总线：传地址，通常由 CPU 向外，宽度决定可寻址空间；
  • 控制总线：传读/写、中断、总线请求等控制信号。

若地址总线有 32 根，按字节编址，可寻址单元数为 2^32，空间为 2^32 B = 4 GiB。

按范围可分芯片内总线、系统总线、外部/通信总线；按传送方式可分串行和并行。并行不是永远更快：线路较长、频率较高时，多根线的时序偏差和串扰会限制速度，现代高速外设常用高速串行链路。

应试动作：题干出现“CPU 忙等”选查询，“设备通知 CPU”选中断，“主存与高速外设批量直传”选 DMA。“中断服务入口”选中断向量；地址线 n 根、按字节编址就写 2^n B。

第八节 指令、寻址方式与 RISC/CISC ★★★

8.1 寻址方式：指令里的地址字段究竟装了什么

设指令地址字段为 A，寄存器 R 的内容记为 (R)，主存单元 A 的内容记为 (A)，EA 为有效地址。

寻址方式 操作数/有效地址 一句话识别
立即寻址 操作数 = A 指令里就是数
直接寻址 EA=A，操作数=(A) 指令里是一次地址
间接寻址 EA=(A)，操作数=((A)) 先从内存取地址，再取数
寄存器寻址 操作数=(R) 寄存器里就是数
寄存器间接寻址 EA=(R)，操作数=((R)) 寄存器里是地址
相对寻址 EA=(PC)+A 相对当前程序位置
基址寻址 EA=(基址寄存器)+A 基地址加偏移
变址寻址 EA=A+(变址寄存器) 数组首址加下标

例：A=100，(100)=500，(500)=36：

  • 立即寻址得到 100；
  • 直接寻址得到 500；
  • 间接寻址得到 36。

反例：直接寻址不是“直接拿到操作数”，而是直接拿到操作数的地址；真正把操作数写在指令中的是立即寻址。寄存器间接寻址也不是操作数在寄存器，而是操作数的地址在寄存器。

一般速度印象：立即/寄存器最快，涉及主存次数越多越慢；但具体排序要看题目的体系结构定义。

8.2 RISC 与 CISC

对比 RISC（精简指令集） CISC（复杂指令集）
指令数量与格式 少、格式较规整/常定长 多、常变长
寻址方式 少 多
单条指令 功能较简单，多数可快速完成 功能复杂，周期差异大
访存 Load/Store：通常只有装入/存储指令访问内存 多种指令可直接访问内存
寄存器 通用寄存器多 相对较少
控制实现 常用硬布线，利于流水线 常用微程序控制
编译器 更依赖优化编译 指令本身表达力强

反例：“RISC 指令少，所以程序一定更短”是错的。完成同一复杂任务，RISC 可能需要更多条简单指令；它追求的是规则、快速、易流水化，不是源程序或机器码条数必然更少。

口诀：RISC：少、齐、快，多寄存器，Load/Store，硬布线，爱流水；CISC 反过来。

应试动作：题干出现“定长、少寻址、多寄存器、Load/Store、硬布线、流水线”就锁定 RISC；“复杂指令、多寻址、可变长、微程序”锁定 CISC。

第九节 流水线：像工厂一样重叠执行指令 ★★

若一条指令分成 k 段，各段时间为 t1、t2…tk，流水线周期 Δt = max(ti)。执行 n 条指令的理论时间：

T = (t1+t2+…+tk) + (n−1)×Δt

若题目按每段都取统一周期，实践公式：

T = (k+n−1)×Δt

例：取指 2 ns、译码 3 ns、执行 4 ns，执行 100 条：

  • 建立时间 = 2+3+4=9 ns；
  • 周期 Δt=4 ns；
  • T=9+(100−1)×4=405 ns。

不用流水线需 100×9=900 ns，所以确实加速。稳态最大吞吐率：

TPmax = 1/Δt = 1/4 ns = 2.5×10^8 条/秒。

反例：不能把流水线时间算成 n×最长段时间就直接结束，这漏掉了第一条指令把流水线“灌满”的建立时间。题目若明确采用统一时钟周期，才用 (k+n−1)Δt。

应试动作：先圈最长段求周期，再写“第一条完整时间+(n−1)周期”；用结果必须小于非流水时间做合理性检查。

第十节 系统可靠性：每个部件可靠，不等于组合后可靠 ★★★

可靠度 R(t) 是系统在规定条件和时间内无故障运行的概率。

10.1 串联、并联、混联

串联系统必须所有部件都正常：

Rs = R1×R2×…×Rn

两个可靠度均为 0.9 的串联系统：Rs=0.9×0.9=0.81。串联环节越多，整体可靠度通常越低。

并联系统只要至少一个正常：

Rp = 1−(1−R1)(1−R2)…(1−Rn)

两个可靠度均为 0.9 的并联系统：Rp=1−0.1×0.1=0.99。

这个公式来自反面事件：“全部失效”的概率是失效率相乘，再用 1 减掉。反例：并联可靠度不能直接写 R1+R2=1.8，概率不可能超过 1。

混联系统先识别局部串/并联，算成一个等效模块，再向外算。例如 A（0.9）与由 B、C（各 0.8）组成的并联模块串联：

RBC=1−(1−0.8)^2=0.96；总可靠度=0.9×0.96=0.864。

反向检查：并联模块 0.96 应高于单件 0.8；与 A 串联后 0.864 应低于 A 的 0.9，符合直觉。

10.2 MTTF、MTTR、MTBF 与可用性

  • MTTF：平均无故障时间；
  • MTTR：平均修复时间；
  • 对可修复系统，一个“正常+修复”周期常写 MTBF = MTTF + MTTR；有些资料把 MTBF 近似当作相邻故障间的正常运行时间，题目若给定义应服从题面；
  • 稳态可用性：A = MTTF / (MTTF+MTTR) = MTTF/MTBF。

例：MTTF=990 h，MTTR=10 h：

A=990/(990+10)=0.99=99%。

若恒定失效率 λ，指数可靠度模型：

R(t)=e^(−λt)，且 MTTF=1/λ。

当 λt 很小时，可近似 R(t)≈1−λt。例如 λ=10^−5/h，t=1000 h：近似 R≈1−0.01=0.99；精确值 e^−0.01≈0.99005，二者接近。

应试动作：串联直接乘；并联先算“全坏”再用 1 减；混联从内到外。涉及 MTTF/MTTR 时先看题目问“可靠度”还是“可用性”，不要把 A=MTTF/(MTTF+MTTR) 当成任意时长的可靠度。

第十一节 校验码：发现传输中的比特翻转 ★★★

11.1 码距与能力

两个合法码字不同位的最少数量叫最小码距 dmin。

  • 要检测 e 位错误：dmin ≥ e+1；
  • 要纠正 t 位错误：dmin ≥ 2t+1。

这说明“检错”和“纠错”不是一回事：发现“有人错了”比指出“具体哪位错了”容易。

11.2 奇偶校验

加 1 位校验位，使整个码字中 1 的数量为奇数（奇校验）或偶数（偶校验）。

数据 1011001 有 4 个 1：

  • 偶校验位填 0，总数仍为偶数；
  • 奇校验位填 1，总数变成 5。

奇偶校验能发现奇数个位错误，不能发现所有偶数个位错误，也不能定位纠错。

反例：不能说“奇校验只能发现奇数值错误”。这里的奇数指发生翻转的位数为奇数，与数据表示的数值奇偶无关。

11.3 CRC：用模二除法求余数

设信息位为 M，生成多项式对应二进制除数 G 有 r+1 位，则校验位有 r 位：

  1. 在 M 后补 r 个 0；
  2. 用 G 做模二除法（减法就是 XOR，无借位）；
  3. 得到 r 位余数，替换补上的 0；
  4. 接收方用同一 G 除完整码字，余数为 0 表示“未检测到错误”。

例：信息 1101，生成多项式 G=1011（最高次数 3，所以 r=3）：

  • 被除数：1101 000；
  • 模二除以 1011，余数为 001；
  • 发送码字：1101 001；
  • 1101001 再除以 1011，余数为 000。

CRC 擅长检错，尤其是突发错误，但一般不能依据余数唯一定位并纠正错误。

11.4 海明码：让校验结果直接指出错误位置

若有 m 位数据、r 位校验位，为纠正 1 位错误需满足：

2^r ≥ m+r+1

右侧的 m+r 是每个可能出错的位置，另加 1 种“无错”状态；r 个校验位能产生 2^r 种状态。

例：m=4。试 r=2：2²=4＜4+2+1=7，不够；试 r=3：2³=8≥4+3+1=8，所以需 3 位校验位。

校验位放在位置 1、2、4、8…（2 的幂），数据放其余位置。以 4 位数据 1011 依次放入位置 3、5、6、7，采用偶校验：

位置 1 2 3 4 5 6 7
内容 p1 p2 1 p4 0 1 1
  • p1 检查 1、3、5、7 → 已有两个 1，所以 p1=0；
  • p2 检查 2、3、6、7 → 已有三个 1，所以 p2=1；
  • p4 检查 4、5、6、7 → 已有两个 1，所以 p4=0；
  • 码字为 0110011。

若第 6 位翻转，三个校验组的异常结果按 s4s2s1 排列为 110₂=6，直接指出第 6 位，翻回即可。

校验方式 校验位 典型能力 核心操作
奇偶校验 1 检奇数位错，不纠错 数 1 的奇偶
CRC 由生成多项式次数决定 强检错，通常不纠错 模二除法
海明码 2^r≥m+r+1 可定位并纠正 1 位错 分组奇偶校验

应试动作：看到“模二除法”选 CRC；“校验位插在 1、2、4、8 位、能定位”选海明码；海明位数从 r=1 往上试，等号满足也算够。

1. A

11101100 是负数补码。求绝对值：整体按位取反得 00010011，再加 1 得 00010100=20，所以原数为 −20。反向验证：+20=00010100，取反加 1 得 11101100。B 少加/多减了 1；C 把无符号数 236 当答案；D 误把后 7 位直接当绝对值。

2. A

阶码位数决定范围，尾数位数决定精度。甲阶码长所以范围更大，尾数短所以精度更低。口诀“阶范尾精”。D 正好说反。

3. B

PC 保存下一条指令地址；IR 保存当前指令；MAR 保存主存地址；PSW 保存状态标志。题干“下一条”是 PC 的直接识别词。

4. C

时间局部性就是刚访问的内容短期内可能再次访问。A、B 把 SRAM/DRAM 说反：SRAM 不刷新，常作 Cache；DRAM 要刷新，常作主存。磁带是顺序存取。

5. B

单元数=5FFFH−2000H+1=4000H=2^14，按字节编址即 2^14 B=16 KiB。交叉检查：2000～2FFF、3000～3FFF、4000～4FFF、5000～5FFF 共 4 段，每段 1000H=4 KiB，总计 16 KiB。

6. B

题目明确 50 ns 是“未命中的完整访问时间”，用加权平均：0.9×5+0.1×50=4.5+5=9.5 ns。结果位于 5～50 ns 之间。不能再额外加一次 Cache 时间。

7. B

全相联映射允许主存块进入任意 Cache 行，冲突率最低；代价是比较范围最大、硬件最复杂。直接映射与之相反，组相联折中。D 不是 Cache 的标准映射方式。

8. C

6000 RPM 的一圈时间=60000/6000=10 ms，平均旋转等待为 5 ms。忽略传输时间，平均存取=7+5=12 ms。D 把整圈 10 ms 加了进去。

9. C

DMA 让外设与主存成批交换数据，由 DMA 控制器接管主要传输工作。查询/轮询让 CPU 忙等；中断虽不忙等，但数据搬运仍较多依赖 CPU。

10. B

中断向量给出中断服务程序入口地址或形成该地址的信息。它不是断点；断点是被中断程序恢复时继续执行的位置。

11. A

间接寻址先取 (120)=600 作为有效地址，再取 (600)=45 作为操作数。B 是立即寻址结果，C 是直接寻址结果。

12. D

“大量、复杂、变长、微程序”是 CISC 画像。RISC 通常指令规整、寻址少、多寄存器、Load/Store、硬布线并利于流水线。

13. C

最长段为 4 ns。理论时间=(2+3+4)+(10−1)×4=9+36=45 ns。非流水时间为 10×9=90 ns，45 ns 小于 90 ns，合理。B 是误用 n×4，漏掉建立时间。

14. C

并联系统可靠度=1−(1−0.8)^2=1−0.04=0.96。A 是误用串联；D 直接相加导致概率超过 1。

15. B

公式 2^r≥m+r+1，m=4。r=2 时 4＜7，不够；r=3 时 8≥8，刚好，所以至少 3 位。

RBC=1−(1−0.9)(1−0.9)=1−0.01=0.99。

再与 A 串联：R=0.95×0.99=0.9405。

合理性检查：并联模块 0.99 高于单件 0.9；串联 A 后 0.9405 低于 0.95。

（2）可用性：

A=MTTF/(MTTF+MTTR)=1990/(1990+10)=1990/2000=0.995=99.5%。

（3）1101 有 4 位，故 r=3。在信息 1010 后补 3 个 0：1010000。用 1101 做模二除法，余数为 001，所以：

  • CRC 校验位：001；
  • 发送码字：1010001。

反向验证：1010001 模二除以 1101，余数为 000。

精华题答案

1. C

8 位补码范围为 −2^7～2^7−1，即 −128～127；最小值编码为 10000000。11111111 是 −1，不是最小值。补码负边比正边多一个数。

2. B

题目是“先查 6 ns，未命中后追加 94 ns”：

Tavg=6+(1−0.98)×94=6+1.88=7.88 ns。

路径加权复核：命中 6 ns，未命中总计 100 ns；0.98×6+0.02×100=5.88+2=7.88 ns。

3. C

字数扩展=32K/8K=4；位宽扩展=16/4=4；总片数=4×4=16。容量反验：16 片×8K×4 bit=512 Kbit；目标 32K×16 bit=512 Kbit。

4. C

12000 RPM 一圈=60000/12000=5 ms；平均等待=2.5 ms；读 2/100 圈=5×2/100=0.1 ms；合计 2.6 ms。B 漏了传输时间，D 使用了整圈等待。

5. B

中间两个 0.9 并联：1−0.1²=0.99。再与前后两个 0.9 串联：0.9×0.99×0.9=0.8019。原系统可靠度为 0.9³=0.729，改造后上升，且仍低于任一必经的 0.9，合理。

6. C

海明码通过多个重叠的奇偶校验组形成“错误位置编号”，可定位并纠正一位错。A 错：两位翻转可能让总体奇偶性不变；B 错：CRC 使用 XOR 的模二除法，无借位；D 错：余数为 0 只表示未检测到错误，不是数学上绝对无错，某些错误模式也可能漏检。

7. B

统一周期 Δt=5 ns，T=(k+n−1)Δt=(4+20−1)×5=115 ns。最大吞吐率=1/5 ns=2×10^8 个/秒。非流水时间=20×4×5=400 ns，115 ns 更小，符合流水线作用。
