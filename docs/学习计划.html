考前学习计划（9 月 15 日 → 10 月 27 日） ​

学习目标：约 38 天学完剩余 10 课 + 模拟卷，10 月 24—27 日机考（以官方通知为准），两科各 ≥45 分。 适用前提：工作日整块 1.5～2 小时 + 碎片 20～30 分钟（通勤/午休），周末可加量到 3～4 小时。 当前起点：第 1 课学到第二节（树与二叉树），其余未开始。 本计划只负责排期；「学到哪了」的唯一记录在 00-总览与进度.md，每周复盘时勾选。

一、总原则：两条泳道，永不合流 ​

你的三类知识分开走——理解/理科类用整块时间顺次学，背诵类用碎片时间每天一小份。背诵从第 1 天就启动，绝不攒到某一天集中狂背（背完就忘的根源就是堆积）。

整块时间（工作日 1.5~2h，周末 3~4h）      碎片时间（每天 20~30min）
┌─────────────────────────────┐     ┌─────────────────────────┐
│ 理解线：01 → 02 → … → 09     │     │ 背诵线：10 → 11 → 12 → 08 │
│ 10/11/12 的计算公式也在这条线  │     │ 每天 ≤15 分钟新背          │
│ 读讲义 45' → 做题 45' → 复盘 10'│    │ + 10 分钟回响复习旧份       │
└─────────────────────────────┘     └─────────────────────────┘
        讲义顺序 = 大纲梯队顺序              内容 = 讲义加粗结论 + 表格
  • 两条线互不挤占：理解课滞后不影响背诵照转；背诵欠账也不许占用整块时间补。
  • 背诵线背的全是「讲义加粗结论 + 对比表格」，正文不背。每份材料 ≤15 分钟能过一遍。
  • 10 标准化与知识产权最独立（跟谁都不联动），所以最早启动；08 信息安全偏背诵，主课线和背诵线两头并进。

执行细则：

  • 回响不是重读：遮住结论回忆，想不起来才看，能回忆的打勾跳过（越背越快）。
  • 某天回响攒到 ≥3 份：只过「昨天的新份 + 最久没见的两份」，其余顺延明天——永远不堆积。
  • 考前 10/22–23：把 11 份全部过最后一轮（此时大多能回忆，很快），这就是背诵的「终审」。

五、复盘体系：日 5 分钟、周 1 小时、阶段加测 ​

日复盘（睡前 5 分钟，写在纸上或手机备忘录，不用进仓库），固定 3 行：

  1. 今天学到：第 X 课第 X 节的 XX 点；
  2. 错题/卡点：第 X 题，错因是「概念不清 / 计算失误 / 没记住」（错因三选一，后面好对症）；
  3. 明天第一件事：XXX（消灭「今晚从哪开始」的犹豫）。

周复盘（周日 1 小时，5 步清单）：

  1. 重做本周全部错题（合上答案重算，不是看一眼）——错题是唯一的复习真源；
  2. 背诵日历完成率自查，欠的份顺延进下周日历，不许周末突击补背；
  3. 计算专项：本周涉及的公式（哈夫曼/WPL、子网、PV……）闭卷默算 1 题；
  4. 勾选 00-总览与进度.md，按实际进度微调下周排期；
  5. 三问自检：本周最大的坑是什么？哪个考点还虚？下周一第一件事？

阶段复盘（阶段一/二/三的最后一个周日，在周复盘上加 20 分钟）：

  • 本阶段各课「精华题」抽 3～5 道限时重做；
  • 案例题模板核对：算法填空（阶段一）、SQL/E-R/数据流图（阶段一二）、UML（阶段二）；
  • 后续排期是否要挪——挪就当场改本文件日期，改完不用愧疚，计划为进度服务。

六、防堆积四条铁律（贴在书桌上） ​

  1. 任何一天新背 ≤15 分钟（考前两天除外）——背诵靠次数多，不靠单次久；
  2. 复习永远优先于学新：时间不够先回响旧份、再错题，新内容永远可以顺延；
  3. 背诵只背加粗结论和表格，发现某个结论看不懂 → 回对应讲义小节重读，不在碎片时间里硬啃；
  4. 落进度不熬夜补：当晚补不完就记进日复盘第 3 行，周复盘重排——熬夜学的东西第二天就还回去了。

七、吃紧时的砍单预案 ​

阶段三开始时若明显落后，按这个顺序砍（保持案例题和背诵线不砍）：

  1. 09 计算机系统基础：浮点数规格化、磁盘阵列计算可只记结论不推导（选择题 6–8 题里拿基础分就够）；
  2. 12 数学与多媒体：12-③ 排列组合可并入考前终审只过一遍；
  3. 07 程序设计语言：编译阶段细节只认「识别特征」不深究原理；
  4. 永远不砍：01/02/03/04 的案例题专攻节（案例 15 分/题是大头）、背诵线 11 份（碎片时间背，不占整块）。

八、本计划的边界 ​

  • 完成进度只记录在 00-总览与进度.md，本文件的日期是「预定日历」，不打勾、不记完成；
  • 排期和实际冲突时：周复盘重排 → 改本文件日期，进度表只反映事实；
  • 学习中哪个讲义看不懂，直接在对话里问（AI 会当场修订讲义），这本身就是「理解线」的一环。
