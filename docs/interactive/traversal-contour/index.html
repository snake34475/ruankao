▸ 这套动画在讲什么（看之前先读这段）

把「前/中/后序」想成同一个绕圈动作、只因记录时机不同就得到三种序：

  • 第 1 次路过（从上方来，贴左缘下去）记下 → 前序；
  • 第 2 次路过（走完左子树，从底下绕回来）记下 → 中序；
  • 第 3 次路过（走完右子树，从右缘离开）记下 → 后序。

所以每个节点被路过三次，但只有叶子（没子树）这三次才紧挨成连续三步；根 / 内部节点的三次被左右子树撑开，分散在整圈里。 对照右边的表：第 3/4/5 行是 D 的三次，但 A 的三次在第 1、11、16 行——这正是「绕一圈」模型的全部秘密。
