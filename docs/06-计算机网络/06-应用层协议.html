06.6 应用层协议与端口 ★★★

端口是什么、怎么记

一台主机上同时跑着浏览器、微信、下载器……数据到了该交给谁？传输层用 16 位端口号区分进程。范围 0～65535；知名端口 1～1023 固定分配给常见服务。端口成对工作：服务器端用知名端口"听"，客户端随机开口。IP 地址找到主机，端口找到主机里的程序。

常用协议端口表（必背，年年考）

协议 端口 传输层 功能一句话
FTP 20（数据）/ 21（控制） TCP 文件传输
SSH 22 TCP 安全远程登录
TELNET 23 TCP 远程登录（明文，不安全）
SMTP 25 TCP 发邮件（推）
DNS 53 UDP 为主（区域传送用 TCP） 域名 ↔ IP 解析
TFTP 69 UDP 简单文件传输
HTTP 80 TCP 网页传输
POP3 110 TCP 收邮件（拉）
SNMP 161 UDP 网络设备管理
HTTPS 443 TCP 加密的网页传输
DHCP 67 / 68 UDP 自动分配 IP 配置

记忆口诀："21 号 FTP 控制，20 传数据；23 远登、25 发信、53 域名、80 网页、110 收信、443 加密"。UDP 一族只有四个：DNS、TFTP、SNMP、DHCP（口诀："域名、简单传文件、网管、拿地址，都图个快"），其余常考应用协议全走 TCP。

DHCP 单独强调（常考功能题）：DHCP 的作用是让主机开机后自动获取 IP 地址、子网掩码、默认网关、DNS 服务器等配置，免手工设置；采用 UDP，客户端从 68 端口向服务器 67 端口申请。工作过程"发现（Discover）→ 提供（Offer）→ 请求（Request）→ 确认（Ack）"四步，知道名字即可。

反例演示：

  1. "SMTP 端口 110"——错。SMTP 发信用 25，POP3 收信用 110，这组是端口题最经典的调包陷阱。
  2. "DNS 用 TCP 53"——错一半。DNS 日常查询用 UDP 53，只有区域传送（主从服务器同步整个区域文件）才用 TCP。选择题若笼统问 DNS 的端口号，答 53；若问传输层载体，答"主要 UDP"。
  3. "FTP 端口是 20"——不完整。FTP 是双端口：21 控制、20 传数据；题目问"控制连接"答 21。

应试动作：① 端口表按口诀背到看到协议名 1 秒报端口（反向也要会：给端口报协议）；② 牢记 UDP 四兄弟 DNS/TFTP/SNMP/DHCP，其余默认 TCP；③ SMTP/POP3 是"发/收"配对，FTP 是"21 控制/20 数据"配对，专防调包。
