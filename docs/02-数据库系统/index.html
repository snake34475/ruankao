02 数据库系统

分值地位：选择题约 5–6 题（稳定第二大块）+ 案例题「数据库设计」一道大题（补 E-R 图/写 SQL，约 15 分）。与数据结构并列第一梯队，范式判定和 SQL 是选择题 + 案例题双考点。

学习目标：读完讲义后，你能——① 画出三级模式两级映像并判断"独立性"考题；② 给业务场景画 E-R 图、判断联系类型、转成关系模式；③ 用属性闭包手算候选键、判定 1NF–BCNF 并检查分解；④ 独立写建表/增删改查/视图 SQL；⑤ 说清 ACID、四类并发错误、两段锁协议和三类故障恢复。
