05.9 答案与解析 ​

课后考题答案（选择题） ​

1. B PCB 记录进程的标识、状态、现场等全部管理信息，系统靠它感知进程的存在——"PCB 是进程存在的唯一标志"。程序和数据只是进程的组成部分，进程撤销后它们仍可能存在。

2. C 线程独有栈和寄存器现场，T3 的栈是 T3 的"私人工作台"，T1 不能直接访问（A、B、D 均为共享内容：代码段、打开的文件、全局变量）。这是"共享/独有"清单的直接考法。

3. D 就绪→阻塞不可能：阻塞源于"运行中的进程主动等待某事件"，就绪进程根本没在运行，无从发起等待。两个恒不可能的转换是"就绪→阻塞"与"阻塞→运行"，后者错在跳过了就绪排队。

4. B 时间片用完 = 被剥夺 CPU 但一切资源俱备 → 回就绪队列排队。若是进程主动请求 I/O 才转阻塞态（A 错）。

5. A S 最大值 = 资源数 3（无人使用时）；最小值 = 初值 − 进程数 = 3 − 10 = −7（10 个进程全在排队）。C 项 [−3,10] 把上下界弄反了，B 项把进程数当成了下界来源且错用 10。

6. C 互斥信号量初值 = 资源数量，3 台打印机 → 3。若只有 1 台才是 1；0 是同步信号量的典型初值；−3 不是初值（初值非负）。

7. C 信号量个数 = 有向弧条数 = 6，前趋图（同步）信号量初值全为 0。5 是进程数不是弧数——这是最典型干扰项；初值 1 是互斥信号量的设定，与同步无关。

8. D 资源全系统统一编号、按序申请，使"环形等待链"无法闭合 → 破坏环路等待。一次性申请全部资源才破坏"请求和保持"（B）。

9. C 可能死锁 ⇔ n ≤ m(i−1)，即 10 ≤ 3(i−1) → i−1 ≥ 10/3 ≈ 3.34 → i ≥ 4.34 → 最小整数 i = 5。 验算 i = 4：每进程最多占 3 个，3 进程最多共占 9 个 < 10，必有资源空闲，持有 3 个的进程可补齐第 4 个而完成，不死锁 ✓；i = 5：3 个进程各持 3 个共 9 个，剩 1 个，任一进程拿走后仍差 1 个且无资源可补，人人等待 → 死锁可能 ✓。

10. A 页大小 4KB = 2^12 = 1000H → 低 3 位十六进制 D30H 是页内地址（不变），高位 2H 是页号 → 查表页 2 → 物理块 3 → 物理地址 = 3D30H。 十进制验算：0x2D30 = 11568，11568 = 2×4096 + 3376（偏移 3376 = 0xD30）；物理地址 = 3×4096 + 3376 = 12288 + 3376 = 15664 = 0x3D30 ✓。B 项是"没查页表"的直接照抄；C、D 是换了错误页帧号的结果。

11. B FIFO 逐位模拟（3 块）：1缺[1]、2缺[1,2]、3缺[1,2,3]、4缺淘汰1[2,3,4]、1缺淘汰2[3,4,1]、2缺淘汰3[4,1,2]、5缺淘汰4[1,2,5]、1命中、2命中、3缺淘汰1[2,5,3]。缺页 8 次，缺页率 8/10 = 80%。 验算：命中仅第 8、9 两次，10 − 2 = 8 ✓。

12. A 合法条件：段号存在 且 偏移 < 段长。(0, 25K)：25K ≥ 段长 20K → 越界非法。B（20K < 25K）、C（10K < 15K）、D（24K < 25K）均合法。

13. A 字号 = ⌊5000 / 32⌋ = 156，位号 = 5000 mod 32 = 8。 验算：156×32 = 4992，4992 + 8 = 5000 ✓。B 项位号 9 是"按从 1 计数"误算；C 项把"除不尽向上"错用在定位题；D 项取整方向错（155×32 = 4960 ≠ 5000 起）。

14. B SSTF：70→65（5）→82（17）→95（13）→110（15）→40（70），总移动 = 5+17+13+15+70 = 120 道。 逐位验算"最近"：70 处距 65 为 5 最近 ✓；65 处距 82 为 17（95 为 30、40 为 25）✓；82 处距 95 为 13（110 为 28、40 为 42）✓；95 处距 110 为 15 ✓；最后只剩 40，移动 70 ✓。

15. B Spooling 用磁盘输入井/输出井做中转，把打印机这类独占设备改造成逻辑上可共享的虚拟设备。它不改变磁盘转速（C）、不优化寻道（D），A 把方向说反了。

案例 1

问题 1（逐弧配对：每条弧起点末 V、终点初 P）：

空答案对应弧
①V(S2)A→C（A 末尾已 V(S1) 对应 A→B，再 V(S2) 对应 A→C）
②P(S1)A→B（B 开头等 A 完成）
③P(S2)A→C
④P(S4)C→D（D 开头需 P(S3) 与 P(S4) 各一次，对应两条入弧）
⑤P(S5)D→E

注：进程 D 开头的 P(S3)、P(S4) 先后顺序可互换，两次 P 都做完才能往下执行。

问题 2：增加 1 个信号量（共 6 个）——每条弧一个信号量，新增弧 B→E 即新增 1 个。E 开头需做 P(S5) 和新信号量的 P 两个 P 操作（E 有两条入弧：D→E 与 B→E，几条入弧就做几个 P）。

案例 2

问题 1： 剩余可用 = 11 − (3+4+2) = 2。 Need = 最大需求 − 已分配：P1 = 7−3 = 4；P2 = 5−4 = 1；P3 = 9−2 = 7。

问题 2：安全，且安全序列唯一，为 P2 → P1 → P3。判定表：

步骤Available可满足者（Need ≤ Available）执行并归还后 Available
12只有 P2（1 ≤ 2；P1 需 4 > 2，P3 需 7 > 2）2 + 4 = 6
26只有 P1（4 ≤ 6；P3 需 7 > 6）6 + 3 = 9
39P3（7 ≤ 9）9 + 2 = 11（全部完成）

唯一性验证：Available = 2 时 P1、P3 都无法启动，第一步只能是 P2；P2 完成后 Available = 6，P3 需 7 > 6 仍无法启动，第二步只能是 P1——每一步都别无选择，故安全序列唯一 ✓。

问题 3：不能满足。试探性分配：Available = 2 − 2 = 0，P3 已分配 = 4、Need = 5。此时 P1 Need 4 > 0、P2 Need 1 > 0、P3 Need 5 > 0——没有任何进程的需求能被满足，找不到安全序列，该状态不安全（可能死锁），系统应拒绝本次申请、回滚试探分配。

精华题答案 ​

1.

  • FIFO（淘汰最先进内存的页）：1缺、3缺、1命中、2缺[1,3,2]、4缺淘汰1[3,2,4]、3命中、1缺淘汰3[2,4,1]、4命中 → 缺页 5 次，缺页率 5/8 = 62.5%。
  • LRU（淘汰最近最久未使用）：1缺、3缺、1命中、2缺[1,3,2]、4缺（最后使用 1@位3、3@位2、2@位4 → 淘汰 3）[1,2,4]、3缺淘汰1[2,4,3]、1缺淘汰2[4,3,1]、4命中 → 缺页 6 次，缺页率 75%。
  • OPT（淘汰将来最久不用）：1缺、3缺、1命中、2缺[1,3,2]、4缺（往后看 3@位6、1@位7、4@位8，2 不再用 → 淘汰 2）[1,3,4]、3命中、1命中、4命中 → 缺页 4 次，缺页率 50%。
  • 验算（串长 − 命中数）：FIFO 命中位3、6、8 共 3 次 → 8−3 = 5 ✓；LRU 命中位3、8 共 2 次 → 8−2 = 6 ✓；OPT 命中位3、6、7、8 共 4 次 → 8−4 = 4 ✓。缺页数 OPT(4) < LRU(6) < FIFO(5)？注意本题 FIFO(5) < LRU(6)——FIFO 并不总比 LRU 差，具体取决于引用串，这也是考题爱设的"反直觉"点 ✓。

2. ① SSTF：100→90（10）→55（35）→30（25）→120（90）→140（20），总移动 = 10+35+25+90+20 = 180 道。 逐位验算最近：100 处 90 最近（120 为 20、55 为 45）✓；90 处 55 最近（120 为 30、30 为 60）✓；55 处 30 最近（120 为 65）✓；30 处 120 最近（140 为 110）✓；最后 140 ✓。 ② SCAN（到 0 号磁道才折返）：100→90→55→30→0→120→140。总移动 = (100−0) + (140−0) = 240 道。 逐段验算：10+35+25+30+120+20 = 240 ✓。

3. ① n = m(w−1)+1 = 5×(3−1)+1 = 11。最坏情形 5 个进程各持 2 个共 10 个仍各差 1 个，第 11 个资源让某进程凑齐跑完并释放 → 必不死锁。 ② 可能发生：10 ≤ m(w−1) = 5×2 = 10 → 满足"可能死锁"的条件（如 5 个进程各持 2 个、资源分光，人人差 1 个 → 死锁）。

4. ① 总块数 = 512GB ÷ 4MB = 512×1024MB ÷ 4MB = 131072 块；字数 = 131072 ÷ 64 = 2048 个字。验算：131072 = 2^17，64 = 2^6，2^17 ÷ 2^6 = 2^11 = 2048 ✓。 ② 字号 = ⌊100000 / 64⌋ = 1562，位号 = 100000 mod 64 = 32。验算：1562×64 = 99968，99968 + 32 = 100000 ✓。即第 1563 个字（按从 1 计数）的第 33 位。

5. 页大小 2KB = 2048。页号 = 4500 ÷ 2048 = 2，页内偏移 = 4500 − 2×2048 = 404。查表页 2 → 物理块 7：物理地址 = 7×2048 + 404 = 14336 + 404 = 14740。 验算（反向拆分）：14740 ÷ 2048 = 7 余 404（7×2048 = 14336，14740−14336 = 404）→ 块号 7、偏移 404，与正向一致 ✓。

6.

  • FCFS：J1 0–5（周转 5−0 = 5）；J2 5–7（周转 7−2 = 5）；J3 7–8（周转 8−3 = 5）。平均 = (5+5+5)/3 = 5。
  • SJF（非抢占）：t=0 只有 J1 已到 → J1 0–5（周转 5）；t=5 时 J2（需 2）、J3（需 1）都已到达，挑短的 J3：5–6（周转 6−3 = 3）；再 J2：6–8（周转 8−2 = 6）。平均 = (5+3+6)/3 = 14/3 ≈ 4.67。 验算：完成时刻 FCFS 为 5、7、8，SJF 为 5、6、8，均不早于各自到达时刻 ✓；SJF 平均更短，符合理论 ✓。

7. 每块可存地址项数 = 2KB ÷ 4B = 2048 ÷ 4 = 512 个。

  • 直接：6 × 2KB = 12KB；
  • 一级间接：512 × 2KB = 1024KB = 1MB；
  • 二级间接：512 × 512 × 2KB = 262144 × 2KB = 524288KB = 512MB；
  • 最大文件 = 12KB + 1MB + 512MB ≈ 513MB + 12KB。 验算：512×512 = 262144 ✓；262144 块 × 2KB = 524288KB ÷ 1024 = 512MB ✓；三部分相加 524288 + 1024 + 12 = 525324KB ≈ 513.01MB ✓。

补充题答案 ​

1. A。段数 = 2^10 = 1024；每段页数 = 2^10 = 1024；页大小 = 2^12 = 4096B = 4KB。B、C、D 把位数直接当十进制（10、12），或把 2^10 与 2^12 混用。 验算：2^10 = 1024、2^12 = 4096 ✓。

2. A。单块 = 5+10+1 = 16ms；整文件 = 100×16 = 1600ms = 1.6s。B（160）漏算旋转/单位；C（100）只算传输；D 把 ms 再放大了 10 倍。 验算：100×16 = 1600ms ✓。

3. C。q = 1KB÷4B = 256。直接段 0～9、一级段 10～265、二级段 266 起；300 ⇒ 二级，读二级索引块 + 一级索引块 + 数据块 = 3 次。A（1 次）当成直接段；B（2 次）当成一级段；D 多读一次。 验算：一级段止于 9+256 = 265 < 300 < 10+256+65536 ⇒ 二级 ✓。

4. A。从 1 编号：字 = ⌊(1000−1)/32⌋+1 = ⌊999/32⌋+1 = 31+1 = 32；位 = (999 mod 32)+1 = 7+1 = 8。 验算：(32−1)×32 + (8−1) = 31×32 + 7 = 999 = 1000−1 ✓。B 直接 ⌊1000/32⌋（把"从 0"当成"从 1"）；C 位号少 1；D 字、位都混口径。

5. A。同步的 P 须在互斥的 P 之前，且"放入"要在临界区内并成对 V。B、C 把 P(mutex) 放到同步 P 之前（缓冲区满时占着 mutex 等空位，与消费者互相等 → 死锁），且 C 的"放入"未受 mutex 保护、V 也不配平；D 用错信号量（生产者的同步应是 empty，用 full 会在空缓冲时误等）。 逐条核对：A 的 P 顺序、临界区、成对 V 全部正确 ✓。

6. A。可化简判据是"申请量 ≤ 当前空闲量"（非阻塞）。B、C 与化简规则无关；D 错——有环未必死锁，要看能否化简。

7. A。单缓冲传/处串行：10×(2+6) = 80ms；双缓冲瓶颈是处理 c=6：10×6 + min(2,6)=2 → 62ms。B 反；C 把双缓冲错算成串行（80/80）；D 只算传输。 验算双缓冲按时间轴：处理从 2ms 连续占据到 62ms（10 次 × 6ms），开头再传一块 2ms，总 62ms ✓。

8. C。FCB 是目录里的登记信息（文件名、位置、长度、权限等），不含文件内容本身。

9. B。754：同组 = 5 = 4+1 = r-x（读+执行，无写）。A（rwx = 7）是属主；C（r-- = 4）是其他用户；D 把 w、x 次序弄反。

10. C。页内 12 位 ⇒ 页大小 = 2^12 = 4096B = 4KB。A（2^10）、B（2^11）、D（2^13）都不是 12 位对应的 2^12。 验算：2^12 = 4096 ✓。
