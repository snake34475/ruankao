07.3 前缀、中缀、后缀表达式 ★★

这一节第 1 课（线性表、栈与队列 第 1.2 节）已详细讲过中缀转后缀的"傻瓜法"（按优先级加满括号，运算符搬到自己那对括号的右边）。这里给速查表和前缀补全：

表达式 运算符位置 例子（(a+b)*c−d） 特点
中缀 两操作数中间 (a+b)*c−d 人习惯，需括号和优先级
后缀（逆波兰式） 两操作数后面 ab+c*d− 计算机求值最方便，无括号
前缀（波兰式） 两操作数前面 −*+abcd 无括号，考试较少考

4.1 语法树遍历与三种表达式

表达式树把“谁先算”直接画成父子关系：内部结点是运算符，叶子是操作数。对 (a+b)*c：

        *
       / \
      +   c
     / \
    a   b

同一棵树用不同遍历顺序读，就得到三种等价写法：

遍历 访问次序 结果 表达式
先序 根—左—右 * + a b c 前缀 *+abc
中序 左—根—右 a + b * c，按树补括号 中缀 (a+b)*c
后序 左—右—根 a b + c * 后缀 ab+c*

为什么中序必须按树补括号：若只把中序字符机械写成 a+b*c，常规优先级会先算 b*c，与树中“先算 a+b”矛盾。树已经规定运算结构，中缀式必须用括号把这层结构保留下来。

反例演示（易错）：有人把这棵树的后缀写成 bc+a*。按后缀规则还原：bc+ 先得到 (b+c)，再与 a 相乘，实际是 (b+c)*a，不是 (a+b)*c。错误版本不是“顺序差一点”，而是换了一棵树、改变了运算含义。

应试动作：见“给语法树求表达式”直接套：先序=前缀，中序=中缀，后序=后缀；中序读完按树补括号。写完把后缀用栈还原一次，确认每个运算符吃到的左右子树正确。

转前缀的傻瓜法：同样先加满括号，把运算符搬到自己那对括号的左边。例：(a+b)*c−d → (((a+b)*c)−d) → +ab 变 +ab，(+ab)c 变 *+abc，整体减 d → −*+abcd。

后缀求值（必考，完整步骤）：从左到右扫，操作数进栈；遇运算符弹出栈顶两个数计算——先弹出的是右操作数——结果再进栈。例：后缀 8 2 3 * − 4 +：

读到 动作 栈
8, 2, 3 依次进栈 8, 2, 3
* 弹 3、弹 2，算 2×3=6，进栈 8, 6
− 弹 6、弹 8，算 8−6=2，进栈 2
4 进栈 2, 4
+ 弹 4、弹 2，算 2+4=6 6

结果 6。反向验证：该后缀对应中缀 8−2*3+4 = 8−6+4 = 6 ✓。

为什么编译器爱用后缀做中间代码：第三节说过中间代码常用形式里就有"后缀式"——扫后缀式时每个运算符出现时它的操作数一定已在栈里，一遍扫完，不需要优先级表和括号。

反例演示：后缀求值时先弹的是右操作数，减法除法顺序不能反。8 6 − 是 8−6=2；若先弹的当左操作数就算成 6−8=−2，错。

应试动作：① 中缀转后缀用"加满括号搬右边"，转前缀"搬左边"；② 求值时先弹的当右操作数；③ 考题给后缀式求值，用栈表逐步算，算完还原成中缀验一遍。
