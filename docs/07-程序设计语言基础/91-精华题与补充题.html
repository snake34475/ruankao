07.10 精华题与补充题

1. 关于编译各阶段的叙述，正确的是（ ）。 A. 语义分析阶段的输出是记号流 B. 中间代码与具体的机器无关 C. 目标代码生成与硬件系统结构无关 D. 词法分析依据语言的语法规则识别各类语法单位

2. 某 DFA（初态 p₀，终态 p₂）的转移表如下：

状态 输入 a 输入 b
→p₀ p₁ p₀
p₁ p₂ p₀
*p₂ p₂ p₀

与该自动机等价的正规式是（ ）。 A. (a|b)*aa B. a(a|b)*a C. (a|b)*a D. aa(a|b)*

3. 正规式 1(0|1)*0 表示的字符串集合是（ ）。 A. 所有以 1 开头、以 0 结尾的 0、1 串 B. 所有以 0 开头、以 1 结尾的 0、1 串 C. 所有含有子串 10 的 0、1 串 D. 所有由偶数个 1 组成的串

4. 有函数 function foo(p, q) { p = p + q; q = p - q; return p * q; }。第一次以引用调用执行 foo(x, y)（x=4, y=1），第二次以传值调用执行同样调用。两次的返回值与实参最终值是（ ）。 A. 返回值相同（均为 20）；引用调用后 x=5、y=4；传值调用后 x=4、y=1 B. 返回值不同；引用调用后 x=5、y=4 C. 返回值相同；引用调用后 x=5、y=1 D. 返回值相同；引用调用后 x=4、y=4

5. 后缀表达式 8 2 3 * - 4 + 的值是（ ）。 A. 2 B. 6 C. 14 D. 26

6. 下列错误中，编译阶段不能发现的是（ ）。 A. 表达式括号不匹配 B. 对两个类型不兼容的运算对象做运算 C. 使用了语言字符集以外的非法字符 D. 运行时数组下标越界

7. Java 能实现"一次编写、到处运行"，其机制是（ ）。 A. Java 编译器直接为每种平台生成对应的机器码 B. Java 是纯解释执行的语言，不经过任何编译 C. Java 编译生成与平台无关的中间代码（字节码），由各平台的 JVM 执行 D. Java 程序不需要任何翻译程序即可在机器上直接运行

补充题（扩充考点专项，不破坏原题编号）

1. 【语言基本成分】 if (score >= 60) print("pass") 中，关系运算 >=、if、print 分别主要属于（ ）。 A. 数据、运算、控制 B. 运算、控制、传输 C. 控制、数据、运算 D. 运算、传输、控制

2. 【Python 容器】 下列说法正确的是（ ）。 A. tuple 和 str 都可按下标修改元素 B. set 有固定位置顺序且允许重复元素 C. list、set、dict 可变，tuple、str 不可变 D. dict 只能用整数下标取值

3. 【编译阶段】 下列关于编译过程的说法正确的是（ ）。 A. 中间代码生成和代码优化在任何编译器中都不可省略 B. 代码优化可以省略，省略后程序一定无法正确运行 C. 汇编指令代码可作为目标程序的一种形式 D. 目标代码生成与具体机器无关

4. 【语法树遍历】 表达式 (a-b)/(c+d) 的语法树以 / 为根，左右子树的根分别为 - 和 +。写出其前缀式和后缀式，并用中缀式反向验证。

5. 【句型与句子】 对文法 S→aSb | ε，下列说法正确的是（ ）。 A. aaSbb 是句子，因为它可由 S 推导得到 B. aabb 是句型也是句子 C. aSb 既不是句型也不是句子 D. 只要含终结符就是句子

6. 【最左推导】 对文法 S→AB，A→aA|a，B→bB|b，写出句子 aabb 的一条最左推导，并说明为什么 abab 不能由该文法生成。

7. 【正规式规律】 正规式 0*(10*1)*0* 表示（ ）。 A. 1 出现奇数次的所有 0、1 串 B. 1 出现偶数次的所有 0、1 串 C. 长度为偶数的所有 0、1 串 D. 只由 0 组成的串

8. 【自动机快判】 某 DFA 的初态 q0 同时也是终态，且 q0 读入字符 a 后仍回到 q0。它识别的语言是（ ）。 A. a+ B. a* C. 仅 {a} D. 空集

9. 【子集法】 NFA 有状态 {q0,q1}，q0 为初态、q1 为终态，δ(q0,a)={q0,q1}、δ(q1,a)=∅，无 ε 边。用子集法写出可达的 DFA 集合状态、终态，并说明它识别的语言。

10. 【作用域与别名】 回答两问：

（1）全局 x=1；过程 P 定义在全局并输出 x；过程 Q 内有局部 x=2，Q 调用 P。静态作用域和动态作用域下 P 分别输出多少？

（2）procedure f(ref x, ref y) { x=x+1; y=x+y; }，a 初值为 2，执行 f(a,a) 后 a 是多少？写出逐句过程。
