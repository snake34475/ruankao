07.8 各语言特点与分类 ★

动机：选择题常给一个应用场景（"人工智能符号处理""科学计算"）问选什么语言，或给一个语言问它的分类。记忆表之前先抓两个判断轴：程序是何时、由谁翻译执行，变量的类型错误是何时暴露。这样看到陌生表述时不用只靠背标签。

按翻译方式分类：

类别 语言
编译型 C、C++、Pascal、Fortran
解释型（脚本语言多属此类） Python、PHP、JavaScript、Ruby
先编译为中间代码、再由虚拟机执行 Java（字节码 + JVM）、C#（中间语言 + .NET）

静态类型 vs 动态类型：静态类型语言（C、C++、Java）在编译期检查类型；动态类型语言（Python、JavaScript）变量类型在运行期才确定、随赋值变化。

8.1 两条判断轴：别把“翻译方式”和“类型检查”混在一起

翻译方式问的是程序怎样变成可执行动作。以 Java 为例，Order.java 先被编译成与机器无关的字节码 Order.class，再由本机的 JVM 解释或即时编译执行；因此“跨平台”的前提不是把同一份机器码搬到别的机器，而是各平台有能执行同一字节码的 JVM。C/C++ 则通常直接编译成目标机器的程序；Python 常由解释器在运行时执行源代码或其内部中间表示。详见第 01 节「编译、解释与语言基本成分」。

类型检查问的是不合规则的值何时被发现。静态类型语言中，像 int count = "三"; 这类赋值通常在编译期就报错；动态类型语言可先执行 count = 3，以后再执行 count = "三"，变量随当前绑定的值表现出不同类型。反例：Java 是“先编译为字节码再由 JVM 执行”，但它仍是静态类型语言；“由虚拟机执行”不等于“动态类型”。

考场判别：题干说“逐句翻译、运行时需要解释器”就按翻译方式判断；题干说“给变量赋不相容的值何时出错”才按静态/动态类型判断。这是两条互不替代的轴。

各语言特点表（背"语言 → 一句话"）：

语言 一句话特点
Fortran 科学计算，执行效率高
Pascal 为教学而开发，表达能力强
C 指针操作能力强、高效，常用于操作系统开发
Lisp 函数式语言，符号处理，人工智能
Prolog 逻辑推理，用于数据库和专家系统
C++ 面向对象且高效
Java 面向对象，编译为中间代码（字节码），跨平台
C# 面向对象，中间代码，.NET 平台
Python 解释型、面向对象、通用脚本语言
PHP 服务器端脚本语言，嵌入 HTML 的动态网页

8.2 Lisp 与 Prolog：都能做 AI，但解决问题的问法不同

  • Lisp擅长把符号和列表当作数据来处理。例如要把一棵表达式树 (+ x 1) 改写为 (+ y 1)，重点是“如何用函数递归处理符号结构”，这是函数式/符号处理的画面。
  • Prolog擅长先写事实和规则，再让系统推理查询。例如已知“甲是乙的父亲”“乙是丙的父亲”，写出“父亲关系可推出祖先关系”后，询问“甲是不是丙的祖先”，重点是“根据规则能否推出结论”。

反例：题干出现“专家系统依据规则和事实推出诊断结论”，应选 Prolog，不是因为它“也与 AI 有关”就选 Lisp；题干强调递归处理列表、符号表达式或函数组合，才更接近 Lisp。

应试动作：重点背两个"最容易和别的搞混"的——Lisp=函数式/AI、Prolog=逻辑推理/专家系统（两者都沾 AI，别互换）；再背 Java 跨平台靠"字节码 + JVM"这条机制描述。其余扫一眼有印象即可。
