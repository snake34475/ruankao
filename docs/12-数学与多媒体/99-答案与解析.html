12.8 答案与解析

课后选择题答案

1. B

只选 3 人、不区分职位，交换顺序不产生新结果，用组合：

C(8,3)=(8×7×6)/(3×2×1)=56。

C 的 336 是 A(8,3)，适用于三个职位不同的情形。反验：336/3!=336/6=56。

2. D

4 个位置，每个位置都有 10 种选择且允许重复、可从 0 开头，按乘法原理：10×10×10×10=10^4=10000。C 的 9000 对应首位不能为 0 的四位数，不是验证码。

3. B

蕴含是“P 发生就承诺 Q 发生”。只有 P 已为真而 Q 为假时承诺被打破。口诀：蕴含只假在前真后假。

4. B

n 个顶点的树有 n−1 条边，所以 12−1=11。D 的 66 是 12 个顶点完全图的边数 C(12,2)。

5. B

握手定理：总度数=2|E|，所以 |E|=28/2=14。每条边在两个端点各贡献 1 度，不能把 28 直接当边数。

6. A

绝对误差=|20.00−19.80|=0.20；相对误差=0.20/20.00=0.01；百分相对误差=0.01×100%=1%。B 把小数 0.01 又误写成 0.01%。

7. B

1024×768×24/8=2359296 B，再除以 2^20 得 2.25 MiB。第二种方法：24 bit=3 B/像素，1024×768×3=2.25 MiB。C 漏了 bit→Byte 的除以 8。

8. C

2^8=256，所以恰需 8 bit。7 bit 只能表示 128 种，4 bit 只能表示 16 种。

9. C

44100×16×2×10/8=1764000 B。逐秒反验：每个声道每次采样 2 B，双声道每秒 44100×2×2=176400 B，10 秒即 1764000 B。D 是未除以 8 的 bit 数。

10. D

采样定理 fs≥2fmax，故最低为 2×8=16 kHz。实际系统还会留滤波余量，但本题问理想最低值。

11. A

RGB 是显示器等发光设备使用的加色模型。CMYK 是印刷减色模型；YUV 分离亮度和色度；MIDI 是音乐演奏指令格式，不是颜色模型。

12. B

Y 表示亮度，U/V 或 Cb/Cr 表示色度/色差。这里的 Y 不是 Yellow；黄色是 CMY 中的 Y。

13. B

JPEG 中量化会粗化并舍弃部分频率系数，是主要有损环节。Huffman 熵编码利用统计冗余，本身是可逆的无损编码。

14. A

PNG 是无损位图格式并支持 Alpha 透明，适合界面图标和截图。JPEG 有损且通常不支持 Alpha；MP3 是音频，MPEG 主要用于运动图像/音视频。

15. B

相邻视频帧往往高度相似，MPEG 用预测编码利用帧间时间冗余；同一帧内部还可利用空间冗余。其余选项不是视频压缩的对应概念。

综合计算题答案

16. 图像与视频容量

（1）每幅图片：

800×600×24/8=1440000 B。

10 幅总容量：

1440000×10=14400000 B；

14400000/1048576≈13.733 MiB。

第二种方法：每像素 3 B，共 800×600×10=4800000 个像素样本；4800000×3=14400000 B，一致。

（2）压缩比 20:1：

14400000/20=720000 B≈0.687 MiB。

反验：720000×20=14400000 B，恢复到原始容量。

（3）帧数=25×8=200 帧：

800×600×24×25×8/8=288000000 B；

288000000/1048576≈274.658 MiB。

分层反验：每帧 1440000 B，200 帧共 1440000×200=288000000 B。

17. 组合、概率与音频容量

（1）不区分成员职位：

C(8,3)=(8×7×6)/(3×2×1)=56 种。

（2）恰有 1 名测试人员：从 3 名测试人员中选 1 名，从 5 名开发人员中选 2 名：

C(3,1)×C(5,2)=3×(5×4)/(2×1)=3×10=30 种。

概率=30/56=15/28≈0.5357。

反向枚举总数：0、1、2、3 名测试人员的选法分别为 C(3,0)C(5,3)=10、30、C(3,2)C(5,1)=15、C(3,3)C(5,0)=1，总和 10+30+15+1=56，与全部组合数一致。

（3）60 秒音频：

48000×24×2×60/8=17280000 B；

17280000/1048576≈16.479 MiB。

第二种方法：24 bit=3 B，每秒双声道容量=48000×3×2=288000 B；60 秒=288000×60=17280000 B，一致。

精华题答案

1. B

LEVEL 共 5 个位置，L 重复 2 次、E 重复 2 次：

5!/(2!×2!)=120/(2×2)=30。

若直接算 5!=120，会把两个 L 和两个 E 的互换错误地当成新排列。

2. B

全称命题“所有都通过”的否定是“至少一个不通过”，不是“所有都不通过”。只找到一个反例，就足以推翻“所有”。

3. C

无向完全图边数=C(7,2)=7×6/2=21。D 的 42 是把每条无向边按两个方向重复计算，适用于相应有向完全图的弧数。

4. B

32 bit=4 B/像素：

1920×1080×4=8294400 B；

8294400/1048576≈7.910 MiB。

用 bit 公式复核：1920×1080×32/8 结果相同。

5. C

1 分钟=60 秒：

48000×24×2×60/8=17280000 B≈16.48 MiB。

D 的 172.80 把十进制 MB 数小数点放错；若按十进制 MB，实际为 17.28 MB，也不是 172.80 MB。

6. B

JPEG 面向连续色调静止图像，通常是有损压缩，量化是主要有损步骤。帧间时间冗余属于视频编码思路；需要无损反复编辑的线条图更适合 PNG 等无损格式。

7. C

B 帧可参考前后帧做双向预测。I 帧可独立解码；P 帧通常参考前面的 I/P 帧；MPEG 常采用有损编码，并非三类帧都只能无损。
