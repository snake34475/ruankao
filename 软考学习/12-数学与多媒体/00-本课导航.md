# 12 数学与多媒体

> **分值地位**：基础知识约 3–4 题，通常由排列组合/逻辑推理与多媒体基础共同构成。题量不大，但公式固定、计算步骤短，尤其是**图像容量、音频容量、颜色位数**，属于考前突击也能拿到的分。
>
> **学习目标**：学完本课后，你能——① 判断一道计数题该用加法、乘法、排列还是组合；② 写出命题蕴含、德摩根律与量词否定；③ 用握手定理、完全图和树的边数公式解基础图论题；④ 区分绝对误差和相对误差；⑤ 独立计算图像、音频和未压缩视频容量；⑥ 解释 RGB、CMYK、YUV 的用途；⑦ 区分 JPEG、PNG、GIF、MPEG、MP3 及有损/无损压缩。

## 第一部分 本课导航

| 模块 | 常见考法 | 优先级 |
|---|---|---:|
| 排列组合 | “选人”还是“排位置”、重复元素、乘法原理 | ★★★ |
| 逻辑推理 | 蕴含真假、否定命题、德摩根律 | ★★ |
| 图论基础 | 度数和、完全图边数、树的边数 | ★★ |
| 误差常识 | 绝对误差、相对误差、舍入与截断 | ★ |
| 图像容量 | 分辨率×位深÷8 | ★★★ |
| 音频容量 | 采样率×量化位数×声道×时间÷8 | ★★★ |
| 颜色空间 | RGB/CMYK/YUV 的用途 | ★★ |
| 压缩标准 | JPEG/MPEG、无损/有损、I/P/B 帧 | ★★★ |

本章不对应独立的下午案例大题，但容量计算会以综合题形式训练。建议把所有公式都写在草稿纸上代一次单位；只在脑中“看懂”，最容易漏掉声道数、帧率或 bit→Byte 的除以 8。
