# 05.6 设备管理与高频计算专题 ★★

### 磁盘的结构与存取时间

磁盘由多个盘面组成，每个盘面划分成一圈圈**磁道**（从外向里 0,1,2,…编号），每个磁道按角度分成**扇区**；多个盘面的同一号磁道构成**柱面**（所以磁道号也叫柱面号）。

**存取时间 = 寻道时间 + 旋转延迟（等待时间）+ 传输时间**：寻道 = 磁头移到目标磁道（**最耗时，有调度算法可优化**）；旋转延迟 = 等目标扇区转到磁头下（盘匀速转，无算法可言）；传输 = 读写数据。选择题直接考"三段构成"与"寻道时间最值得优化"。

**存取时间算例（公式三件套）**：
- 通用形式：读一个数据块的时间 = 寻道 + 旋转延迟 + 传输；含 N 个**分散**数据块的文件总时间 ≈ N × 单块时间。
- 代入算例：读一个数据块需寻道 5ms、平均旋转延迟 10ms、传输 1ms；文件分散放在 100 个数据块。单块 = 5+10+1 = 16ms，整个文件 = 100 × 16 = **1600ms = 1.6s**。
- 手算口诀：**"先算一块，再乘块数"**。
- 反例演示（易错）：若题干说"文件在**同一磁道连续**存放"，寻道只发生**一次**（磁头移过去后停在原磁道连续读），总时间 = 寻道 + N×(旋转+传输)，不能每块都算寻道；旋转延迟给"平均（半圈）"还是"整一圈"，以题干为准，不要自行取平均。

### 磁盘调度算法（★★★ 计算）

磁头一次只在一个位置，多个磁道访问请求排队，按什么顺序服务？目标：**平均寻道距离最短**。

| 算法 | 规则 | 特征 |
|---|---|---|
| FCFS 先来先服务 | 按请求到达顺序 | 公平但寻道长；方向随时变 |
| **SSTF** 最短寻道时间优先 | 每次选**距当前磁头最近**的请求 | 贪心，效率高；可能让远处请求"饥饿"；方向随时变 |
| **SCAN** 扫描（电梯） | 沿一个方向扫，沿途服务，**到端头再折返**（题目会说明端头规则） | 不饥饿；方向固定到头才变 |
| C-SCAN 循环扫描 | 扫到端头后直接跳回另一端再同方向扫 | 各磁道等待更均匀 |

**解题模板**：① 列出请求磁道号和磁头起点；② 按算法规则排出服务顺序；③ 相邻两站求距离差绝对值；④ 全部加总 = 移动道数；除以请求数 = 平均寻道长度。

**代入算例**：磁头在 60 号磁道，请求队列：40、70、25、90、65、10。
- **SSTF**：60→65（5）→70（5）→90（20）→40（50）→25（15）→10（15），总移动 = 5+5+20+50+15+15 = **110 道**。验算两遍：① 逐站确认"最近"——60 处各请求距离 40:20、70:10、25:35、90:30、65:5、10:50，选 65 ✓；65 处 70:5 最近 ✓；70 处 90:20 < 40:30 ✓；90 处 40:50 最近（25:65、10:80）✓；② 路径逐段累加复核：5+5=10，+20=30，+50=80，+15=95，+15=110 ✓。
- **SCAN**（题干设定：磁头朝磁道号增大方向移动，移动到最外侧磁道 199 才折返）：60→65→70→90→199→40→25→10。总移动 = (199−60) + (199−10) = 139 + 189 = **328 道**。验算逐段：5+5+20+109+159+15+15 = 5+5=10，+20=30，+109=139，+159=298，+15=313，+15=328 ✓。

**反例演示（易错）**：① SCAN 是否"必须扫到磁盘端头再折返"，**不同题干设定不同**——有的按"到该方向最后一个请求即折返"处理。务必先读题干：本题明确说"到 199 号磁道才折返"，就必须走到 199，不能在 90 就回头（若在 90 折返则总移动 = (90−60)+(90−10) = 110）；② SSTF 每一步都要**重新**找最近，不是全局排序一次。

### I/O 软件的四层结构与缓冲（★★）

**四层结构**（从上层到下层）：
| 层次 | 职责 | 例 |
|---|---|---|
| 用户层软件 | 面向应用封装 I/O 库函数 | printf、read 系统调用封装 |
| 设备独立性软件 | 与具体设备无关的公共逻辑：命名、缓冲、设备分配 | 缓冲管理、分配设备 |
| 设备驱动程序 | 与具体设备相关，把上层动作翻译成该设备命令 | 向打印机控制器发指令 |
| 中断处理程序 | 设备完成后中断、唤醒等待进程 | 传输完毕收尾 |

**应试动作**："缓冲归哪层管" → 设备独立性软件；"与具体设备相关、翻译成指令" → 设备驱动程序；"最贴近硬件的两级" → 设备驱动 + 中断处理。

**单缓冲 / 双缓冲时间（★ 计算）**：
- 动机：CPU 与外设速度差几个数量级，不能干等，于是设缓冲。核心差异在**重叠**：单缓冲只有一个格子，处理当前块时下一块**不能开始传**（串行）；双缓冲有两个格子，处理 A 的同时可以传 B（并行）。
- 通用形式：设传一块 t、处理一块 c、共 N 块——
  - 单缓冲（传/处串行）：总时间 = **N·(t+c)**；
  - 双缓冲（传与处可并行）：瓶颈是较慢者，总时间 = **N·max(t,c) + min(t,c)**。
- 代入算例：t = 2ms、c = 6ms、N = 10：单缓冲 = 10×(2+6) = **80ms**；双缓冲 = 10×6 + 2 = **62ms**（处理 c 是瓶颈，10 次处理 60ms，加上开头一次传输 2ms）。
- 手算口诀：**"单缓冲串着加，双缓冲看瓶颈（大的乘 N、小的只在尾巴加一次）"**。
- 反例演示（易错）：把单缓冲也按双缓冲的"瓶颈×N + min"算（会少算——单缓冲中间的传输与处理完全串行）；双缓冲里把小的也乘 N（双缓冲中传输与处理重叠，只多出开头那一次，不逐块叠加）。

### Spooling 与虚拟设备

打印机是**独占设备**，一人占用整台机器别人只能干等。**Spooling（假脱机）技术**用磁盘当中转站：打印请求先排队写进磁盘上的输出井，打印进程慢慢取——用户感觉"随时都能提交打印"，仿佛打印机人人可共享。这种由独占设备改造出来的、逻辑上可共享的设备叫**虚拟设备**。特征词：**"独占设备改造成共享设备"→ Spooling → 虚拟设备**，三者一条链。

**应试动作**：① 存取时间三段构成背下来，"寻道可优化、旋转无算法"考过判断；② SSTF/SCAN 老老实实列表逐段相加，SCAN 先看题干折返规则；③ 认题：看到"假脱机/输入井输出井"选 Spooling，看到"虚拟设备"想"独占→共享"。

## 第十节 高频计算题型专攻（应试模板汇总）

本课所有计算题的考场流水线，考前把这张表过一遍：

| 题型 | 第一步 | 核心动作 | 验算方法 |
|---|---|---|---|
| **信号量取值范围** | 找资源数 k、进程数 n | 范围 [k−n, k] | 最小值含义 = 全部进程都在排队 |
| **前趋图 PV 填空** | 数弧 → 定信号量 | V 在弧**起点末尾**、P 在弧**终点开头** | 逐弧检查"一弧一 V 一 P" |
| **死锁资源数** | 认 m、w、n | n = m(w−1)+1 不死锁；n ≤ m(w−1) 可能死锁 | 反代：把答案代回公式看是否自洽 |
| **银行家安全序列** | 求 Need、Available | 反复找 Need ≤ Available 者执行并归还 | 找不到时验证"所有进程 Need > Available" |
| **页式地址变换** | 页大小化成 2^k | 低 k 位是页内地址（不变），高位查页表换帧号 | 十进制走一遍：物理 = 帧号×页大小+偏移 |
| **页面置换** | 画表逐位模拟 | 命中不淘汰；LRU 看过去、OPT 看未来 | 缺页数 = 串长 − 命中数 |
| **位示图** | 认清编号起点 | 字号 ⌊b/w⌋、位号 b mod w；字数 = 总块数/w | 乘回去：字号×w+位号 = 块号 |
| **索引文件最大长度** | 算每块地址项数 B/A | d + B/A + (B/A)² 块 × B | 分层逐项相加复核 |
| **磁盘调度** | 认起点、方向、折返规则 | 逐段绝对差相加 | 路径两头相减粗验（SCAN 到端头型：(端−起点)+(端−最远反端)） |
| **周转时间** | 列到达/运行时刻表 | 完成 = max(上一完成时刻， 到达) + 运行；周转 = 完成 − 到达 | 平均值介于最短/最长周转之间 |

**考场提示**：这类题是"送分题里最费草稿的"——一定画表，不心算；算完用表里最后一列的验算法快速复核，30 秒能拦住绝大多数失分。
