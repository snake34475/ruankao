# 05.5 文件管理 ★★

### 索引文件计算（★★★）

**动机**：文件占很多离散的磁盘块，怎么记录"这个文件都放在哪些块"？——给文件建一张"块号清单"（索引表），清单本身也占块。索引表放不下怎么办？搞**多级索引**：一级索引块里存的不再是数据块号，而是"二级索引块的块号"，二级里才存数据块号。

- **通用形式**（UNIX 式索引节点）：设磁盘块大小 B、每个地址项占 A 字节，则一个索引块能存 **B/A** 个块号。若索引节点含 d 个**直接地址**（直接指向数据块）、1 个**一级间接**（指向的块里全是数据块号）、1 个**二级间接**（指向的块里全是"一级间接块"号），则文件最大长度 = (d + B/A + (B/A)²) × B。
- **代入算例**：块大小 1KB，地址项 4B，索引节点含 10 个直接、1 个一级间接、1 个二级间接：
  - 每个索引块存块号数 = 1KB ÷ 4B = 1024 ÷ 4 = 256 个；
  - 直接部分 10 × 1KB = 10KB；一级间接 256 × 1KB = 256KB；二级间接 256 × 256 = 65536 块 = 65536KB = 64MB；
  - 最大文件 = 10KB + 256KB + 65536KB = **65802KB ≈ 64.25MB**。
- **手算口诀**：**"直接乘，一级乘一次，二级平方乘"**——先算每块能装几个地址项（B/A），直接地址管 d 块，一级管 B/A 块，二级管 (B/A)² 块。

**反例演示（易错）**：二级间接的块数是 **(B/A)²** 不是 2×(B/A)——"二级"是嵌套两层，一层 256 个指向下一层，下一层每块再 256 个，256×256 = 65536，不是 512。

**索引文件逻辑块号落级定位（真题型，公式三件套）**：
- 动机：给文件某一**逻辑块号**，问它落在直接 / 一级 / 二级哪一级、访问要读几次盘。
- 通用形式：设 d 个直接地址、每索引块装 q 个块号（q = 块大小 ÷ 地址项大小）。则
  直接段 = 逻辑块号 0 ～ d−1；
  一级段 = 逻辑块号 d ～ d+q−1；
  二级段 = 逻辑块号 d+q 起（最多到 d+q+q²−1）。
  访问次数：直接 1 次、一级 2 次、二级 3 次（每升一级多读一个索引块）。
- 代入算例：块 1KB、地址项 4B → q = 256；10 直接 + 1 一级 + 1 二级。
  - 范围表：直接 0～9；一级 10～265；二级 266 起。
  - 逻辑块号 5 → 直接 → 读 **1** 次；70 → 一级 → 读 **2** 次；300 → 二级 → 读 **3** 次。
- 手算口诀：**"直接从 0 数 d 块，一级接 q 块，再往后全两级"**；访问次数"几级几读"（直接不用读索引块所以 1 次，一级、二级分别 2、3 次）。
- 反例演示（易错）：一级起点写成 d+1（第 11 块）——直接段含 0～9 共 10 块，一级应从**第 10 块**（逻辑块号 10）开始；访问直接段块时误加"读索引块"的次数。

### 位示图计算（★★★）

**动机**：磁盘上哪些块空着、哪些被占？给全盘每个物理块安排 1 个比特：0 空闲、1 占用——这张比特表就是**位示图（bitmap）**。机器按"字"存取，一个字长 w 位能管 w 个块。

- **通用形式**：物理块号 b、字长 w、**均从 0 开始编号**：字号 = **⌊b / w⌋**，位号 = **b mod w**；位示图总字数 = ⌈总块数 / w⌉，其中总块数 = 磁盘容量 ÷ 物理块大小。
- **代入算例**：字长 32 位，块号 1000：1000 ÷ 32 = 31 余 8 → 字号 31、位号 8（即第 32 个字的第 9 位，若按从 1 计数）。验算：31×32 + 8 = 992 + 8 = 1000 ✓。
- **手算口诀**：**"除留字号，余做位号；容量除块得总块，总块除字长得字数"**。

容量型算例：磁盘 160GB、物理块 1MB、字长 32 位：总块数 = 160×1024 ÷ 1 = 163840 块；字数 = 163840 ÷ 32 = **5120 字**。验算：160GB = 163840MB，除以 1MB/块得 163840 块，除以 32 位/字得 5120 ✓。

**反例演示（易错）**：① 题干会说明块号、字号"从 0"还是"从 1"编号——从 0 换算成第几个时要 +1（从 1 计数时 1000 号块在第 32 个字）；② 忘了 GB→MB 的 1024 进制换算（160GB = 160×1024MB，不是 160×1000）。

**从 0 还是从 1 编号（必背对照）**：

| 起点 | 求字号 / 位号 | 换算成"第几个字 / 第几位" |
|---|---|---|
| 从 0 编号 | 字号 = ⌊b/w⌋，位号 = b mod w | 第（字号+1）字、第（位号+1）位 |
| 从 1 编号 | 字 = ⌊(b−1)/w⌋+1，位 = (b−1) mod w + 1 | 就写"第该字、第该位"（验算：(字−1)×w+(位−1) = b−1） |

**代入算例（从 1 编号）**：字长 32 位，块号、字号、位号均从 1 编号，物理块 1000 记录在哪？字 = ⌊(1000−1)/32⌋+1 = ⌊999/32⌋+1 = 31+1 = **32**；位 = (999 mod 32)+1 = 7+1 = **8**。验算：(32−1)×32 + (8−1) = 31×32 + 7 = 999 = 1000−1 ✓。

**口诀**：**"从 0 直接除；从 1 先减 1、商加 1"**。

### 目录、路径与文件控制块（★）

**文件控制块 FCB**：目录里每个文件都有登记项，记文件名、类型、物理位置、长度、存取权限等，这一登记项就是 **FCB**。目录是 FCB 的集合，两级作用：**文件名 → FCB → 物理地址**。注意 FCB 只是登记信息，**不含文件内容本身**。

**多级（树形）目录对比**：
| 目录结构 | 特点 | 是否允许重名 |
|---|---|---|
| 一级（单级）目录 | 全盘一张表 | **不允许**同名 |
| 二级目录 | 主目录 + 各用户子目录 | 不同用户可同名 |
| 树形（多级）目录 | 从主目录任意分层 | **不同目录下允许**同名 |

- **绝对路径**：从**根（盘符）**开始写全；**相对路径**：从**当前目录**开始。考法：给目录树和当前目录，写某文件的两条路径，或问"从当前目录出发少走了哪一段"。
- **Linux 权限数值（★★）**：三组权限 rwx（属主 Owner / 同组 Group / 其他 Others），每组 r=4、w=2、x=1 相加成一位数字，三位即如 `chmod 754`。`754`：属主 7 = rwx、同组 5 = r-x、其他 4 = r--。口诀：**"r=4、w=2、x=1，数字是三者和"**。
- **反例演示（易错）**：把 `755` 的"5"当成 rwx——5 = r-x，**缺 w**；绝对/相对路径写反根起点，按"从根 / 从当前目录"逐级写即对齐。

**应试动作**：① 索引文件公式背"每块地址数 = 块大小 ÷ 地址项大小"，二级平方；② 位示图两套小题（定位、容量）套口诀；③ 注意题目给的是 KB/MB/GB 混合单位，先统一成同一单位再除。
