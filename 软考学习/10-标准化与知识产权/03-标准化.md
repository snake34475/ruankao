# 10.3 标准化：分级、代号与强制推荐 ★★

**动机**：软件要互联互通，就得有统一的标准（协议格式、编码规范、质量体系）。考试考的不是标准内容本身，而是**看到代号能归类、听到说法能判断强制还是推荐**。

### 我国标准的层级与代号

| 层级 | 代号 | 举例与说明 |
|---|---|---|
| **国家标准** | **GB**（强制性）、**GB/T**（推荐性，T = 推荐 tuī）、**GB/Z**（指导性技术文件，Z = 指 zhǐ） | GB 18030 强制编码标准；GB/T 19001 质量管理体系推荐标准 |
| **行业标准** | 各行业主管部门代号，如 **SJ**（电子）、**YD**（通信）、**JB**（机械）、**DL**（电力）、**HB**（航空）、**GA**（公安） | SJ/T 即电子行业推荐性标准 |
| **地方标准** | **DB**（DB + 省级行政区划代码，如 DB11/T 为北京地方推荐性标准） | 适用于本行政区域内 |
| **企业标准** | **Q/**（企业代号） | 企业内制定，要求不得低于强制性国家标准 |
| 团体标准 | T/ + 团体代号 | 2018 年新《标准化法》新增的层级，了解即可 |
| **国际标准** | **ISO**（国际标准化组织）、**IEC**（国际电工委员会）、**ITU**（国际电信联盟）制定的标准，以及 ISO 确认并公布的其他国际组织标准 | ISO 9001 是国际标准（我国转化为 GB/T 19001 采用） |

**强制性 vs 推荐性**：代号里**带 T（推荐）就一定不是强制性**；GB（不带 T）是强制性国家标准，**必须执行**。按 2018 年施行的新《标准化法》，强制性标准严格限定在**国家标准**层面（行业、地方标准均为推荐性），旧教材里"强制性行业标准/强制性行地标"的说法是修订前的口径——考试认代号判推荐/强制即可，代号是绝对可靠的判别依据。

**标准也会过期**：标准实施后要定期复审，**复审周期一般不超过 5 年**——技术迭代快，5 年不改的标准可能已经落伍。

**记忆口诀**：「国行地企四层级，T 是推荐不带强制，GB 强制必须执行，复审五年不超期」。反例演示：把 GB/T 19001 判成"强制性国家标准"——错，带 T 即推荐性；把 ISO 9001 判成"国家标准"——错，它是国际标准，我国只是**等同采用**转化为 GB/T。

**团体标准代号里的 T 最容易和 GB/T 记混**：两者都有字母 **T**，但**位置**不同，别当成一回事——
- **GB/T**：T 在「国标代码 GB」**后面**，表示**推荐性国家标准**；
- **T/团体代号**：T 孤悬在**最前面、后面带斜杠**，这里的 T 是「团体 Tuántǐ」的首字母，紧跟其后的是团体代号（如 T/某协会代码）。

识别特征一句话：**T 在后是"推荐"，T 在前是"团体"**。反例：把 T/XXX 当成"推荐性标准"来选——错，它是团体标准；把 GB/T 当成"团体标准"——同样错，它是推荐性国家标准。团体标准由**社会团体**（行业协会、学会等）协调相关市场主体共同制定，是 2018 年新《标准化法》新增的层级，管谁用谁自担责任，属了解即可的考点。

**与已学内容的联系**：[03-软件工程基础.md](../03-软件工程基础/06-软件质量与文档.md) 讲的软件质量模型（ISO 9126）就是以"ISO 国际标准"形式发布的，两者代号判别口径一致。

**应试动作**：背代号表的两列——代号 → 层级、带不带 T → 强制/推荐。认题特征：题干直接给一个标准号（GB 18030、SJ/T 10796、DB11/T、Q/ABC、ISO 9001）问归类，或给"标准复审周期是几年"（5 年）。纯识别题，看到 T 就选推荐。
