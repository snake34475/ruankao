# 01.9 精华题与补充题

1. 【遍历还原】某二叉树的中序序列为 BDCEAFHG，后序序列为 DECBHGFA，画出/写出该二叉树的前序序列。

2. 【哈夫曼】设字符集 {a,b,c,d,e} 出现频率为 {5, 2, 3, 1, 4}，构造哈夫曼编码（左 0 右 1），求 WPL 及各字符编码长度。

3. 【散列表】哈希函数 H(key)=key%7，表长 8，用线性探测法处理冲突。依次插入关键字 15, 22, 8, 29, 36。给出各关键字最终存储位置，并计算查找成功的平均查找长度 ASL。

4. 【关键路径】某 AOE 网活动：a1: V1→V2 工期 3；a2: V1→V3 工期 2；a3: V2→V4 工期 4；a4: V3→V4 工期 5；a5: V4→V5 工期 1（V1 为源点，V5 为汇点）。求关键路径及总工期，指出各活动的最早/最迟开始时间与时间余量。

5. 【排序判别】对序列 {25, 84, 21, 47, 15, 27, 68, 35, 20} 进行某种排序，第一趟结束后序列变为 {20, 15, 21, 25, 47, 27, 68, 35, 84}，这是哪种排序？（提示：25 和 84 都到了最终位置附近，注意 25 左右两侧的大小关系）

6. 【复杂度】下列代码段的时间复杂度是（ ）？
   ```c
   for (i = 1; i <= n; i *= 2)
       for (j = 1; j <= n; j++)
           sum++;
   ```

7. 【拓扑排序】有向图边：A→B, A→C, B→D, C→D, D→E。写出所有可能的拓扑序列（共几种？）。

## 补充题（第三节 图 专项）

> 第三节从 50 行扩写到 500 多行后补的练手题：最小生成树、关键路径、遍历与度数各一题；后来又补了两道关键路径题（一题完整计算、一题压缩工期）。做完再看末尾的「补充题答案」。

**1【最小生成树】** 带权无向图 G：顶点 A、B、C、D、E；边及权值：
A-B 6、A-C 4、B-C 1、B-D 5、C-D 2、C-E 7、D-E 3。

- (1) 求该图最小生成树的权值和，并列出选中的边。
- (2) 说明为什么 A-B 这条边一定不在最小生成树里。

**2【关键路径】** 某 AOE 网中活动及工期如下（V1 为源点、V5 为汇点）：

| 活动 | 起止 | 工期 |
|---|---|---|
| a1 | V1→V2 | 6 |
| a2 | V1→V3 | 4 |
| a3 | V2→V4 | 1 |
| a4 | V3→V4 | 5 |
| a5 | V4→V5 | 3 |
| a6 | V3→V5 | 9 |

- (1) 求整个工程的最短工期。
- (2) 写出关键路径（用顶点序列表示）。
- (3) 逐个求出各活动的时间余量，指出哪些活动一天都不能推迟、哪些可以推迟及最多推迟多久。

**3【遍历与度数】** 无向图 G 的边为：1-2、1-3、2-4、3-5、4-5、2-3。从顶点 1 出发遍历，邻接点一律按编号**从小到大**访问。

- (1) 写出深度优先遍历（DFS）得到的顶点序列。
- (2) 写出广度优先遍历（BFS）得到的顶点序列。
- (3) 该图有多少条边？所有顶点的度数之和是多少？这个图有几个连通分量？

**4【关键路径 · 完整计算】** 某 AOE 网中活动及工期如下（V1 为源点、V6 为汇点）：

| 活动 | 起止 | 工期 |
|---|---|---|
| a1 | V1→V2 | 4 |
| a2 | V1→V3 | 3 |
| a3 | V2→V4 | 5 |
| a4 | V3→V4 | 2 |
| a5 | V3→V5 | 5 |
| a6 | V4→V6 | 3 |
| a7 | V5→V6 | 2 |

- (1) 顺推求各事件的 ve，写出总工期。
- (2) 逆推求各事件的 vl（注意 V3 有两条出边）。
- (3) 求各活动的 e、l 与时间余量，指出哪些是关键活动。
- (4) 写出关键路径，并说明它是否唯一。

**5【关键路径 · 压缩工期】** 某 AOE 网中活动及工期如下（V1 为源点、V5 为汇点）：

| 活动 | 起止 | 工期 |
|---|---|---|
| a1 | V1→V2 | 6 |
| a2 | V1→V3 | 3 |
| a3 | V2→V4 | 3 |
| a4 | V3→V4 | 4 |
| a5 | V4→V5 | 2 |

- (1) 求总工期与关键路径，并指出活动 a2 的时间余量。
- (2) 若只把 a1 的工期从 6 天压缩到 4 天，总工期变成多少？此时关键路径有几条？
- (3) 若把 a1 继续压缩到 3 天，总工期还能再缩短吗？为什么？
