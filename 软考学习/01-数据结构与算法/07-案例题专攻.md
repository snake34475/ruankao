# 01.7 案例题专攻：算法填空解题套路

案例第 4 题一般是「一段说明 + C 代码（或伪代码）+ 3～5 个空 + 1 小问」，常考：动态规划、贪心、回溯、字符串处理、链表/树操作。**套路如下：**

### 套路一：先读说明再读代码，说明就是答案说明书
题干「说明」部分会用文字描述算法步骤，例如"第 3 步：若 a[i] 大于当前最大值，则更新最大值"。**空基本就藏在文字步骤对应的代码行上，照着文字填代码。**

### 套路二：看空的位置判断要填什么
1. **空在初始化处**：常填 `0`、`1`、`-1`、`INT_MAX` 或数组首元素 `a[0]`。
2. **空在循环条件**：看循环变量和边界，`i < n`、`j > 0`，或动态规划的 `i <= n`。
3. **空在 if 内部更新处**：动态规划常填递推式 `dp[i] = dp[i-1] + xxx`；求最大值常填 `maxv = a[i]`。
4. **空在递归调用**：填递归式，参数看函数定义对应着填，注意返回值 `return f(...)`。
5. **空在 return**：动态规划常填 `dp[n]` 或 `dp[m][n]`。

### 套路三：代入一个具体例子验证
填完后，用一个 n=2 或 n=3 的小例子手动模拟整段代码，能跑通且结果符合说明，基本就对了。

### 常见考题模板速记
- **0-1 背包**：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])`，j 从大到小滚动数组。
- **最长公共子序列**：字符相等 `dp[i][j]=dp[i-1][j-1]+1`，否则 `max(dp[i-1][j], dp[i][j-1])`。
- **Fibonacci / 爬楼梯**：`f[i] = f[i-1] + f[i-2]`。
- **链表插入**：`s->next = p->next; p->next = s;`（顺序不能反）。
- **链表删除**：`p->next = p->next->next;`。
- **二叉树递归遍历**：`visit(root); f(root->left); f(root->right);` 按序对应前中后序。

### 四大方向的填空模板（除动态规划外）

**贪心**。认题：说明写"每一步都取当前最优（最大、最早、最便宜）"。固定三步：先排序或逐个扫描；每步比较用**贪心选择条件**；选中后**累积答案并推进边界**。
- 活动安排（按结束时间升序后）：`if (s[i] >= lastEnd) { cnt++; lastEnd = f[i]; }`——常挖 `s[i] >= lastEnd` 和 `lastEnd = f[i]` 两处。
- 找零钱：`cnt += a / m` 后再 `a = a % m`——常挖取余一步。
- 验算提醒：贪心不是万能，题干若允许"物品可拆分（分数背包）"按性价比贪心才成立；0-1 背包按价值或重量贪心都可能反例，命题方若写"每件必须整体拿"而让你贪心，多半该回头怀疑，此时改按动态规划模板。

**回溯**。认题：说明写"依次尝试每个候选，不满足就退回换下一个"（八皇后、求全部子集、走迷宫）。固定骨架三段，填空必在其中：
```c
void f(int k) {
    if (/* 到达解的层数，如 k == n */) { output(); return; }
    for (/* 本层每个候选 c */) {
        if (/* 约束检查通过 */) {
            记录第 k 层选择;          // 做选择
            f(k + 1);                 // 进入下一层
            撤销第 k 层选择;          // 回溯：恢复现场
        }
    }
}
```
- 最常挖"记录"与"撤销"成对的两空（如 `x[k] = c;` 与 `used[c] = 0;`），以及约束检查式。
- 验算：代入 n=3 的子集枚举，检查撤销缺失会不会导致候选被重复使用。

**分治**。认题：说明写"分成两（几）个规模更小的子问题，各自求解后合并"。固定三步：拆分点、递归子问题、合并结果。
- 数组求最大：`mid = (l + r) / 2;`，左 `f(l, mid)` 右 `f(mid + 1, r)`，合并 `return max(L, R);`——常挖 `mid` 一行与 `f(mid + 1, r)` 的边界。
- 归并排序：`merge(beg, mid, end)` 常整段挖空，背"双副本指针逐一取小，谁剩整段搬"。
- 汉诺塔：`f(n-1, A, C, B); 移第 n 盘 A 到 C; f(n-1, B, A, C);`——两递归的辅助柱互换是考点。

**字符串处理**。认题：说明写"从头到尾扫描串，统计或转换字符"。固定要点：
- 扫描终止：循环条件 `s[i] != '\0'`（字符串末尾是 `'\0'`，不是 0 个字符也不是空格）。
- 统计型：`if (s[i] == 目标字符) cnt++;`
- 大小写转换：大写转小写 `s[i] = s[i] - 'A' + 'a';`（等价于加 32；考 `c + 32` 也要认得）。
- 回文判断：双指针 `for (i = 0, j = n - 1; i < j; i++, j--)`，发现 `s[i] != s[j]` 即不是回文。

**应试动作**：先在说明里圈"每一步取最优""依次尝试、退回""分成两半""从头扫描"这四类标志词，定方向后再套对应模板；填完仍用套路三代小例子验证。带完整答案的分方向练习见本课 90 文件案例题二（动态规划：LIS）与案例题三（贪心：活动安排）。
