# 01.7 案例题专攻：算法填空解题套路

案例第 4 题一般是「一段说明 + C 代码（或伪代码）+ 3～5 个空 + 1 小问」，常考：动态规划、贪心、回溯、字符串处理、链表/树操作。**套路如下：**

### 套路一：先读说明再读代码，说明就是答案说明书
题干「说明」部分会用文字描述算法步骤，例如"第 3 步：若 a[i] 大于当前最大值，则更新最大值"。**空基本就藏在文字步骤对应的代码行上，照着文字填代码。**

### 套路二：看空的位置判断要填什么
1. **空在初始化处**：常填 `0`、`1`、`-1`、`INT_MAX` 或数组首元素 `a[0]`。
2. **空在循环条件**：看循环变量和边界，`i < n`、`j > 0`，或动态规划的 `i <= n`。
3. **空在 if 内部更新处**：动态规划常填递推式 `dp[i] = dp[i-1] + xxx`；求最大值常填 `maxv = a[i]`。
4. **空在递归调用**：填递归式，参数看函数定义对应着填，注意返回值 `return f(...)`。
5. **空在 return**：动态规划常填 `dp[n]` 或 `dp[m][n]`。

### 套路三：代入一个具体例子验证
填完后，用一个 n=2 或 n=3 的小例子手动模拟整段代码，能跑通且结果符合说明，基本就对了。

### 常见考题模板速记
- **0-1 背包**：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])`，j 从大到小滚动数组。
- **最长公共子序列**：字符相等 `dp[i][j]=dp[i-1][j-1]+1`，否则 `max(dp[i-1][j], dp[i][j-1])`。
- **Fibonacci / 爬楼梯**：`f[i] = f[i-1] + f[i-2]`。
- **链表插入**：`s->next = p->next; p->next = s;`（顺序不能反）。
- **链表删除**：`p->next = p->next->next;`。
- **二叉树递归遍历**：`visit(root); f(root->left); f(root->right);` 按序对应前中后序。
