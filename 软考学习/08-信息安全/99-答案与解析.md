# 08.6 答案与解析

### 课后考题答案

**1. B**
"篡改首页内容"改动了数据，破坏**完整性**。A 机密性对应"偷看/泄露"；C 可用性对应"服务瘫痪、用不了"；D 不可否认性对应"发过却抵赖"。配对口诀"看改断造对密完用真"，见第一节 1.1 表。

**2. A**
被动攻击 = 只看不改。流量分析只观察通信模式与流向，不改任何数据，属被动攻击。B 重放"重发了旧报文"、C 拒绝服务"发洪流砸服务"、D 篡改"改了数据"，都动了手，全是主动攻击。这是真题原考点：把"流量分析"塞进主动攻击选项里设坑。

**3. B**
DES 是**对称（共享密钥）加密**算法：分组 64 位、有效密钥 56 位，加解密同一把钥匙。A 非对称代表是 RSA/ECC；C 摘要代表是 MD5/SHA；D 数字签名不是算法类别而是一种技术应用。归类口诀：DES/AES/IDEA → 对称；RSA/ECC → 非对称。

**4. C**
公钥可以随便给、私钥自己藏——这正是非对称体制解决密钥分发问题的核心。A 反了，对称快、非对称慢（差 1～2 个数量级）；B 反了，对称加密加解密用**同一把**；D 反了，RSA 慢，只适合加密少量数据（如密钥、摘要），大文件交给对称算法。

**5. C**
对称体制下每两人共用一把密钥：C(10,2) = (10×9)/(2×1) = **45**。交叉验证：第 1 人要与其余 9 人各一把共 9 把，第 2 人再与新对象配 8 把……9+8+…+1 = 9×10/2 = 45 ✓。B（20）是误用非对称算法 2n=20；D（90）是误算 n(n−1)=90，忘了除以 2（同一把钥匙被两人共用，不能算两次）。

**6. B**
数字信封标准流程：**对称密钥管大数据（快），对方公钥只管那一小段对称密钥（好分发）**。A 反了——用公钥加密全部大数据太慢，对称密钥也没必要"加密乙的私钥"；C、D 都出现了"加密私钥"这种无意义操作，且用乙的私钥加密甲根本做不到（乙的私钥只有乙有）。

**7. C**
Hash 函数**无密钥**：任何人算同一文件的摘要结果都一样，这正是它可用于第三方完整性验证的原因。A、B、D 都是摘要的正当特性（定长输出、单向性、雪崩效应）。本题逆向选"不具备的"，审题别顺拐。

**8. B**
MD5 摘要 **128 位**；C（160 位）是 SHA-1 的摘要长度——这两个数字是历年选择题挖坑对挖的经典搭档，一起背。

**9. A**
签名是甲用**甲的私钥**做的，验证必须用配对的**甲的公钥**（验签 = 用发方公钥解签名、比对摘要）。C/D 是乙自己的钥匙对，用于"发给乙的密文"的加解密，与验签名无关。速查表见第四节 4.2。

**10. D**
签名管"真、赖不掉、没被改"（A 真实性、B 不可否认性、C 完整性），但签名后的"正文+签名摘要"是**明文**发送的，第三方照样能看——机密性要靠再用对方公钥加密（第四节 4.3）。

**11. B**
完整流程：甲用**甲私钥**签摘要（证明是甲），再用**乙公钥**加密整包（只有乙能拆）。A 方向错乱："公钥签名"不能证明身份（公钥人人有），"私钥加密消息"乙没有甲的私钥解不开；C 用对方公钥签名、用自己公钥加密，两处都错；D 用乙的私钥——甲根本拿不到乙的私钥。口诀"先签后封，私签公验；封用收方公"。

**12. A**
证书里装的就是**持有者的身份 + 持有者的公钥**。B 错——证书上的签名是 CA 做的，验证要用 **CA 的公钥**；C 错——证书由权威机构 CA 签发，不是持有者自制（自制就无公信力可言）；D 错——**任何人的私钥都不进证书**，私钥永远自己保管。

**13. C**
包过滤防火墙在**网络层**按 IP、端口等头部字段过滤。A 应用层是应用代理防火墙的地盘；会话层、物理层不承担包过滤功能。配套记忆：包过滤"网络层看头"，应用代理"应用层看内容"。

**14. C**
防火墙守在**内外网边界**，对内部人员之间的攻击无能为力——"不防内部"是它最经典的局限性，考"不正确的是"就选它。A、B、D 都是防火墙的正当功能（控制包流向、日志审计、隐藏内部结构）。

**15. A**
题干关键词"**截获合法报文 + 原样重发**"正是重放攻击的定义，主战场是身份认证。B SQL 注入是在输入里夹带 SQL 片段；C DDoS 是海量请求拖垮服务；D 钓鱼是仿冒诱骗用户主动交出凭证。防重放靠时间戳/一次性口令（见精华题 4）。

**16. 案例题答案**

（1）**单向 Hash 函数**（信息摘要函数）。要求"未被篡改"，靠摘要比对实现；只有乙能读取靠加密实现，两者分工明确。

（2）**甲的私钥**。签名永远用发送方自己的私钥——私钥唯一，签了才赖不掉，满足要求②的"确实由甲发出"。

（3）**乙的公钥**。要求①"只有乙能读取"是保密方向，用接收方乙的公钥加密，全世界只有持有对应私钥的乙能解开。

（4）乙先用**自己的私钥**解密，得到"指令+签名"；再用**甲的公钥**验证签名，并用**同一个 Hash 函数**重算指令摘要、与解出的摘要比对，一致则确认出自甲且未被篡改。

（5）这种攻击叫**重放攻击**。防御：在认证报文中引入**时间戳**（过期作废）或**一次性口令/挑战-应答**（每次认证用一次性凭据），让"旧报文"重发时失效。

### 精华题答案

**1. A**
两步定式："私签公封"——甲私钥签名（认证自己），乙公钥加密（保密给乙）。B 用甲的公钥"签名"（谁都能做，无效）+ 用乙的私钥加密（甲拿不到乙的私钥）；C、D 签名与加密双双方向错乱。凡此类题，先问"这一步要保密还是认证"，再套 4.2 速查表。

**2. B**
证书上的签名是 **CA 用自己的私钥**盖的章，验证自然用 **CA 的公钥**。A 的网站公钥是证书里**被证明的对象**，不是验证工具；C 用户自己的公钥与本证书无关；D 私钥永远不外露，也不用于验证。

**3. D**
防火墙管外不管内，"不防内部攻击"是正确描述。A、B 两个工作层次正好说反：**包过滤=网络层看头部，应用代理=应用层看内容**；C 错——不经过防火墙的连接（如内部私拉拨号）它无法防范，这正是局限性之一。

**4. A**
重放攻击的命门是"旧报文依然有效"，所以给凭据**加时效或改成一次性**（时间戳 / 一次性口令）即可防住。B 是保密与身份手段，管不住"报文本身合法但是旧的"；C 是防火墙手段；D 增加密钥长度对抗的是破解，与报文新旧无关。

**5. B**
题干三个关键词"**不寄生（无宿主）+ 漏洞自我复制 + 网络主动传播**"是蠕虫的画像。A 病毒必须依附宿主程序；C 木马靠伪装驻留做远程控制、不自我复制；D 逻辑炸弹靠条件触发。口诀"病毒寄生、蠕虫自爬、木马开门、炸弹看日子"。

**6. C**
海量请求把服务器"砸瘫"，合法用户要用时用不了——破坏**可用性**（对应安全攻击里的"中断"）。A 窃听破坏机密性；B 篡改破坏完整性；D 伪造破坏真实性/不可否认性。四类攻击"截获—篡改—中断—伪造"与属性的配对要形成条件反射。
