# 07.1 编译、解释与语言基本成分 ★★★

**动机**：计算机 CPU 只认识机器码（0/1 指令），而我们写的是高级语言（C、Java、Python…）。中间必须有一个"翻译程序"把高级语言翻译成机器能执行的东西。按翻译方式不同，分两大流派：

| 对比项 | 编译方式 | 解释方式 |
|---|---|---|
| 代表语言 | C、C++、Pascal、Fortran | Python、PHP、JavaScript、Ruby |
| 翻译过程 | **整本翻译**：源程序一次性翻译成目标程序（机器码） | **逐句翻译**：边解释边执行，翻译一句执行一句 |
| 是否生成目标程序 | **生成** | **不生成** |
| 执行效率 | 高（运行时不再翻译） | 低（运行时还要翻译） |
| 灵活性/可移植性 | 差（目标程序绑定具体机器） | 好（源程序拿到哪都能跑） |
| 翻译程序是否参与执行 | 编译器**不参与**执行 | 解释器**参与**执行 |

共同点：两种方式**都**要做词法分析、语法分析、语义分析——别以为解释器就"不分析"，它只是不生成目标程序。

**记忆口诀**：编译"先翻完再念"，解释"边念边翻"——像拿到一本外文书：编译是请人整本翻译好再读，解释是请个翻译坐在旁边念一句你听一句。

**Java / C# 是特殊流派（选择题爱考）**：它们**先编译成中间代码**（Java 字节码 / .NET 中间语言），**再由虚拟机（JVM / CLR）解释或即时编译执行**——"先编译后解释"。正因为中间代码与平台无关、各平台各有虚拟机，Java 才能"一次编写，到处运行"。

**反例演示**：判断题「解释方式也会生成与源程序等价的目标程序」——**错**。这是本考点最常见的陷阱选项；解释器从头到尾不产出可独立执行的目标程序。反向陷阱「编译方式执行效率比解释方式低」——错，编译是"先翻完再念"，运行时零翻译开销，效率更高。

**应试动作**：背对比表的三行——①是否生成目标程序（编译生成、解释不生成）②执行效率（编译高）③可移植性（解释好）。考场上题干不会出现"流派"这种词，直接给"某语言程序需先翻译成目标程序后执行""逐句翻译执行"等描述让你归类。

## 第二节 程序设计语言的基本成分 ★★★

**动机**：不同语言的写法看起来差别很大，但任何程序都绕不开四个问题：**数据长什么样、数据怎么算、执行顺序怎么走、数据怎样进出程序**。教材把这四件事概括为数据、运算、控制和传输成分。选择题常把其中一个换成“语法/编译/存储”等干扰词。

| 基本成分 | 解决的问题 | 常见内容 | 最小例子 |
|---|---|---|---|
| **数据成分** | 程序处理什么 | 数据类型、变量、常量、数据结构 | `int age`、Python 列表 |
| **运算成分** | 数据怎样变化 | 算术、关系、逻辑、位、赋值运算 | `total = price * count` |
| **控制成分** | 语句按什么顺序执行 | 顺序、选择、循环 | `if`、`for`、`while` |
| **传输成分** | 数据怎样进入、离开或跨过程传递 | 输入/输出、参数、返回值、文件与网络读写 | `read()`、`print()`、`return` |

**反例演示（易错）**：“整数、字符、布尔”属于数据成分，不是运算成分；`if` 决定走哪条路径，属于控制成分；`+`、`&&`、赋值号描述数据上的操作，才属于运算成分。题目问“可计算问题的程序都能由哪三种控制结构描述”，答**顺序、选择、循环**，不要把函数调用当第四种基本控制结构。

### 2.1 数据成分：类型决定“能存什么、能做什么”

数据类型不只是规定占多少空间，还规定**取值范围和允许的运算**。例如布尔值可以做逻辑运算，整数可以做取模；字符串能拼接，却不能直接参与数值除法。第三节编译知识中的“类型不合法”之所以能在语义分析阶段发现，就是因为类型带着运算规则。

C/C++ 常见基本类型有整数、浮点、字符、布尔、枚举和指针。Python 高频容器要按两个维度分：

| 类型 | 是否有序 | 是否可变 | 是否允许重复 | 取元素方式 |
|---|---:|---:|---:|---|
| `list` 列表 | 是 | **可变** | 是 | 下标 |
| `tuple` 元组 | 是 | **不可变** | 是 | 下标 |
| `str` 字符串 | 是 | **不可变** | 是 | 下标 |
| `set` 集合 | 否 | **可变** | **否** | 不能按位置下标 |
| `dict` 字典 | 按插入次序保存键值对 | **可变** | 键不可重复 | 键 |

**反例演示**：`tuple` 不可变，表示不能把其中某个位置重新赋值，不等于“元组里引用的可变对象永远不会变化”；考试只考第一层结论，记作“字符串、元组不可变；列表、集合、字典可变”。集合去重且不靠位置取值，不能因为打印时看见某个顺序就把它当列表。

### 2.2 运算成分：同一个符号要结合类型理解

- 算术运算：`+ - * / %`；
- 关系运算：`< <= == != >= >`，结果通常是布尔值；
- 逻辑运算：`and/or/not` 或 `&&/||/!`；
- 位运算：按二进制位与、或、异或、移位；
- 赋值运算：把计算结果写回变量。

Python 中 `+` 对数字表示相加，对字符串或列表表示拼接；`*` 对数字表示乘法，对字符串或列表可表示重复。例如 `[1,2]+[3]=[1,2,3]`，`'ab'*2='abab'`。这不是符号“随便变义”，而是运算符根据操作数类型选择对应操作。

### 2.3 控制成分：所有流程都能拆成三种结构

1. **顺序**：从上到下依次执行；
2. **选择**：条件为真走一支，为假走另一支；
3. **循环**：条件满足时重复一段操作。

```text
顺序：A → B → C
选择：条件 ─真→ A
           └假→ B
循环：条件 ─真→ A ─┐
           ↑       │
           └───────┘；假→ 离开
```

### 2.4 传输成分：不只是键盘输入和屏幕输出

传输成分负责数据在不同边界之间移动：用户与程序之间有输入/输出，文件与程序之间有读/写，调用者与函数之间有参数和返回值，网络两端之间有发送/接收。例如 `x=read()` 把外部数据送入程序，`return result` 把函数结果送回调用者。

**反例演示（易错）**：赋值 `x=x+1` 是运算成分，因为数据只在程序内部被计算并写回变量；`return x` 才是把结果跨越函数边界传回调用者。不要看到“数据发生变化”就一律选传输，关键看是否跨越输入输出或过程边界。

**应试动作**：背“四成分 = 数据、运算、控制、传输”和“三结构 = 顺序、选择、循环”。题干给 Python 类型时按“是否可变、是否有序、是否去重、怎样取值”四问排除；题干给 `+、*` 时先看操作数类型，再判断实际运算。
