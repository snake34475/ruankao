### 案例题风格题

**案例 1**　某程序片段如下：

```
function calc(p, q) {
    q = q - p;
    p = p - q;
    return p;
}
主调方：x = 5; y = 3;  r = calc(x, y);
```

问题 1：若 p 采用**传值**、q 采用**引用**调用，给出函数执行后 r、x、y 的值（列出每句执行后各变量状态）。
问题 2：若 p、q **都采用传值**调用，r、x、y 又是多少？
问题 3：对比两种结果，用一句话说明传值与引用调用的本质区别。

**案例 2**　某 DFA 的状态转移表如下（q₀ 为初态，q₂ 为终态，字母表 {a, b}）：

| 状态 | 输入 a | 输入 b |
|---|---|---|
| →q₀ | q₁ | q₀ |
| q₁ | q₁ | q₂ |
| *q₂ | q₁ | q₀ |

问题 1：该自动机识别的字符串有什么共同特征？写出与之等价的正规式。
问题 2：判断 `aab`、`abb`、`abab`、`baab` 中哪些被该自动机接受（逐步列出状态轨迹）。
问题 3：若把 q₁ 对输入 a 的转移改为"q₁ 或 q₂ 均可"，该自动机变成了什么类型？说明判断依据。
