# 11.3 面向对象、设计模式与程序语言词汇 ★★

### 3.1 面向对象

| English | 中文 | 关键词 |
|---|---|---|
| class / object / instance | 类 / 对象 / 实例 | blueprint / concrete occurrence |
| encapsulation | 封装 | hide internal details |
| inheritance | 继承 | derive from a base class |
| polymorphism | 多态 | same interface, different behavior |
| abstraction | 抽象 | focus on essential features |
| interface | 接口 | contract of operations |
| override | 重写 | subclass replaces inherited behavior |
| overload | 重载 | same name, different parameter lists |

`object` 和 `instance` 在许多上下文中都可表示“对象/实例”，但 `class` 是蓝图，instance 是按蓝图创建的具体对象。

### 3.2 高频设计模式英文

| Pattern | 一句话英文识别 | 中文意图 |
|---|---|---|
| Singleton | ensures a class has only one instance | 保证单实例 |
| Factory Method | lets subclasses decide which class to instantiate | 由子类决定实例化谁 |
| Observer | one-to-many dependency; observers are notified | 状态变化时通知观察者 |
| Strategy | encapsulates interchangeable algorithms | 封装可替换算法 |
| Adapter | converts one interface into another expected by clients | 转换接口 |
| Decorator | adds responsibilities to an object dynamically | 动态增加职责 |
| Proxy | controls access to another object | 控制对象访问 |
| Facade | provides a unified interface to a subsystem | 为子系统提供统一入口 |

### 3.3 编译与算法

| English | 中文 |
|---|---|
| lexical analysis | 词法分析，把字符流变成 token |
| syntax analysis / parsing | 语法分析，检查结构 |
| semantic analysis | 语义分析，检查类型和含义 |
| intermediate code | 中间代码 |
| optimization | 优化 |
| executable | 可执行文件；也可作形容词“可执行的” |
| recursion | 递归 |
| iteration | 迭代 |
| greedy algorithm | 贪心算法 |
| dynamic programming | 动态规划 |
| divide and conquer | 分治 |
| time/space complexity | 时间/空间复杂度 |

**应试动作**：模式名不只背中文。看到 `notified automatically` 想 Observer；`interchangeable algorithms` 想 Strategy；`convert an interface` 想 Adapter；`only one instance` 想 Singleton。
