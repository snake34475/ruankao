# 11.4 数据库、操作系统与网络词汇 ★★★

### 4.1 数据库

| English | 中文 | 典型表达 |
|---|---|---|
| relation / tuple / attribute | 关系 / 元组 / 属性 | table / row / column |
| primary key / foreign key | 主键 / 外键 | uniquely identify / reference another table |
| constraint | 约束 | integrity constraint |
| normalization | 规范化 | reduce redundancy |
| redundancy | 冗余 | duplicated data |
| transaction | 事务 | a logical unit of work |
| atomicity | 原子性 | all or nothing |
| consistency | 一致性 | valid state to valid state |
| isolation | 隔离性 | concurrent transactions appear independent |
| durability | 持久性 | committed changes survive failures |
| concurrency control | 并发控制 | locks, serializability |
| commit / rollback | 提交 / 回滚 | make permanent / undo |
| query / retrieve | 查询 / 检索 | retrieve rows from a table |

ACID 识别句：

- `either all operations occur or none do` → atomicity；
- `concurrent transactions do not interfere improperly` → isolation；
- `committed data survives a crash` → durability；
- `constraints remain satisfied` → consistency。

### 4.2 操作系统

| English | 中文 |
|---|---|
| process / thread | 进程 / 线程 |
| scheduling | 调度 |
| mutual exclusion | 互斥 |
| synchronization | 同步 |
| semaphore | 信号量 |
| deadlock / starvation | 死锁 / 饥饿 |
| virtual memory | 虚拟存储 |
| page fault | 缺页 |
| page replacement | 页面置换 |
| file system | 文件系统 |
| device driver | 设备驱动程序 |
| interrupt | 中断 |

`process` 在操作系统中是“进程”，但作普通动词是“处理”。要用句子位置判断：`a running process` 是名词；`the server processes requests` 是动词。

### 4.3 网络

| English | 中文 | 典型词组 |
|---|---|---|
| packet / frame / segment | 分组 / 帧 / 报文段 | network/data-link/transport layer |
| routing | 路由选择 | select a path |
| forwarding | 转发 | send to next hop |
| bandwidth | 带宽 | capacity per unit time |
| latency | 时延 | time taken to travel/respond |
| throughput | 吞吐率 | actual delivered rate |
| congestion | 拥塞 | too much traffic |
| reliable delivery | 可靠交付 | acknowledgment and retransmission |
| connection-oriented | 面向连接 | TCP |
| connectionless | 无连接 | UDP/IP |
| domain name resolution | 域名解析 | DNS |

**易错反例**：bandwidth 和 throughput 不等价。Bandwidth 像公路理论车道容量，throughput 是实际每秒通过多少车；latency 是一辆车从起点到终点花多久。

**应试动作**：数据库重点背 ACID 的英文定义；操作系统重点背 process/thread、deadlock、page fault；网络重点背 bandwidth/throughput/latency 三分法。
