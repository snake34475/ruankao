# 04.5 设计模式分类与意图速查 ★★★

### 4.1 23 种模式的分类框架（先背骨架）

模式按**目的**分三类——这本身就回答了"为什么有 23 种"：**创建型**管"对象怎么造出来"（5 种）、**结构型**管"对象怎么组装起来"（7 种）、**行为型**管"对象怎么交互分工"（11 种）。

口诀（自编，按序号背）：
- 创建型 5：**单原工抽建**（单例、原型、工厂方法、抽象工厂、构建器）
- 结构型 7：**适桥组外装享代**（适配器、桥接、组合、外观、装饰器、享元、代理）
- 行为型 11：**责命解迭中，备观状策模访**（职责链、命令、解释器、迭代器、中介者、备忘录、观察者、状态、策略、模板方法、访问者）

**数量口诀**：**5 / 7 / 11**（连着念"五七十一"）。考题问"下列属于创建型的有几个"，先数出 5 个就够了，不必逐个回忆意图。

**另一种分类维度（算考点，别忽略）**：按**作用范围**分**类模式**与**对象模式**——**类模式只有 4 个**：**工厂方法、适配器（类）、模板方法、解释器**；其余 19 个都是**对象模式**（适配器两种都算：既可用类继承实现，也可用对象组合实现，所以两边都列它）。**记住"类模式 = 4 个"这个数**比记名字更实用：看到"下列属于类模式的是"，先在心里数出这 4 个。

### 4.2 23 种意图速查表（背"意图一句话 + 速记词"）

**创建型（管出生）**：

| 模式 | 意图一句话 | 速记词 |
|---|---|---|
| Singleton 单例 | 保证一个类**只有一个实例**，提供全局访问点 | 唯一实例 |
| Prototype 原型 | 通过**拷贝**原型来创建新对象 | 克隆 |
| Factory Method 工厂方法 | 定义创建对象的接口，**由子类决定**实例化哪个类 | 动态生产对象 |
| Abstract Factory 抽象工厂 | 创建**一系列相关对象**，无需指定具体类 | 成系列生产 |
| Builder 构建器 | 复杂对象的**构建过程与表示分离**，分步构造 | 分步组装 |

**结构型（管组装）**：

| 模式 | 意图一句话 | 速记词 |
|---|---|---|
| Adapter 适配器 | **转换接口**，使原本不兼容的类协同工作 | 转换接口 |
| Bridge 桥接 | 把**抽象与实现分离**（两个维度），使它们独立变化 | 继承树拆两维 |
| Composite 组合 | 把对象组成**树形结构**表示"整体—部分"，单个和组合对象使用一致 | 树形目录 |
| Facade 外观 | 给复杂子系统提供一个**统一的高层接口** | 统一窗口 |
| Decorator 装饰器 | **动态地给对象附加职责**，比继承灵活 | 附加职责 |
| Flyweight 享元 | **共享**大量细粒度对象，节省内存 | 共享细粒度 |
| Proxy 代理 | 为对象提供一个**替身**以控制对它的访问 | 间接访问 |

**行为型（管交互）**：

| 模式 | 意图一句话 | 速记词 |
|---|---|---|
| Chain of Responsibility 职责链 | 请求沿处理者**链条传递**，直到被处理 | 传递职责 |
| Command 命令 | 把请求封装成对象，支持**撤销、日志、排队** | 请求变对象 |
| Interpreter 解释器 | 给定语言文法，用解释器**解释句子** | 解释语言 |
| Iterator 迭代器 | 顺序访问聚合元素而**不暴露内部表示** | 逐个访问 |
| Mediator 中介者 | 封装对象间交互，各对象**不必显式互相引用** | 中介转达 |
| Memento 备忘录 | 保存对象状态，需要时**恢复** | 存档恢复 |
| Observer 观察者 | 一对多依赖，状态变化时**通知所有依赖者** | 订阅—通知 |
| State 状态 | 对象在**状态改变时改变行为** | 状态变行为变 |
| Strategy 策略 | 封装一系列**算法**，使它们可**互相替换** | 算法可换 |
| Template Method 模板方法 | 父类定**算法骨架**，某些步骤延迟到子类 | 骨架在父类 |
| Visitor 访问者 | 不改动类的前提下给类**添加新操作** | 外加操作 |
