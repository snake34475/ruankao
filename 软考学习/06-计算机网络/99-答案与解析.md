# 06.10 答案与解析

### 课后考题答案

**1. B**。按 IP 地址查路由表转发、连接不同网络、拦截广播帧——三条全是路由器（网络层）的职责。A/D 是物理层设备，C 二层交换机按 MAC 转发、不能隔离广播域。

**2. A**。TCP/IP 应用层 = OSI 的应用+表示+会话三层，SMTP/FTP/HTTP/DNS/DHCP 等应用协议都在此层。传输层只有 TCP/UDP，网际层是 IP/ICMP/ARP。

**3. B**。交换机（数据链路层）每端口一个冲突域，可隔离冲突域；集线器（物理层）所有端口共享一条路，隔离不了。广播域两者都隔离不了（C 错），D 错在交换机按 MAC 转发、工作在数据链路层。

**4. B**。第一字节 172 落在 128～191 → B 类；B 类私网段是 172.16.0.0～172.31.255.255，第二字节 30 恰好在 16～31 之间 → 私网。若写成 172.32.x.x 就是公网了，边界要抠准。

**5. C**。私网三段：10.x.x.x、172.16～172.31.x.x、192.168.x.x。A 的 172.32 越界（只到 172.31），B 的 192.169 越界（只有 192.168），D 的 169.254 是链路本地地址、不属于私网三段；C 的 10.255.255.1 在 10.0.0.0/8 内 ✓。

**6. B**。/28 → 主机位 32−28 = 4 → 2^4 − 2 = 16 − 2 = **14**。A 的 16 忘了减 2；D 的 30 是 /27 的答案；/28 一共 16 个地址，C 的 12 无依据。

**7. B**。掩码 255.255.255.**240** → 块大小 = 256 − 240 = **16**。边界：0、16、32、48…；37 落在 [32, 47] → 网络地址 **192.168.10.32**。二进制验证：37 = `00100101`，240 = `11110000`，按位与 = `00100000` = 32 ✓。该子网广播地址是 192.168.10.47，可用范围 .33～.46。

**8. B**。借位 s 需 2^s ≥ 6 → s = 3（2^2 = 4 不够，2^3 = 8 ≥ 6）。主机位 = 16 − 3 = 13，可用主机 2^13 − 2 = 8190 ≥ 25 ✓ 两个条件同时满足。掩码 = /19：前两字节 255.255，第三字节借 3 位 → 128+64+32 = 224 → **255.255.224.0**。"使每个子网可用主机数尽可能多"= 借位尽量少，故取满足条件的最小借位 s = 3：A（/18，借 2 位）只有 4 个子网、不满足子网数；C（/20）、D（/21）借位更多，子网数虽够但每子网主机数变少（C 为 2^12−2 = 4094，D 为 2^11−2 = 2046），均非"尽可能多"，排除。

**9. A**。4 个连续 /24 → 需要 2 位变化 → 前缀 24−2 = /22；起始网段 4.0，第三字节 4 是块大小 4（256−252=4）的整数倍 → 边界对齐 ✓ 聚合为 **192.168.4.0/22**（覆盖 4.0～7.255）。B 的 5 不是块边界（5/22 的网络地址其实是 4.0，写法非法）；C 的 /23 只能覆盖 2 个 /24；D 的 192.168.0.0/21 覆盖 0～7，范围过大、包含了题目没有的 0～3 网段，不精确。

**10. B**。UDP 三特征：无连接、不可靠（不确认不重传）、开销小速度快。A/C 是 TCP 的特征（UDP 无连接、无流量/拥塞控制），D 按序到达也是 TCP 才保证。

**11. D**。TCP 与 UDP 都用端口号区分上层应用（端口寻址）。A 连接管理、B 重传、C 流量控制都只有 TCP 提供——UDP 无连接、不重传、无流量控制。

**12. C**。三次握手：① 客户端发 **SYN**（进入 SYN-SENT）；② 服务器回 SYN+ACK（进入 SYN-RCVD）；③ 客户端回 ACK（双方 ESTABLISHED）。FIN 是断开连接用的，D 的 SYN+ACK 是第二步服务器发的。

**13. C**。SMTP 的默认端口是 **25**，110 是 **POP3**（收邮件）的端口——"发 25、收 110"是最经典的调包点。A/B/D 对应均正确（FTP 控制 21、HTTP 80、TELNET 23）。

**14. B**。DHCP = 动态主机配置协议，自动下发 IP 地址、子网掩码、默认网关、DNS 服务器等参数（UDP 67/68）。A 是 DNS，C 是 SMTP，D 是 HTTPS。

**15. D**。超链接用 `<a href="URL">`；`<p>` 段落、`<img>` 图片、`<br>` 换行。

### 案例题答案

**案例 1：**

**(1) 求掩码。** 每个子网最多 50 台主机 → 主机位 m 需满足 2^m − 2 ≥ 50 → m = 6（2^6−2 = 62 ≥ 50；m=5 时 2^5−2=30 < 50 不够）。C 类主机位共 8 位，借 8 − 6 = 2 位做子网位 → 恰好 2^2 = **4** 个子网 ✓（与题意吻合）。掩码 = /26 → 255.255.255.**192**。
验证：块大小 = 256 − 192 = 64，每个子网 64 个地址，可用 64 − 2 = 62 ≥ 50 ✓。

**(2) 四个子网。** 边界按 64 步进：

| 序号 | 网络地址 | 可用主机范围 | 可用主机数 |
|---|---|---|---|
| 1 | 192.168.100.0/26 | 192.168.100.1 ～ 62 | 62 |
| 2 | 192.168.100.64/26 | 192.168.100.65 ～ 126 | 62 |
| 3 | 192.168.100.128/26 | 192.168.100.129 ～ 190 | 62 |
| 4 | 192.168.100.192/26 | 192.168.100.193 ～ 254 | 62 |

每个子网可用主机数 = 2^6 − 2 = **62**。

**(3) 第 3 个子网。** 网络地址 192.168.100.128/26，主机位 6 位全置 1 得广播地址：128 = `10000000`，或上 `00111111` 得 `10111111` = 191 → 广播地址 **192.168.100.191**（即下一子网起点 192 减 1）。可用主机地址范围 **192.168.100.129 ～ 192.168.100.190**，共 190 − 129 + 1 = 62 个 ✓（与公式一致）。

### 扩充专项题答案

**1. B**。发送方自上而下封装：应用数据先加传输层首部成为段/UDP 数据报，再加 IP 首部成为分组，再加链路层首尾成为帧，最后在物理层变成比特流。A 把帧放得过早；C 把网络层与传输层颠倒；D 把帧与分组颠倒。

**2. B**。数据链路层的 PDU 是**帧**，随后物理层把帧编码成比特信号传输。A 是物理层的数据单位，C 是网络层，D 是 TCP 所在传输层。

**3. C**。目的 IP 10.1.1.8 与 192.168.10.20/24 不同网段，A 必须先把帧交给同网段的默认网关。因此第一跳帧的目的 MAC 是网关的 MAC；但 IP 分组的目的 IP 仍是 10.1.1.8。远程主机不在本地链路，A 无法直接查询并使用它的 MAC。

**4. A**。NAT 把内网私有地址映射到公网侧地址；配合端口转换时，多条连接可用不同公网端口共享一个公网 IPv4 地址。B 错在 NAT 不等于防火墙；C 与“共享地址”相反；D 错在 NAT 主要转换网络层地址，并可能连同传输层端口一起转换。

**5. A**。通用形式：发送窗口上限 = `min(rwnd, cwnd)`。代入得 `min(24 KB, 10 KB) = 10 KB`。接收方虽能容纳 24 KB，但当前网络拥塞控制只允许 10 KB，取较小者。

**6. B**。原窗口 `[1,4]` 含 1、2、3、4。确认 1、2 后，两个已确认位置从左侧移出，同时右侧加入两个新位置 5、6，得到 `[3,6]`。D 错误地把尚未确认的 3、4 也移出了窗口。

**7. C**。主机名位于 `://` 之后、端口号或第一个路径斜杠之前，因此是 `learn.example.org`。其中 `learn` 只是左侧主机标签，`https` 是协议，`/course` 是路径。

**8. A**。直接访问公网 IP 可行，说明网卡、链路、IP 路由大体可用；所有域名都失败，故障集中在“域名变成 IP”的 DNS 环节。若网卡损坏或链路完全中断，公网 IP 也无法访问。

**9. C**。GET 常用于获取/查询，参数常见于 URL；POST 常用于提交或改变状态，数据常放请求体。二者都不天然提供加密，机密数据传输要依赖 HTTPS。A、B 把请求方法与加密混为一谈；D 对传输内容作了不存在的限制。

**10. B**。根据用户身份、请求参数或数据库内容在运行时生成结果，是服务器端动态网页的典型特征。A 是静态资源；C 是链路层转发；D 是名称解析，都不是网页动态生成。

### 精华题答案

**1. C**。加密/压缩/编码转换是**表示层**的本职（TCP/IP 模型中并入应用层实现）。应用层直接面向用户程序，会话层管会话建立与终止，传输层管端到端交付。

**2. A**。五步法：/22 → 主机位 10 位；掩码最后非 255 字节在第三字节 = 252，块大小 = 256 − 252 = **4**。第三字节边界：0、4、8、…、32、36…；35 落在 [32, 35] → 网络地址 130.24.32.0。广播地址 = 本块末尾：第三字节取 35、第四字节全 1 → **130.24.35.255**。
二进制验证：第三字节 35 = `00100011`，掩码 252 = `11111100`，按位与 = `00100000` = 32 ✓（网络地址第三字节 32）；主机位（第三字节低 2 位 + 第四字节 8 位）全置 1：`00100011` → `00100011`（低两位本来就是 11）、第四字节 = 255 → 广播 = 130.24.35.255 ✓。C 选项的 36 已是下一块的网络地址；D 的 130.24.63.255 是把 /22 误当 /19 或 /18 算出的更大块末尾。

**3. A**。第三字节 76、77、78、79 = `01001100`～`01001111`，前 6 位相同（`010011`）→ 聚合前缀 24 − 2 = /22，地址 **202.113.76.0/22**（覆盖 76.0～79.255）。B 写法非法（77 不是块边界：77 对应 /22 的网络地址是 76）；C 的 /23 只覆盖 76～77 两个 /24；D 的 /21 覆盖 72～79，把不属于题目的 72～75 也包了进去。

**4. D**。服务器状态机：LISTEN →（收到 SYN，回 SYN+ACK）→ SYN-RCVD →（收到 ACK）→ **ESTABLISHED**。客户端是 SYN-SENT → ESTABLISHED，且 SYN-SENT 只出现在客户端一侧；C 的 SYN-SENT 是客户端发完第一个 SYN 后的状态。

**5. B**。ICMP（互联网控制报文协议，ping 的底层）与 IP、ARP 同属**网际层**。UDP 是传输层，FTP/SMTP 是应用层。

**6. C**。借位 s 需 2^s ≥ 12 → s = 4（2^3 = 8 < 12，2^4 = 16 ≥ 12）。掩码 = /28 → 255.255.255.**240**。"使每个子网可用主机数尽可能多"= 借位尽量少，故取最小借位 s = 4；A（/26，4 个子网）、B（/27，8 个子网）不满足"至少 12 个"，D（/29，32 个子网）借位更多、每子网可用主机仅 2^3−2 = 6 台，均排除。C 每子网可用 2^4 − 2 = 14 台。

**7. B**。每子网最多 30 台主机 → 2^m − 2 ≥ 30 且取最小 → m = 5（2^5−2 = 30 恰好满足）。C 类 8 位主机位借出 8 − 5 = 3 位做子网位 → 子网数 2^3 = **8** 个，掩码 /27（255.255.255.224）。验证：块大小 256 − 224 = 32，8 个子网 × 32 地址 = 256 ✓ 恰好用满整个 C 类网段。
