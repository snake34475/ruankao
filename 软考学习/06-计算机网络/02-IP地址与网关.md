# 06.2 IP 地址、NAT 与默认网关 ★★

### IP 地址长什么样

IPv4 地址是 **32 位二进制数**，为了人能看懂，每 8 位一组转成十进制、中间用点隔开，叫**点分十进制**，如 `192.168.1.1`。每组取值 0～255。32 位 = 4 个字节。

### 五类地址（必须会判断类别）

按**第一个字节**（前几位）划分：

| 类别 | 二进制开头 | 网络位/主机位 | 第一字节范围 | 默认掩码 | 用途 |
|---|---|---|---|---|---|
| **A 类** | 0 | 8 位 / 24 位 | **1 ～ 126** | 255.0.0.0 | 超大网络（主机数极多） |
| **B 类** | 10 | 16 位 / 16 位 | **128 ～ 191** | 255.255.0.0 | 中型网络 |
| **C 类** | 110 | 24 位 / 8 位 | **192 ～ 223** | 255.255.255.0 | 小型网络 |
| D 类 | 1110 | — | 224 ～ 239 | — | 组播（多播） |
| E 类 | 1111 | — | 240 ～ 255 | — | 保留（实验） |

**判断口诀**：看第一字节——**1～126 是 A，128～191 是 B，192～223 是 C**；中间没写的 127 是特例（见下）。D、E 类不用于给普通主机编址。

### 特殊地址（考试直接考结论）

| 地址 | 含义 |
|---|---|
| **127.x.x.x** | **回环地址**（本机自测，最常见 127.0.0.1），永远不进网络 |
| 主机位**全 0** | 代表**网络本身**（网络地址），不能分给主机 |
| 主机位**全 1** | 代表**广播地址**（向全网段所有主机广播），不能分给主机 |
| **169.254.x.x** | 链路本地地址（DHCP 要不到地址时系统自动配的"临时工"），不是私网地址 |
| 0.0.0.0 | 代表所有网络/未指定地址 |
| **255.255.255.255** | **受限广播地址**：只在本地网段广播，路由器不转发 |

**这正是第三节"减 2"的来源**：一个网段里主机位全 0（网络地址）和全 1（广播地址）两个地址被"公家"占用，可用主机数要减 2。

### 私网地址（三段，必背）

私网地址是只允许在单位内部使用的地址段，**不会出现在公网路由上**（不同公司的内网可以重用同一批私网地址）：

| 段 | 范围 | 相当于哪类 |
|---|---|---|
| **10.0.0.0/8** | 10.0.0.0 ～ 10.255.255.255 | A 类 |
| **172.16.0.0/12** | **172.16.0.0 ～ 172.31.255.255** | B 类 |
| **192.168.0.0/16** | 192.168.0.0 ～ 192.168.255.255 | C 类 |

**反例演示（三段边界陷阱）**：
1. **172.32.1.1 不是私网**——私网只到 172.31.255.255，172.32 已越界（是普通 B 类公网地址）。判断只看第二字节是否在 **16～31** 之间。
2. **192.169.1.1 不是私网**——192.168 段只覆盖第三组为 0～255 的 192.168.x.x；192.169 越界。
3. **127.0.0.1 不是私网地址**，它是回环地址，和私网是两个概念。
4. 私网判断题里若出现 169.254.x.x，它是"链路本地"，也不是 RFC 私网三段之一。

### NAT：私网主机怎样访问公网 ★★

私网地址不能直接在公网中路由，但家里多台设备仍能共用一个公网地址上网，靠的是路由器上的 **NAT（网络地址转换）**。数据离开内网时，NAT 把报文中的私网源地址改成公网地址；返回报文到达后，再根据转换记录还原并交给原主机。

家庭路由器常用端口转换（也常称 NAPT/PAT）：不仅转换 IP，还给不同内网连接分配不同的公网端口。例如：

```text
192.168.1.10:5000 ── NAT ──→ 203.0.113.8:40001
192.168.1.20:5000 ── NAT ──→ 203.0.113.8:40002
```

两台主机可以使用相同的内网端口，因为公网侧端口不同，返回数据仍能找到各自的主人。NAT 的主要作用是**节省公网 IPv4 地址、让私网地址访问公网**；它会隐藏内部地址结构，但**不等同于防火墙**，不能因为用了 NAT 就认为系统自动安全。

### 默认网关：跨网段通信的第一跳 ★★

**默认网关**通常是“与本机位于同一网段的路由器接口 IP 地址”。主机准备发送数据时，先用自己的子网掩码判断目的 IP 是否同网段：

- **同网段**：直接查询目的主机的 MAC 地址并发送，**不经过默认网关**。
- **不同网段**：主机不知道完整远程路径，就先把帧交给默认网关，由路由器继续查路由表转发。

例：主机 A 为 `192.168.1.10/24`，网关为 `192.168.1.1`。

- 访问 `192.168.1.80`：前三个字节相同，属于同一 /24 网段，帧直接发给 `.80` 的 MAC。
- 访问 `10.0.0.8`：不同网段，IP 分组的目的 IP 仍是 `10.0.0.8`，但第一跳帧的目的 MAC 是网关 `192.168.1.1` 对应的 MAC。

**常见故障判断**：本机能访问同网段设备，却不能访问任何外网地址，优先检查默认网关或路由；若连同网段设备也不通，则还要检查 IP、掩码、网卡与链路。

**反例演示**：“默认网关可以随便填一个公网 IP”——错。主机必须能在本地链路上把帧交给网关，因此网关接口通常必须和主机在同一子网；否则连第一跳都送不到。

**应试动作**：① 背 A/B/C 三类的第一字节范围与默认掩码；② 私网三段背死（10 / 172.16～172.31 / 192.168），判断时逐字节比边界；③ 记住"主机位全 0 是网络地址、全 1 是广播地址、127 是回环"，这三条既直接出选择题，又是子网计算的理论基础。
